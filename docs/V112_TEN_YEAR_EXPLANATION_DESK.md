# ConceptKnot v112 — 10개년 800문항 개인 해설 작업대·백업 호환

2026-11-04 · 기준 커밋: v111 `86dd887429aa86fa52cfba1dd6f92f33f5a797da`.
**이 문서는 코드 개발 기준이며 운영 배포 또는 실기 PASS 보고가 아닙니다.**

## 복원·실제 확인
- GitHub neoflowcore/ConceptKnot main을 직접 읽어 이전 v111의 작업대·공식 기출 등록·해설 번들·TTS 상태와 비교했다.
- 2016~2025년 공식 문항 800/800, 연도별 80문항, 5개 선지 × 800=4,000선지 데이터는 변경하지 않았다.
- 최근 5개년 해설 파일만 존재: 2021~2025 총 400문항 중 기본 초안 32, 미작성 368, 공식 조문/판례 근거 확인 0(기존 데이터 보고).
- 2016~2020년 400문항은 공식 문제·채점 인정 선지만 존재하며 **별도 해설 번들은 존재하지 않음**. 내용/근거를 자동 생성하거나 게시하지 않는다.

## 구현 범위 (v112)
1. `ck-study-workbench-v81.js`: 유효 문항 ID 2016~2025, 개인 진행 저장 상한 800으로 확대. 2021~2025 5개 해설 번들만 로드하고 2016~2020년은 "기본 해설 미제공"으로 분리.
2. 공식 은행 `CK89OfficialBank.loadAll()`을 통해 과거 5개년 400문항 검증/로딩 시도. 실패하면 부분 자료를 검증 완료로 승격하지 않으며 기존 개인 상태 보호.
3. 연도 × 과목 20셀 현황판, 개인 초안 8항목 입력도·출처 5/5 건수, 오답·복습 우선순위, 특수정답·원문 유사도 및 법령/판례 대조용 5문항 묶음 질문을 전체 10개년으로 확장. 질문 텍스트에는 선택지 ①~⑤의 판정·조문/판례·시행일 입력 칸을 두고, **검증 전 템플릿**이라는 경고를 포함한 로컬 TXT 저장 버튼을 제공.
4. `ck-study-editor-v80.js`: 2016~2020년 원문이 등록된 문제는 **비어 있는 개인 해설 초안**으로 작성 가능. 기존 2021~2025 초안은 유지하고 공식 정답·원문은 수정 불가.
5. 개인 편집 저장 및 복원 시 검토 작업대가 즉시 현황을 갱신. 800문항/5선지 입력 UI와 "내 해설 초안" 바로가기 연결.
6. 독립 JSON 내보내기 범위 `personal-unpublished-2016-2025`. 과거 `personal-unpublished-2021-2025` 파일도 복원 허용, 겹치는 항목의 최신 수정 시각 기반 병합 유지. 개인 기록이 공식 검수로 승격되지 않음.
7. `ck-data-integrity-v86.js` 통합 JSON 복원에서 800건 개인 초안·과거 연도 ID·최대 350만 문자 허용. 새로 도입한 유효성 검사를 통해 임의 게시 상태/잘못된 문항 번호 차단. 백업 적용 실패 시 기존 저장값 롤백 원칙 유지.
8. `index.html` / `sw.js`: v112 파일 캐시 갱신, 안전 복원 대체 경로가 과거 5개년 개인 초안을 누락하지 않게 처리. Git 자동배포 불허 및 Actions/EXE/APK/ZIP 생성 안 함.

## 문제 분석·TTS 연계 확대
- 해설 작업대에서 문항별 ▶ 바로 듣기와 상위 1·3·5문항 ▶ 연속 듣기, ■ 음성 정지를 제공합니다. 사용자의 음성 방식/배속을 그대로 따르며 음성은 실제 버튼 클릭으로만 시작됩니다.
- 800문항 근거 검토 대기열에서도 현재 페이지 상위 5문항 또는 개별 문항을 바로 듣고 정지할 수 있습니다.
- 새로운 `CK76Voice.playSelected(ids, mode)`는 연도·과목을 넘나드는 개인 검토 묶음에서도 **실제 공식 등록 문항만** 낭독합니다. 하나라도 공식 원문이 누락되면 전체 묶음을 재생하지 않고 오류를 보고합니다.
- 전원정답 문항은 정답 중심 모드에서 제외하고, 전체 5선지 모드에서만 별도 안내와 함께 읽습니다. 채점상 정답 인정과 각 선지의 참/거짓을 동일시하지 않습니다.
- 원문·법령·선지 근거 검토 질문 TXT 출력은 개인 작업 템플릿이며, 법령 검수·전문가 확인 완료라고 표시하지 않습니다.

## ①~⑤ 선택지별 출처 기록과 작업대 정합성
- 개인 해설 편집기에 5개 선지 각각의 **판례번호·조문·원문 PDF 페이지·시험당시 기준일 등** 출처 입력 칸을 추가했습니다. 항목당 260자 제한, 새/구 개인 JSON에 선택적 출처 텍스트가 저장되고, 검증이 끝났다는 표식으로는 사용하지 않습니다.
- Android Brave의 작은 화면에서도 출처 textarea가 좁은 열로 찌그러지지 않도록 1열 전체 너비와 최소 높이를 지정했습니다. 2019년 문항 1건의 빈 개인 초안을 열어 5칸을 표시하고, ①·② 출처를 저장한 뒤 `ck:personal-editor-updated` 이벤트가 발생하며 공식 정답은 불변인 모의 DOM 검사를 통과했습니다.
- 기존 CK83 선지 메모에 저장한 출처와 CK80 개인 해설 초안에 저장한 출처는 **서로 독립된 기록**으로 유지합니다. 10개년 해설 작업대와 800문항 근거 검토 대기열에 두 출처의 누적 작성 수(/4,000)를 각각 표시하며, CSV의 해당 열도 분리합니다.
- 검토 대기열에서 **'해설 초안 출처 미기록'** 필터로 출처가 5개 미만인 문항을 추려봅니다. 기존 선지 메모의 5/5 충실도 표시는 CK83의 수치임을 명시해 CK80의 개인 초안 출처와 오인하지 않도록 했습니다.
- 출처 텍스트가 수식으로 시작해도 검토 CSV에서 스프레드시트 수식으로 실행되지 않도록 이스케이프합니다. 기존 사용자 기록은 건드리지 않습니다.
