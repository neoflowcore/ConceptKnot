# ConceptKnot v93 · 선택지별 개인 검토 통합

- 2016~2025 공식 800문항에 개인 메모로서 각 5선지의 참/거짓/조건부/미검토와 근거·출처를 기록합니다.
- 기존 ck83-personal-concept-links-v1 저장 키와 legacy records를 유지하며 선택적 optionNotes를 추가합니다.
- JSON 백업/복원, 개인 개념 역검색, 모달 편집기, 개인 검토 진행률, 7/30일 통계 문구에 연동합니다.
- 정답 인정은 참/거짓 판정과 별개이며 공식 기출 원본이나 검증 완료 표시를 수정하지 않습니다.
- 개인정보는 localStorage에 보관합니다. 자동 CI, Actions, 설치 아티팩트는 생성하지 않습니다.
- 실기 확인: 2025-1 편집→선지별 근거 저장→새로고침→복원; 2016-1 과거 기출 로딩 후 편집; 중복 탭 충돌; 다크·모바일; 손상 JSON 거부.
- 사용자 요청에 따른 후속 800문항 전문가 원문/법령 대조 및 Android S펜 검증은 여전히 미완료입니다.
