# ConceptKnot v100 · 해설 작업대·복습 통합·검수 우선순위

기준 커밋: v99 \`9d0177c37fd5d1b9be8f5d138c88b77776ed2333\` (2026-11-02).
저장소 \`neoflowcore/ConceptKnot\`, \`main\`. 로컬 소스가 없어도 GitHub 브랜치와 프로젝트 체크포인트를 비교하여 개발 재개.

## v100에서 바꾼 동작

1. **해설 작업대 초기화 오류 수리** — 로컬 저장 상태 값이 초기화되기 전에 실행되는 호출을 정정해 스크립트 시작 예외를 방지.
2. **복습 판정 일원화** — 해설 작업대가 독립적으로 지난 오답을 합산하는 대신, \`CK86ExamBridge.getDue()\`의 최신 시험·복습·해소 기록을 사용. 다른 탭의 변동 반영.
3. **해설 검수 상태와 개인 진행 분리** — 기본 해설 초안, 미착수, 개인 초안, 내용 근거·선지별 출처 검수를 각각 표시. 사용자의 개인 \`ready\` 상태는 전문가 확인으로 표시하지 않음.
4. **검수 우선순위** — 대기 중인 오답·복수/전원정답·OCR/원문 텍스트 유사도 0.90 미만·시각 대조 미확인 등을 기준으로 **우선순위를 안내**. 유사도 점수만으로 내용 오류라고 확정하지 않음.
5. **단건/묶음 검토 프롬프트** — 1·3·5문항 단위로 문제·5개 선지·채점 인정·원본 PDF·Q-Net 출처·검수 상태 및 근거 대조 요청을 텍스트로 복사. 자동 API 전송·기출 변경 없음.
6. **개인 검토 대기열 일괄 추가** — 최대 5문항을 한 번의 저장으로 \`researching\`/중요 표시에 반영. 이미 \`hold\`/ \`ready\`인 문항을 덮어쓰지 않음.
7. **검토 가능성 개선** — 공식 출처와 외부 PDF 링크를 구분하고, 2021~2025년 40문항씩 행렬에 해설 근거 검수 비율 표시. 필터·정렬·CSV에 원문 검수 정보를 추가.
8. **동시 탭 충돌 안전성** — 유효한 외부 변경은 새 상태로 다시 읽고, 비정상 기록은 추가 저장하지 않음. 미반영 외부 기록을 무조건 덮어쓰지 않음.
9. **오프라인 파일 갱신** — 정적 파일 URL 버전 및 서비스 워커 캐시만 변경. 설치 아티팩트/Actions/자동배포 없음.
10. **해설 등록 데이터 품질 감사** — 2021~2025년 400문항의 최종 정답 일치·선지 구조·검수 플래그·해설 출처 준비도 확인. 감사를 실행해도 공식 파일을 수정하지 않음.

1. 기존 브라우저 학습 데이터를 **원본 JSON 백업**해 안전한 곳에 저장.
2. 자동 배포 비활성이므로 v100이 반영된 수동 배포/로컬 테스트 웹페이지에서 실행.
3. 최근 5개년 해설 작업대 열기: 초안 32·미착수 368·해설 근거 검수 0을 확인.
4. 상태 필터 ‘원문 유사도 0.90 미만’, ‘해설 근거 미검수’, ‘중요·복습 우선’ 선택.
5. 1·3·5문항 출처 검토 질문 복사; 공식 최종정답과 Q-Net 링크, 외부 PDF 링크 분리 확인.
6. 5문항 일괄 개인 연구 등록. 한 번에 저장되고 보류·준비 상태를 덮어쓰지 않는지 확인.
7. 별도 브라우저 탭에서 개인 상태 변경 후 다른 탭 자동 동기화 및 손상/충돌 대응 확인.
8. 80문항 모의고사에서 틀린 뒤 해설 작업대 ‘복습 대기’에 보이는지 확인; 다시 정답/회상 성공 후 해소와 일치하는지 확인.
9. CSV 다운로드 후 ‘개인 진행’ 및 ‘근거/선지/시각 검수 상태’ 열이 올바르게 정렬되는지 확인.
10. 2016~2020 공식 원문 및 특수정답을 대조하고, S펜 몸통 버튼·손터치·TTS·PDF·애니메이션 GPU 실기를 별도 실시.

## v100 추가 검수 진단·연결 수정

- 10개년 데이터 안전 점검에서 시각 미검토와 원문 유사도 0.90 미만 후보를 분리해 탐색. \`visualReview: true\`라도 낮은 텍스트 유사도만으로 바로 내용 오류라 단정하지 않고 재대조 대상으로 보여줌.
- 2016~2020 연도 선택 시 등록된 정적 공식 데이터를 요청하고 연속 선택해도 로딩을 중복하지 않음.
- 해설 작업대에서 원문 PDF(외부 참조)와 공식 Q-Net 출처를 서로 다른 링크로 표시.
- 해설 작업대 → \`CK83Links\` 선지별 개인 판단·근거 편집으로 직접 이동.
- 해설 작업대 CSV의 16개 열이 제목/행과 일치하는지 400개 실제 자료를 사용한 모의 UI 실행에서 확인.
- 개인 복습 대기열은 해설 작업대·집중복습·학습계획·학습통계에 공통 \`CK86ExamBridge\` 경로 사용. 정답/복습 예약/최근 제출 결정의 우선순위는 최신 데이터에 따라 재계산.

### 검사 범위 / 해석

- 새 v100 기능의 개별 테스트는 Node용 테스트 파일로 저장하고, 연결된 GitHub 소스를 V8 모의 DOM/저장소 환경에서 실행한 검사 결과만 실제 통과로 표기한다.
- 오프라인 정적 사전 검사 \`node scripts/check-release-readonly.cjs\` 제공(수동 실행용, 파일 변경·네트워크/Actions/빌드 없음).
- 실제 Chromium GUI, 모바일 Brave/S펜 버튼·압력·PDF·한국어 TTS는 사용자 기기에서 확인 전까지 미검증.
- \`원문 유사도\`는 자동 텍스트 비교 점수일 뿐 정답의 법적·사실적 적합성을 판단하지 않는다.
