## 2. 추가한 경제학 수학 모형

1. **예산선/무차별곡선** — `I=Px·X+Py·Y`; `U=X^α Y^(1−α)`. 최적소비 `X*=αI/Px`, `Y*=(1−α)I/Py`; 예산 변화와 상대가격 변화의 차이를 시각화.
2. **생산가능곡선** — `Y=Ymax·[1−(X/Xmax)^γ]`, `γ>1`; 한계 기회비용 및 효율·비효율·생산불가능 구분.
3. **한계수입/한계비용** — `P=A−bQ`, `TC=F+cQ+kQ²`, `MR=A−2bQ`, `MC=c+2kQ`; 단기 이윤 극대화 `Q*=max(0,(A−c)/(2(b+k)))`.
4. **거리·지대** — `R=max(0,R0−t·distance)` 단순 입찰지대. 현실 지가 인과로 오해하지 않도록 고정 조건 제시.
5. **거미집 모형** — `Q(t)=c+d·P(t−1)`, `P(t)=(a−Q(t))/b`; `|d/b|<1` 수렴, `>1` 발산, `=1` 중립진동. 음수 가격 진입 시 추정 중단.
6. **호탄력성** — 두 관찰점의 중간점 변화율. 가격 변화가 0이면 무한대로 오표기하지 않고 계산 불가 표시. 점탄력성과 별도.

각 모형의 숫자는 **가상 학습 예시**. 공식 기출 데이터나 시장가격 예측이 아니다. 가정이 성립하지 않으면 일반명제로 단정하지 않는다.
