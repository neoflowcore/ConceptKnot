# ConceptKnot v111 — 800문항 선지 근거 대기열 / TTS 안정성

## 출처 및 재개 기준
- repository: neoflowcore/ConceptKnot, main bdbfb852a05a38a3292e5147c23dc9d067b700be (v110).
- 공식 문제/최종정답 JSON은 읽기 전용, 해설 32개 초안과 미작성 368개를 공식 검수 완료로 승격하지 않는다.

## 구현
1. 자료·분석 메뉴 안에 검토 대기열을 추가. 2016~2025 / 부동산학개론·민법 / 출처 누락 / 판단·이유 미기재 / 계산·수치 / 도표 / 법령·판례 / 복수·전원정답 필터와 우선순위, 24개씩 페이징.
2. 기존 CK83Links 개인 근거 편집기 및 CK78Analysis 공식 문제 분석 진입 연결. 공식 정답의 '채점 인정'은 개별 지문의 옳고 그름과 구별한다.
3. 연도별 80문항, 총 800문항의 구조가 모두 검증되어 로드된 경우에만 800문항 요약 CSV 및 4,000선지 검토 CSV 다운로드 가능. 스프레드시트 수식 주입 방어와 로컬 전용 다운로드.
4. 분석 창에서 TTS 일시정지·재개·정지 버튼 및 실시간 상태(준비/재생/중단/오류/진행도) 표시.
5. 과목 연속 듣기에서 미로드 문제를 조용히 건너뛰지 않고 오류를 명시, 부정확한 '재생 성공' 표시를 제한. 음성이 시작되기 전 책갈피를 저장하던 경로 수정.
6. 2016~2020년 문항 비동기 불러오기 완료가 이후에 선택한 새 분석 창을 덮는 문제를 취소 토큰으로 차단.
7. 기존 다크모드/고정 오른쪽 설정/한 줄 모바일 탭 스크롤, 개인 저장 내용과 JSON 백업 로직을 변경하지 않는다. 서비스워커 캐시 버전을 변경해 신규 리소스 제공.

## 정량 기준 및 미완료
- 기출 800문항 구조는 등록됨. 해설 최근 5개년 400건 중 초안 32건, 미작성 368건. 4,000선지의 판례/조문 원문 전문가 검수 완료 수는 0건(기존 기록).
- 개인 판단과 출처 작성은 전문가 검증이 아니며 자동 키워드 후보도 사실 확인된 출제 빈도가 아니다.
- 마지막 과거 운영 체크포인트 P0~P5 = 80/80/80/60/40/40%, 합계 19/30(63%). v111의 현재 완성률·디자인 초안 일치율은 재측정 전.
- 자동 Actions / Vercel Git push deploy / EXE·APK·ZIP 금지, 사용자의 별도 요청 없는 수동 운영 배포 없음.

1. 모바일 Android Brave와 PC에서 자료·분석 → 근거 검토 대기열 열기. 10개년/과목/필터/24개 페이징과 문제 분석 및 ①~⑤ 개인 근거 편집 연결 확인.
2. 2016~2025 각 80문항 로드한 뒤 CSV 800행 및 4,000행 다운로드. 개인 기록이 출처/이유/판단 칸에만 기록되고 공식 정답이 변하지 않는지 확인.
3. 2016~2020년 문제를 로딩하다가 빠르게 다른 문제 분석을 눌러 오래된 모달 결과가 덮어씌워지지 않는지 확인.
4. 2024년 학개론·민법 문제의 TTS 3모드, 일시정지→재개→정지, 실제 한국어 여성 AI F1~F5, 1.5배속 및 40문항 연속재생 확인.

6. 원문 일부가 미로드된 상태에서 40문항 연속 듣기를 누르면 오류가 표시되고 부분 소리가 나지 않는지 확인.
7. 이미 저장된 개인 JSON을 백업하고 PDF 2쪽, SPen 버튼/터치, 상단 탭 위치, GPU·배경 정지를 수동으로 재확인.
