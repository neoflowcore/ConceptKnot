# ConceptKnot v117 — PDF 필기 비파괴 백업·복원 / 저장 실패 보호 / 선택형 텍스트 추출

기준: 2026-11-04, `main` v116 `7ad68198005eac0fa507969e45f062237b4b2955`.
대상: 기존 `assets/ck-pdf-workspace-v15.js`, 보조 스타일, 앱 연결, 캐시, 회귀 테스트.

> 이 문서는 **코드 변경과 수기검증 계획**이다. Android Brave/S Pen 실기 PASS, 공식 기출 원문·법령 감수 완료, OCR 구현 완료를 뜻하지 않는다.

## 변경 기능

1. PDF 필기 저장 실패(`localStorage` 공간 부족/권한 거부)를 **`inkDirty`**로 표시한다. 미저장 필기가 남아 있으면 PDF 페이지 이동·펼쳐보기 전환·앱 탭 이동을 차단하고 JSON/PDF 보존을 안내한다.
2. 유효하지 않은 기존 PDF 획/페이지/JSON이 있을 때 빈 기록으로 조용히 덮어쓰지 않는다. 손상된 원본 문자열을 **수기 다운로드**할 수 있게 하고, 명시적 복원 파일을 선택하기 전에는 보호한다.
3. PDF **필기 JSON 백업/복원** 버튼을 원문 필기 UI에 추가한다. 원본 PDF 파일은 수정하지 않는다. 백업은 전체 학습 JSON과 별개이며 직접 다운로드를 확인해야 한다.
4. JSON 복원 시 **현재 연도·원본 문서 키**, 가능하면 원본 PDF SHA-256을 비교한다. 형식, 좌표(0~1), RGB 색상, 굵기, 페이지 범위, 최대 500페이지/12,000획/400,000점/12MB를 검사한다. 불일치, 손상, 다중 탭 수정 충돌이면 기록을 덮어쓰지 않는다.
5. 기존 필기가 있거나 손상된 기록을 교체할 때 **사용자 확인**을 요청한다. 백업 파일은 브라우저에서만 읽고, 서버/AI/OCR 서비스로 전송하지 않는다.
6. 펼친 PDF의 **현재 페이지 또는 양쪽 2페이지의 선택 가능한 문자 레이어**를 수동으로 TXT 추출한다. 스캔 이미지에서는 추출할 텍스트가 없으며 **이 기능은 OCR이 아니다**. 추출 내용은 자동으로 공식 기출 원문에 등록하지 않는다.
7. 오른쪽 PDF 필기·물리 버튼 pointerup·다중 탭 덮어쓰기 차단 등 v116 수정 경로를 계속 보존한다. 같은 파일명·같은 용량의 **다른 파일 객체**를 선택해도 이전 PDF 렌더 객체를 재사용하지 않고 다시 읽는다.
8. PDF 구문/자산 URL을 `?v=117`로 일치시키고 SW 캐시 이름 변경, 새 스타일 오프라인 캐시 추가. `vercel.json.git.deploymentEnabled=false` 및 워크플로 없음 유지.

## ⭐ 실기검증 — 직접 수기로 표시할 것

1. **개인자료 백업 선행**: `설정 → 내 학습 데이터 다운로드`로 학습 JSON 내려받기. PDF에 필기한 경우 해당 PDF 화면의 `필기 JSON 백업` 또는 `PDF 저장`도 별도로 완료하고 다운로드 파일 존재 여부 확인.
2. **운영 버전**: v117을 수동 운영 배포한 뒤 새로고침. GitHub v117 코드와 Vercel 배포 커밋이 일치하는지 확인. v115 운영 사이트에서 이 항목을 시험하면 수정 검증이 아니다.
3. **기본 PDF 기능**: 2025년/2024년 기출 PDF 로딩, 한쪽/두쪽 펼쳐보기, 왼쪽과 오른쪽에 S Pen 작성, 페이지 전환·새로고침·복원 뒤 각 페이지 획 유지. 펜 종료/물리 버튼/지우개/손가락 터치도 직접 검사.
4. **필기 JSON**: ① 왼쪽 1획, 오른쪽 1획 기록 → ② `필기 JSON 백업` 클릭 → ③ 다운로드 파일 저장 확인 → ④ 원본 PDF에서 내용 일부를 변경 → ⑤ `필기 JSON 복원` 선택 → ⑥ 교체 경고 확인 → ⑦ 1·2쪽 획 복원 확인. 원본 시험/정답 데이터는 그대로인지 확인.
5. **서로 다른 PDF**: 다른 연도 또는 다른 이름/용량의 PDF를 열고 이전 백업을 복원하면 연도·문서 키가 맞지 않는다는 오류가 나야 한다. 가능한 브라우저에서 SHA-256 불일치도 차단돼야 한다.
6. **두 탭 충돌**: 같은 PDF를 두 탭에 열고 A탭 수정 후 B탭에서 기존 상태로 새 획을 쓰면 B탭이 A의 기록을 덮지 않고 충돌 경고를 보여야 한다. 기존 개인자료는 먼저 백업한 상태에서 시험한다.
7. **저장 실패**: 기존 프로필 저장공간을 의도적으로 채우지 말 것. **격리된 새 프로필**에서 저장 실패를 재현하면 앱 탭/펼쳐보기/페이지 이동이 막히고, 필기 JSON 또는 필기 PDF 저장 후 사용자에게 내보낸 파일을 확인하도록 안내해야 한다.
8. **문자 추출**: 글자를 마우스로 선택할 수 있는 PDF 1·2쪽에서 `현재 PDF 문자 추출` 클릭 → TXT 파일과 페이지 구분 확인. 이미지 스캔 PDF에서는 OCR 미지원 경고 확인.
9. **모바일 UI**: Android Brave에서 상단 설정 버튼 오른쪽 고정, 360/420px 탭 스와이프 위치 유지, 미저장 메모 보호, TTS 1.5배속/3모드 실제 소리, 다크모드·GPU 유휴 정지 확인.
10. **기록**: `설정 → 실기검증표`에 PASS/FAIL/미확인·실패 재현 경로와 브라우저·페이지 번호를 직접 남기고 TXT 및 전체 학습 JSON 저장. 실패한 항목은 코드 테스트 PASS로 바꾸지 않는다.

## 학습 통계 보강 (같은 v117 묶음)

- `CK83Analytics.compute`에서 과거 2016~2020 문항 데이터가 아직 로딩되지 않은 제출 시험을 조용히 0점으로 확정하지 않고, **통계 계산 누락 연도**를 표시한다.
- **사용자가 직접 클릭했을 때만** 이전 5개년 공식 기출 로딩 재시도를 호출한다. 최근 5개년 기본 자료가 누락된 경우 재시도 버튼 대신 사이트 파일/새로고침을 확인하도록 구분한다.
- 개인 데이터에 빈 타이핑/회상 이벤트가 포함돼도 통계 화면이 예외로 중단되지 않도록 한다. 타이핑 정확도·타수 값이 없는 경우 0으로 둔갑하지 않고 **자료 없음**으로 유지한다.
- `tests/v117-analytics-integrity.test.cjs` 3개 수동 Node 회귀 항목을 추가했고, 같은 로직의 분리된 V8 모의 실행에서 2019 미로딩 경고, 80문항 완전 로딩 후 100점/100점 계산, 빈 이벤트 무시를 확인했다. 실제 브라우저/Android 실기 PASS와 별개다.

### 학습 통계 수기검증

1. 설정에서 기존 개인 학습기록을 먼저 JSON 백업한다.
2. 2019년 모의고사를 제출한 기록이 있는 브라우저에서 `학습 데이터 분석 → 7일/30일`을 확인한다. 공식 과거 데이터가 로드되지 않은 경우 통계 누락 연도 경고가 있어야 한다.
3. `2016~2020 기출 데이터 재시도`를 직접 눌러 데이터 로딩 성공 시 연도별 점수 및 경고 해제 여부를 확인한다. 최근 데이터 기본 파일이 없다면 새로고침 안내가 나와야 한다.
4. 본인 타이핑 기록 중 정확도/타수 기록이 없는 항목을 '0점'으로 잘못 평균 내지 않는지 확인한다. 실측/회상 시각과 표본이 다른 경우 현재 학습 성적 일반화 금지.
5. 과목 필터 전환, 최근 7일/30일 선택, TXT 다운로드, 실패 시 경고를 확인한다.

## 사용자 파일명 충돌 주의

현재 로컬 PDF 필기 저장 키는 과거 호환성을 위해 연도·파일명·파일 크기를 사용한다. 내용이 다른 PDF의 **연도·파일명·크기가 정확히 같다면** 이전 필기 저장 키를 공유할 수 있으므로, 다른 PDF는 이름을 변경해 열고 각각 별도 필기 JSON을 저장한다. v117은 **PDF 렌더 객체 재사용 오류만 차단**하며, 파일 지문을 이용해 모든 로컬 저장 키의 충돌을 방지하는 전체 마이그레이션은 미완료다. 필기 JSON 복원에는 지원되는 브라우저에서 PDF SHA-256 비교가 적용된다.
