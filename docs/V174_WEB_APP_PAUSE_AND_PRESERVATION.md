# ConceptKnot 웹앱 잠정중단 및 보존 지침
> 문서 버전: v174 · 결정일: 2026-11-14 · 상태: **WEB DEVELOPMENT PAUSED / ANDROID APK PRIORITY**

## 1. 결정
ConceptKnot **웹앱 전체의 신규 개발을 잠정중단**한다. 이는 v173에서 정의한 "웹 AI TTS만 중단"보다 넓은 범위이며, 이전 웹앱 우선/웹·Android 병행 개발 결정을 대체한다. 개발 자원은 Android 네이티브 APK에 집중한다. **서비스 종료·삭제·기존 배포 중단을 의미하지 않는다.**

## 2. 중단 범위
- Brave/PWA 웹앱 신규 기능, UI/UX 리디자인, TTS 모델 배포·캐시 고도화
- 웹 전용 기출·모의고사·도형차트·검색·필기 신규 개발 및 일반적인 배포
- 웹 성능·애니메이션·테마 등 비필수 개선
- 자동 배포, 불필요한 GitHub Actions/아티팩트 생성

## 3. 보존 및 예외
- 저장소: https://github.com/neoflowcore/ConceptKnot
- 기존 운영 웹: https://conceptknot.vercel.app/
- 원본 문제·선지·해설 초안·학습 데이터·오답·노트·UI 및 차트 소스는 삭제하지 않는다.
- 기존 프로덕션 배포는 유지한다. 현재 코드가 자동 배포를 비활성화한 상태임을 보존한다.
- 긴급 보안 취약점, 데이터 유실, 서비스 장애 등 **보존에 필수적인 최소 수정**만 예외적으로 허용한다. 그 외에는 Android 앱으로 이관한다.
- Android 구현에 필요한 데이터 인터페이스/공유 모듈 추출은 허용하되 웹 화면의 기능 변경은 원칙적으로 하지 않는다.
- P4 구조적 400문항 및 10개년 800문항 관련 과거 진행 보고는 보존한다. **법령·판례·선지별 전문가 검수가 완료되었다고 표시하지 않는다.**
- 기존 이용자의 기기별 로컬 학습 기록은 원격 저장소에 자동 백업된다고 가정하지 않는다. 앱 이관 전 내보내기·가져오기 및 데이터 손실 방지 방안을 검증한다.

## 4. 웹앱 상태 동결 기준
