# ConceptKnot v145 — 선 드래그 화면 스크롤·무반응 수정 / 쉬운·심화 전후 설명

> 작성: 2026-11-08 KST · 기준: `main` v144 `2a7cea576640c210109234892434d733f560b42e` · 저장소: https://github.com/neoflowcore/ConceptKnot  
> 사용자 증상: “차트 안에서 선을 잡아 움직이면 화면 전체가 이동하고, 선은 움직이지 않는다. 예시를 보여주고 선 변화 전후의 쉬운 설명과 가격 심화 설명도 제공해야 한다.”

## 1. 코드 확인 원인

1. v144의 `#main .ck141-stage`와 `svg.ck141-live-svg`에는 **터치 영역 전체를 보호하는 `touch-action:none`이 없었음**. 25px SVG 투명 선 터치영역만으로는 좁은 Android 화면에서 판정이 어려워 원래 페이지 스크롤이 시작될 수 있었음.
2. 입력 시작 핸들러가 문서 **버블 단계**에서 `[data-ck141-drag]` 요소 정확히 일치한 경우에만 반응했음. 선 바로 옆을 누르면 조작 자체가 시작되지 않았음.
3. 곡선 화면 위의 설명·개념 패널이 **드래그 중 높이가 달라질 수 있는 상태**로 배치되어, 실시간 텍스트 갱신에 따라 차트가 이동하는 것처럼 보일 여지가 있었음.
4. 심화 6종 그래프도 제한된 핸들에만 조작을 허용해 곡선 본체를 잡아도 아무 변화가 없을 수 있었음.
5. 원래 상단의 **17종 기존 도식은 재생/진행률 변경 방식**인 반면, 새 수학적 조작 엔진은 화면 내 별도의 P6-B 실험실에 있어 사용자가 기능 범위를 혼동할 수 있었음. 17종을 실제 기울기 시뮬레이터라고 잘못 표시하지 않음.

## 3. 화면 동작 계약

- 차트 **안**에서 손가락 또는 S Pen으로 선 가까이를 누르고 움직이면 **해당 선이 이동/회전**하고 전 상태 점선·후 상태 실선 및 이론이 변경된다. **드래그 중 페이지는 스크롤되지 않는다**.
- 차트 **밖**의 일반 여백, 모의고사, 개인약점, PDF 필기 등은 기존 터치 스크롤 동작 그대로 유지한다.
- `⇄ 선 평행이동` 모드: 선 본체를 좌우 드래그할 때 비가격 요인 u/v가 변경된다. `↷ 선 기울기 변경` 모드: 학습용 가상 모델 기준가격 P25의 수량 고정점 중심 회전.
- 차트 바로 **아래**에 손가락 움직임에도 위치가 바뀌지 않는 **개념 이름 / 전후 수치 / 쉬운 생활 예시** 요약이 나타난다. 우측/아래에는 변경한 조건·고정한 조건 및 이론 해설.
- 예시 버튼: 소득 증가→수요 +20, 건축비 상승→공급 −20, 가격 +5, 수요의 가격반응계수 변경. 각각 현재 상태에서 한 번 적용되어 Undo/Redo로 비교 가능.
- 설명 레벨: `쉽게 · 생활 예시` 기본값, `심화 · 가격/수량` 선택 시 상세 표 자동 펼침. 경제학 가격점 변화의 Qd/Qs, 초과공급/초과수요, 기존 균형가격과 선택가격 구별.
- 구형 17종은 **원래 도식 애니메이션**이며 실제 수학적 기울기 변화는 별도의 P6-B 실험실에서 한다. 버튼으로 해당 실험실 진입.
