# ConceptKnot v31 · 타이핑 키보드·칠판 배치 · 운영 배포
작성일: 2026-10-29

## 네 가지 변경 사항

### 1) 타이핑 Enter·Space 두 버튼 (각각 기본 ON)
- `↵ Enter`: 활성화 시 미완성 문제의 현재까지 친 글자를 보존하고 즉시 정답 단락으로 이동. 문제를 끝까지 입력한 경우 한 번의 Enter로 문제/정답 구분 두 줄을 넘김. 정답 단락에 여러 줄이 있으면 Enter로 줄바꿈.
- `▱ Space`: 활성화 시 띄어쓰기 1칸을 직접 입력해야 진행. 중복 공백은 기존 sanitize에서 1개로 정규화.
- 토글 비활성화: Space는 입력 생략, Enter는 줄바꿈 입력 생략(건너뛰기 키 동작 중지). 입력 요구사항만 변경.
- 토글은 각각 `ck31EnterRequired`, `ck31SpaceRequired`로 저장하며 기본 true.
- 고정 원문/타겟 glyphs는 입력 길이와 관계없이 같은 문자·같은 줄바꿈으로 렌더. 모든 글자의 굵기 동일, 움직이는 등장 애니메이션 없음.
- 중간 Enter로 정답만 푼 경우 `answer-only:<문항ID>` 학습 기록으로 따로 보관; **문제 전체 완료율은 증가하지 않음**.

### 2) 단축키
- 타이핑 문항 이동: `Ctrl+←`, `Ctrl+→`.
- 기존 `Alt+←/→`와 `Alt+↑/↓`, `Alt+Enter` 전용 핸들러 제거.
- `Alt+Shift+WASD` 공간 포커스 이동은 유지.
- Ctrl 단독 KeyTips, Ctrl+Z/X, Ctrl+WASD, Ctrl+Enter 기존 기능 유지.
- 일반 문항 탭 이동 위·아래 방향키는 Ctrl+↑/↓로 변경. 입력란에서는 전용키 비활성.

### 3) 칠판 접기
- 레일 손잡이 아래에 접기/펼치기 아이콘. 접으면 칠판 칼럼이 완전히 제거돼 본문 공간을 확보.
- 칠판 DOM, 메모 내용, 펜 획은 그대로 유지; 클릭 시 전체 화면 render() 호출하지 않음.
- 로컬 `ck31BoardCollapsed` 저장, 탭 전환 후에도 유지.

### 4) 칠판 본문 아래 배치
- 레일의 좌우 위치 아이콘 아래에 상하 위치 아이콘. 선택하면 본문을 위, 칠판을 아래에 전체 너비로 배치.
- 다시 선택하면 마지막 좌우 배치(`ck6Swapped` 상태)를 복원.
- 피벗 및 좁은 화면에서는 본문 상단 → 칠판 하단의 세로 구조, 접기와 조합 가능.
- 레일 순서: 드래그 너비 → 좌우 바꾸기 → 상하 바꾸기 → 접기 → ChatGPT → Gemini → Claude.
- 상하/접기 상태에서는 가로폭 드래그를 비활성화하고 이전 폭을 보존.
