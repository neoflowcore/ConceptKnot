# 자료 신뢰도 및 법령 기준 정책

## 화면에 반드시 구분할 3종 자료

1. **공식 기출 원문**: 한국산업인력공단 Q-Net의 문항 PDF 링크. 해당 원문을 직접 확인하는 단계입니다. 10개년 800문항의 본문·5선지·최종정답을 앱에 내장하며 원본 PDF 링크도 유지합니다.
2. **학습용 정답 데이터**: 2016~2025년 A형 최종정답과 사용자가 직접 입력한 답안. 내장 답안은 원문 정답표와 대조했으며 전원정답·복수정답을 보존합니다. 사용자 수동 등록 값은 별도입니다.
3. **자체 제작 학습문항·요약·전이문항**: 공인중개사 기출에서 자주 다루는 주제를 연습하도록 만든 창작 콘텐츠. 실제 출제된 문제라고 표시하지 않습니다.

## OCR TXT 입력

- **입력 지원**: 외부 OCR에서 내보낸 텍스트(`.txt`, `.md`, 2MB 이하). 앱 내 이미지/PDF OCR은 지원하지 않습니다.
- **분할**: 문항 번호(선택한 과목 번호 범위 1–40 또는 41–80)를 기준으로 분리. OCR 인식 오류나 번호 중복은 있을 수 있습니다.
- **검토**: 저장 전에 미리보기를 확인하고, 기존 지문 덮어쓰기 시 경고합니다.
- **분석**: 키워드 기반으로 관련 개념 후보를 제안합니다. 법률적 결론이나 답을 생성하지 않습니다.
- **사용자 연결**: 선택한 핵심개념에만 매핑하며 '사용자가 확인한 학습 연결'이라는 출처를 유지합니다.
- **저장 장소**: 브라우저의 localStorage. 외부 서버로 문항/파일을 자동 업로드하지 않습니다.
