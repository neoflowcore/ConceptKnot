## 사용
`node scripts/p4-primary-evidence-v166.cjs --template > local-evidence-v166.json`
`node scripts/p4-primary-evidence-v166.cjs --evidence=local-evidence-v166.json --gate=publish`
`node --test tests/v166-primary-evidence-gate.test.cjs`

생성 원장은 최초 전부 UNREVIEWED. 사용자가 실제로 근거 문서의 첨부 PDF를 읽고 페이지 및 법령·판례 사건번호·시험 당시 효력일을 기록하기 전에는 임의로 검수 완료로 변환하지 않는다. 로컬 검독 원장에는 검수자의 식별 정보가 포함되므로 자동 업로드하지 않는다.

EXE/APK/ZIP 생성하지 않음. 자동배포는 vercel.json git.deploymentEnabled=false, Actions 워크플로 확인된 범위에 없음. 수동 배포하지 않음.
