# ConceptKnot 음성학습 TTS 전면 재설계 계획서 v1.0

기준일: 2026-11-08. 기준선: v135 / 4eb1e4c664ea26d27e7033360f7ff28c618f9375.
본 문서는 **개발 계획**이다. v136 변경은 메뉴 이름·순서이며, AI 모델 자체 호스팅이나 TTS 실음성 작동이 완성됐다는 뜻이 아니다.

## 1. 먼저 반영할 메뉴 변경

- '문제·정답' → **음성학습**
- '비교 도형과 차트' → **도형차트**
- 메뉴 배치: 오늘의 학습 → 핵심 이론 → 그림 연상 → 타이핑 → 기출 → 이론 → 모의고사 → 계산 집중 → 10개년 기출 → **도형차트 → 음성학습** → 오답 복습 → 학습 계획 → 정리본
- 내부 route ID (venn, listen)는 그대로 두어 저장 데이터·이동 코드를 지킨다. 모바일 페이지 이동, Ctrl 번호 KeyTips와 상단 메뉴 순서를 맞춘다.

## 2. 실패 원인 (현재 코드 기준)

1. 현행 neural-tts.mjs는 약 380 MB Supertonic 3 ONNX 자산을 Hugging Face의 외부 URL에서 로드한다. 기존 화면에는 'AI 여성 음성 준비' 버튼이 있으며, 엔진 ready가 되지 않으면 AI 음성 생성이 안 된다.
2. Web Speech API 경로는 speechSynthesis.getVoices()에서 한국어 보이스를 못 찾으면 아예 재생을 시작하지 않는다. OS에 실제 한국어 보이스가 없는 경우와 브라우저가 목록을 늦게 주는 경우를 나누어 처리해야 한다.
3. 재생 상태가 여러 제어 함수와 두 엔진 경로에 분산되어 있어서 실음성 시작 실패, 이어듣기, 일시정지에서 통합된 오류 복구가 어렵다.
4. **실제 기기에서 왜 재생이 멈추는지는 아직 확정 불가**: 외부 호스팅 실패, 네트워크, RAM, WASM 초기화, 기기 음성 부재, 사용자 제스처/재생 제한을 실기 로그로 구분한다.
5. 공식 문제·정답·특수정답/사용자 개인 메모/기출 해설은 재설계 대상이 아니다. 출처 검증을 별도 유지한다.

## 3. 목표 UX: 준비 버튼 없이 곧바로 재생

### 기본 경로: OS 한국어 음성 원클릭

- 사용자가 재생을 눌렀을 때 이미 OS에 등록된 한국어 보이스가 있으면, 별도 '여성 음성 준비' 버튼 없이 바로 읽는다.
- 기본 읽기 속도 1.5×, 선택은 0.75×/1×/1.25×/1.5×/1.75×/2×. 읽기 모드는 '정답만', '문제+정답', '문제+선지+정답 전체' 세 가지.
- getVoices()가 즉시 비어 있을 때 voiceschanged와 제한된 재시도/진단을 적용한다. 한국어 보이스가 없는 기기에 남성/외국어 보이스를 '여성 한국어'라고 표시하지 않는다.
- 브라우저 재생 권한·OS 볼륨·텍스트 길이 오류를 구분하고, 음성을 실제로 못 읽으면 완료 처리하지 않는다.

### 자체 제공 AI 여성 음성: Supertonic 3 ONNX 우선 PoC

- 모델 후보: Supertonic 3 (한국어 포함 31언어, ~99M parameters, ONNX, CPU/WASM 또는 가능한 브라우저에서 WebGPU). 현행 Supertonic 연동 경험을 재사용하되 다운로드와 플레이어는 새 구조로 교체한다.
- 모델 매니페스트에 버전/SHA-256/각 파일 크기/라이선스/원본을 고정한다. ONNX 4종, 텍스트 사전/설정, 선택한 여성 스타일 JSON, 런타임을 *자체 관리하는 동일 출처 정적 경로*로 제공해 외부 Hugging Face 요청에 종속되지 않게 한다.
- 모델 380 MB 규모는 GitHub 일반 객체 단일 100 MiB 제한을 초과할 수 있다. Git LFS + Vercel LFS 지원 여부·전송 비용 또는 별도 정적 스토리지의 안정성을 우선 비교한다. GitHub에는 매니페스트/코드/해시를 관리하고 바이너리는 재배포 권한을 확인한 방식으로 고정한다.
- Supertonic 3 샘플 코드는 MIT, 모델 가중치는 OpenRAIL-M. **가중치 재배포 전에 적용 라이선스의 사용 제한·고지 의무를 먼저 확인**한다. 공식 오픈소스 저장소는 2026-07-23 지원 종료/아카이브를 공지했으므로 원본과 모델 버전을 고정해 자체 테스트한다.
- Native TTS를 장애 시 fallback으로 남긴다. CPU 추론이 느리거나 메모리가 부족한 Android/AMD PC에서 CUDA를 강제하지 않는다. 필요 시 Worker로 추론하고 메모리를 해제한다.

### '준비 없이'의 정확한 의미

**새 기기에서 첫 방문 즉시 약 380 MB 고음질 AI 모델을 전송·초기화 없이 실행하는 것은 기술적으로 불가능하다.** 해결책은 첫 재생은 설치된 OS 음성으로 시도하고, 온라인·Wi‑Fi·저장 공간 여유가 있을 때 앱 사용을 방해하지 않는 방식으로 AI 모델을 자동 수신·캐시하며, 그 후에는 사용자가 준비 버튼을 누르지 않고 AI 음성이 바로 재생되도록 하는 것이다.

모바일 데이터 절약·저장 공간 부족·느린 기기에서는 무단 대량 다운로드를 하지 않는다. **OS 한국어 음성도 없고 모델도 미캐시인 최초 방문**은 정확히 그 이유를 안내하고 모델 1회 다운로드 경로를 제공한다. 어떤 방식에서도 오프라인 모델 파일 수신 실패가 핵심 800문항, 타이핑, 개인 필기, 기본 서비스워커 설치를 막지 않게 한다.

## 4. 구현 모듈과 데이터 원칙

- CKVoiceController 단일 상태: idle → probing → ready → speaking → paused → ended / recoverable-error. 중복 onend/onerror 이벤트, 중복 클릭, 탭 이탈, 중지 토큰을 하나의 엔진 인터페이스로 통합.
- SpeechSource: 공식 RECALL_OFFICIAL 자료만 공식 기출 음성으로 낭독. 개인 OCR·메모로 공식 최종정답·선지 원문을 바꿀 수 없음.
- SpeechSegments: 세 가지 읽기 모드, 문항 번호·세그먼트 번호·문구를 함께 보관. 전원정답(8건)과 복수정답(3건)을 구분; 긴 문장, 계산식, 법률용어 발음 보정은 공식 원문과 출력 변환을 분리.
- NativeAdapter: 비동기 OS voice 목록 수신 및 사용자 제스처에서 재생, 중단/이어듣기.
- LocalModelAdapter: 해시 검사, 자체 호스팅 ONNX, WASM fallback, 선택 여성 음색, 사용자 동의 정책·기기 자원 예산을 고려한 캐싱.
- AudioQueue: 읽기 중 중단/재개/1.5×/연속재생/책갈피를 양쪽 엔진에 공통 적용. 누락된 세그먼트를 읽은 척 완료할 수 없음.
- OfflineStore: 기본 PWA 필수 설치 캐시에서 380MB 모델을 분리. 모델 캐시 완전성 별도 점검. 데이터 삭제나 무단 초기화 불가.
- UI: 상단은 음성학습. 재생·일시정지·중지·이어듣기·모드·배속·과목/연도를 전면 배치. 기존 'AI 여성 음성 준비' 버튼 폐기. 별도 '고음질 음성 상태'는 작은 영역/접이식 안내로만 표시.

## 5. 실행 순서 및 종료 기준

| 단계 | 내용 | 완료 조건 |
|---|---|---|
| M0 (즉시) | 메뉴 이름 변경·도형차트 우측으로 이동·KeyTips/모바일 순서 동기화 | 상단·모바일·키보드 순서 일치, 학습 데이터 유지 |
| T1 (최우선) | Native 한국어 음성 원클릭, OS voice 비동기 처리, 실패 원인 진단 | Windows·Android Brave에서 실음성 재생, 없을 때 이유 명시 |
| T2 (최우선) | 기존 TTS 상태 제어 제거 후 단일 큐·3모드·1.5×·북마크 | 누락·중복 없이 30문항 연속재생; 정지·이어서·탭 이동 정상 |
| T3 (상) | Supertonic 3 자체 호스팅 PoC, 라이선스/모델 배포 경로 확정 | 실기 여성 음색 확인, 다운로드 크기·초기화 시간·RAM 기록 |
| T4 (상) | 캐시 후 원클릭 AI 자동전환, 미캐시 Native fallback | 재방문·오프라인에서 준비 버튼 없이 재생, 기록 손상 0 |
| T5 (상) | Android Brave/Windows Brave·Edge 실기검증 | 1.5×·모드별 800문항·오류/중단/오프라인 PASS 증거 |
| T6 (중) | 공인중개사 용어·법조문/숫자 읽기 정규화 | 검증된 발음 표와 원문 불변 처리 |

성능 목표: 캐시된 OS 음성 재생은 가능하면 버튼 후 1초 이내. 로컬 AI 첫 소리는 **실제 기기에서 먼저 측정한 뒤 목표 설정**; 최초 380MB 다운로드가 0초라고 약속하지 않는다.

## 6. 실제 기기 인수검증표

1. Windows Brave, Edge / Android Brave: 첫 클릭 시 실제 소리, 한국어 여성 음색 확인 또는 음성 선택 불가 안내.
2. 모델 미캐시·Wi‑Fi 해제·모바일 데이터·저장 부족·Android 화면 잠금 → 기존 개인 학습 데이터/칠판/PDF 필기 안전.
3. 모델 캐시 완료 후 새로고침과 오프라인 재접속: 별도 '준비' 클릭 없이 재생.
4. 정답만 / 문제+정답 / 전체 세 모드: 2016~2025 공식 출처, 특수정답, 법률용어·수식에서 누락·반복 없는지 실청취.
5. 1.5×, 100문항 이상 자동 이어듣기, 중지·재개·다른 탭 이동, 음성 실패 복구 시 실제 세그먼트/자막 번호 일치.
6. 모델 추론 시 메모리·GPU 사용량, 애니메이션 중지 규칙, 타이핑 IME·S Pen 간섭 없음.
7. 실기 전에는 TTS 완료율 100%나 여성 음성 PASS로 표기 금지. Actions 0회, APK/EXE/ZIP 생성 금지.

## 7. 다른 잔여 개발 우선순위

1. **T1/T2: 지금 소리가 나지 않는 음성학습 기본 경로부터 복구** → T3/T4 모델 자체 호스팅.
2. **P4: 368건 해설 초안 추가 + 400문항 × 5선지 = 2,000개 근거 감수**. 초안과 공식 검수 완료를 구분하고 원문/법령 근거 검증.
3. **P5: 800문항 빈출 분석·개인 오답 통계 검증**. 정답 인정과 선지 사실 여부를 혼동하지 않음.
4. **P6: 검색·17차트·타이핑·S Pen 모바일 기기 안정화**.
5. **P7: 모든 기능을 묶어 실기 검증 후 운영 배포**. 일반 Push로 자동 배포·자동 Actions를 켜지 않음.
