# ConceptKnot v134 · 모의고사·10개년 기출 단축키 통일

기준: 2026-11-07. 기준 GitHub `main` v133 `1bd018575936200e093ce1c9ff9262a1b48556e7`.

## 목적

사용자가 모의고사(기본 연습·기출 응용 5세트), 기출혼합 5세트, 공식 통합 실전 연도별 80문항, 별도 10개년 기출 탭에서 **동일한 키보드 동작**으로 공부하도록 한다. 기존 UI(문제 왼쪽·OMR 오른쪽), 각 엔진 답안저장, 공식 인정 정답, 100분 제한시간, 타이핑 단축키는 변경하지 않는다.

## 단축키

| 화면 | 숫자 1~5 | Ctrl+← / Ctrl+→ |
|---|---|---|
| 모의고사 기본 15문항/응용 1~5세트(CK20) | 표시된 현재 문제의 기존 선지 선택 버튼 실행 | 기존 이전/다음 버튼 실행(최초/마지막 경계 유지) |
| 10개년 공식 기출혼합 1~5세트(CK129) | **진행 중이고 시험판이 열린 때만** 기존 `answer(n)` 호출 | 실행/일시정지 중 현재 위치의 `goto(position±1)` 호출, 1~80번 경계 유지 |
| 공식 통합 실전 2016~2025년(CK82) | 진행 중 시험판에서만 기존 `setAnswer(n)` 호출 | 기존 `navigate(position±1)`, 1~80번 경계 유지 |
| 별도 10개년 기출 탭의 연도별 A형 OMR | 기존 `data-exam-mark` 클릭. **즉시 채점 OFF면 기존처럼 자동 다음 문제** | 기존 `exam-prev`/`exam-next` 실행, 선택 과목 내 40문항 경계 유지 |

- 키보드 상단 숫자와 NumPad 숫자(브라우저가 동일한 `event.key`로 전달한 경우) 1~5를 지원한다.
- CK82·CK129에서 이미 동작하던 시험판 내부 숫자키·일반 방향키는 그대로 유지한다. 기존 전역 10개년 기출 일반 방향키도 유지하고 **Ctrl 조합을 추가**한다.
- 시험판 이외의 모의고사 **선택 버튼에 포커스해도** 실행 중인 실전의 선택·이동이 가능하다. 현재 선택한 분류만 호출하며 숨겨진 다른 엔진의 답안은 변경하지 않는다.
- **시험 일시정지·제출·미시작 시에는 새 숫자 답안을 입력하지 않는다.** 일시정지 중에는 문항 탐색만 가능, 제출 이후에는 원본 채점을 변경하지 않는다.
- 키 입력을 통한 자동 새 시험 시작·제출·정답 공개·타이머 초기화는 수행하지 않는다.

## 충돌·데이터 보호

- **텍스트 입력창(`input`, `textarea`, `select`), PDF/S Pen 필기 영역, 편집 가능 문단, 대화창·모달 포커스**에서 키보드 조작을 가로채지 않는다.
- 한글 IME 조합(`isComposing`, `keyCode 229`), 키 길게 누르기 자동반복, Alt/Meta/Shift 조합은 무시한다. `Ctrl+←/→`만 시험 이동에 사용하고 Ctrl+숫자는 기존 브라우저·기능 단축키로 남긴다.
- 기존 타이핑 탭의 **Ctrl+←/→** 핸들러와 계산·이론·오답노트 단축키는 수정하지 않았다.
- CK82·CK129의 `getState()`에는 **읽기 전용 현재 `position`**만 추가한다. `localStorage` 저장 객체의 스키마나 사용자 답안·이력 데이터는 수정하지 않는다.
- `ck133-exam-mode-v1`, `ck133-practice-clock-v1` 같은 기존 세션 선택·타이머 키도 유지한다.

## 변경 파일·오프라인

- `index.html` 통합 키보드 이벤트 처리, 선택 유형별 엔진 분기, 인라인 안내문 추가.
- `assets/ck-full-exam-v82.js` 및 `assets/ck-mixed-mock-v129.js`: 읽기 전용 `position` API 추가.
- `assets/ck-exam-hub-v133.js`: 3대분류 카드 아래 단축키 도움말 추가.
- 변경 JS 및 진단 모듈만 `?v=134`로 갱신. `sw.js` 서비스워커 세대 `conceptknot-study-v134-exam-keyboard`. 오프라인 최소 자산은 기존 11개 그대로, 혼합·복습·허브 자산도 유지한다.
- `tests/v134-exam-keyboard.test.cjs`에 단축키 방향/숫자·경계·IME·편집창·일시정지·제출·화면 충돌 검사를 추가. 기존 캐시 버전 의존 테스트 정렬.
- 자동 Actions 및 일반 Push 자동배포 금지 유지. 설치 EXE/APK/ZIP 생성 없음.

## 수기 실기검증 (모든 결과 사용자 확인 전에는 PASS 처리 금지)

1. **먼저** 현재 통합 학습 JSON, 공식 통합 CK82 시험 기록, 혼합 CK129 시험 기록 JSON, S Pen PDF 필기/개인 풀이·OCR 자료 각각 백업하고 다운로드 파일이 열리는지 확인한다. 사이트 데이터·localStorage·세션 기록을 지우지 않는다.
2. 모의고사 탭 → **모의고사** → 기본 연습과 1~5세트에서 `1`, `3`, `5` 선택 후 실제 선지 표시와 오답노트/기존 기록 상태 비교. `Ctrl+← / Ctrl+→`로 첫·중간·마지막 경계를 확인한다.
3. 같은 탭 → **기출혼합** 2세트 새 시험 시작 → 선택기를 포함한 시험판 어디에서든 `1~5`로 현재 문항 답안을 바꾼 뒤 OMR 및 새로고침 복원을 확인한다. `Ctrl+←/→`가 1~80번에서만 이동하는지 확인한다.
4. **공식 통합 실전** 2020년 선택 → 80문항 시험에서 `1~5`와 `Ctrl+←/→` 작동 및 시간 진행·정지·재개, 제출 후 잘못된 답안 재입력 차단을 확인한다.
5. 별도 **10개년 기출** 탭 → 2021년·2025년, 학개론 1~40·민법 41~80 각 과목에서 숫자 선택, Ctrl 방향 이동, 기존 일반 방향키 이동, 과목 경계를 확인한다.
6. 브라우저 입력창·검색창·설정 모달·개인 풀이 메모·PDF 손글씨에 포커스를 둔 채 같은 키를 눌러 **문항 이동이나 답안 변경이 없어야 PASS**.
7. 타이핑 탭 Ctrl 방향키는 이전대로 동작해야 하며, 모의고사 100분 타이머와 공식 실전 100분 카운트다운이 새로 초기화되지 않아야 한다.
8. 설정에서 현재 서비스워커 `v134`·필수 캐시 11/11·혼합 2/2·복습 2/2·선택 UI 2/2, Windows/Android Brave에서 키보드·하드웨어 보조키 및 S Pen 이상 여부 확인.
9. 소스 환경에서는 수동 `node --test tests/v134-exam-keyboard.test.cjs` 와 `node scripts/check-release-readonly.cjs` 실행. 자동 CI는 돌리지 않는다.

## 완료율

마지막 확정된 운영 검증 기준선 전체 **19/30 ≈ 63%**, P0~P2 각 80%, P3 60%, P4~P5 40%는 과거 수치이고, v134의 실물 기기 검증률이나 디자인 초안 일치율을 새로 측정한 숫자가 아니다.
