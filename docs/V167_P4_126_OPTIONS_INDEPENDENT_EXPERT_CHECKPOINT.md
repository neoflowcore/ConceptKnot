## 3. 독립 전문가 서명·실제 검독 게이트

- 기존 `scripts/p4-evidence-gate-v166.cjs`의 원장 `baseline()`/`validate()`를 모듈에서 재사용 가능하게 수정(기존 `--init`, `--check`, `--self-test` CLI 유지).
- 신규 `scripts/p4-independent-expert-v167.cjs`:
  1. 400문항·2,000선지의 원문 해시 및 원전근거 입력을 v166으로 먼저 검증.
  2. 독립 검토자 등록부는 프로젝트 **외부의 신뢰할 수 있는 검증 주체**가 자격·신원·독립성 실사 후 Ed25519로 서명한 것만 수용. 검증 주체 공개키는 `CK_P4_TRUSTED_REVIEW_AUTHORITY_PUBLIC_KEY` 환경변수로 별도 공급. 키가 없거나 등록부 서명 검증에 실패하면 검수 승격 차단.
  3. 전문가별 등록 공개키가 실제 선지의 원전 증거·진위판정·해설·작성자 식별자·서명일을 묶어 디지털 서명했는지 확인. 작성자와 동일 ID 또는 등록 전문가 불일치, 서명 후 본문 변조, 이해충돌 확인 누락, 원전 독립 검독 선언 누락 시 차단.
  4. 5개 선지 전체의 독립 전문가 서명이 유효하고 별도 문항 승인 기록이 있는 경우에만 `expertApprovedQuestions` 증가.
  5. `officialCertifiedQuestions=0` 유지: 프로젝트 내 전문가 승인 ≠ Q-Net·정부 기관 공인 해설 인증.
- 원장 파일, 전문가 개인정보, **개인키**는 Git에 자동 저장하지 않음. 테스트는 임시 테스트 키만 생성; 실제 전문 감수 및 실명 검증은 별도 인간 절차 필요.
- **주의**: 인증된 공개키 서명의 무결성과 형식 검사는 법리적 타당성·원전 URL의 실제 내용·자격증의 진본성 확인 자체를 대체하지 못한다. 사람의 전문검토 없이 `verified`/공식 게시로 표시 금지.
