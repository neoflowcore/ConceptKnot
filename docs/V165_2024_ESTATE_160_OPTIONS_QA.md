- Q-Net [2024 제35회 시험문제지 게시글](https://www.q-net.or.kr/cst003.do?artlSeq=5214724&boardId=Q004&gId=08&gSite=L&id=cst00302&menuType=cst00309)과 [별도 최종정답 게시글](https://www.q-net.or.kr/cst003.do?artlSeq=5218527&boardId=Q004&gId=08&gSite=L&id=cst00302&menuType=cst00310)은 확인 가능한 1차 공고 링크다. **공고 열람은 첨부 ZIP·PDF 각 페이지 직접 검독의 증거가 아니다.**

- 법령형·판례형 해설은 **시험 당시 효력 법령·판례 사건번호/판시 문장·원본 쪽수 미확인**. `expertVerdict=unreviewed`, `sourcePdfRead=false`, `signedOff=false` 고정. 공식기관이 작성한 해설로 표시하지 않는다.
- 조합형·복수정답의 '채점 인정'과 선지 각각의 진위는 구분한다. 2024년 민법 67번처럼 전원정답 인정은 ①~⑤의 진위가 모두 참이라는 뜻이 아니다.
