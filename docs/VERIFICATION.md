# 실기 검증 안내 (Chrome/Edge, Android Chrome)

> 이 문서는 안내서이며, GitHub Actions나 설치파일 빌드를 실행하는 문서가 아닙니다.

## 실행

GitHub 저장소의 최신 `index.html`을 내려받고 데스크톱 Chrome/Edge로 엽니다. 다른 JS 파일을 반드시 다운로드할 필요 없이 **HTML 하나로 실행**됩니다. 모바일에서는 나중에 별도 정적 호스팅된 URL 또는 안전하게 옮긴 HTML로 접속해 사용합니다.

## 10~15분 최소 실기

1. **대시보드**: 두 과목 선택, '기출에서 이론 뽑기'로 진입.
2. **첫 문제**: 1번을 일부러 틀리게 고름. 정답 공개와 5개 선지의 이유 확인.
3. **회상**: '핵심만 가리고 외우기' → 소리 내어 설명 → 정답 공개 → '기억 안 남'. 복습 일정 확인.
4. **전이**: 같은 규칙에 대한 새로운 상황의 문제를 푼 뒤 최초 문제를 재도전. '첫 시도 오답 → 재도전 정답' 기록 확인.
5. **공식 기출**: 공식 기출 연결 탭에서 2025년 1번 원문 PDF를 열고 수동 마킹. OMR에서도 동일 선택이 나오는지 확인.
6. **TXT**: OCR된 예제 TXT에서 `1. ...` / `2. ...` 입력 및 미리보기. 현재 과목 번호만 인식하는지 확인. 자동 OCR이 아님을 확인.
7. **링크**: 학습용 지문에 나오는 키워드로 개념 후보 찾기 → 실제 원문 확인 후 수동 연결. 10개년 연결 카운트 증가 확인.
8. **기록 보존**: 새로고침 후 기록 확인. 내 데이터에서 JSON 백업(사용자 요청 시) 및 복원 기능 확인.
9. **모바일**: 두 과목 전환, 설명카드, 전이/OMR 버튼이 화면 밖으로 가려지지 않는지 확인.

## 주의

- 내장 2020~2025 정답은 시험당일 A형·최종정답/복수정답 기준과 검증해야 합니다. 2016~2019년은 필요하면 정답을 직접 등록합니다.
- Q-Net PDF 원문 외부 링크는 인터넷이 필요하고 브라우저 iframe 정책에 따라 미리보기가 막힐 수 있습니다.
- 브라우저 로컬 저장은 컴퓨터·프로필이 다르면 공유되지 않습니다. 시크릿 모드/브라우저 데이터 삭제에 주의하세요.
- 법령·판례는 시험 기준일에 맞춰 재확인하세요.
