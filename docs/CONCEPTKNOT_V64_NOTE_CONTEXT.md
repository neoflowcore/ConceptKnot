# ConceptKnot v64 — 칠판 선택 텍스트 우클릭 편집

- 칠판 글자를 드래그로 선택하고 우클릭하면 자체 글라스 팝업: B(선택 영역), 복사, 붙여넣기, 글자 색상(분필 팔레트 및 사용자 선택).
- 기존 전체 B 토글과 구분: 우클릭 B는 선택 글자만 잉크 획 두께로 강조하므로 편집 커서/줄바꿈 폭을 바꾸지 않음.
- 선택 영역 서식은 기존 노트 레코드의 ck64BoldChars, ck64ColorHex 배열에 저장하고 입력 변경 시 chalkReconcile로 위치 동기화.
- 일반 문서/타이핑/S펜 사용에는 우클릭 가로채기를 적용하지 않음. 클립보드 권한 제한 시 Ctrl+C/Ctrl+V 대안 안내.
- 자동 Actions 및 Git 자동 배포는 비활성 유지. 운영 수동 단일 배포.
