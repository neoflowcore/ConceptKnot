- **2022년 12번**은 정답 ③에 대응하는 정보가치 계산식의 독립 일치 증거가 아직 부족해 이번 초안 작성에서 **5개 선지 전부 보류**했다. 정답을 보고 계산의 근거를 꾸미지 않는다.
