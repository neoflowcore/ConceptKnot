# ConceptKnot v62 · 타이핑 위치 일치 및 진행률/글라스 개선
작성: 2026-10-31

## 변경 사항
1. 기본 **일반 입력**은 textarea의 실제 커서와 편집 동작(Enter, Space, Backspace, 방향키, IME, 붙여넣기)을 그대로 사용한다.
2. 원문과 입력 텍스트를 같은 그리드 영역의 별도 요소로 그리며, 문자/커서의 글꼴·크기·굵기·줄 높이·자간·줄바꿈·여백을 일치시킨다. 원문의 줄바꿈은 입력이 달라져도 그대로 보존한다.
3. **문자만** 모드는 원문의 글자/숫자 위치에 실제 입력 글자를 올려 표시한다. Enter와 Space는 진행하지 않으며 Backspace로 수정하면 진행률이 되돌아간다.
4. 입력창 바로 위에 문단 전체 진행률 **슬라이더형 표시 바**를 두고, 현재 입력 개수/전체 개수 및 퍼센트를 표시한다. 정답과 일치하는 개수는 정확도와 분리한다.
5. 화면 상단 우측의 **일반 입력 / 문자만** 토글과 각 모드별 초안 분리 보관을 유지한다.
6. 커서가 있는 **현재 줄**에 은은한 배경과 얇은 왼쪽 강조선을 추가한다. 줄 인식은 실제 입력 커서(일반 입력) 또는 원문 위치(문자만)에 따라 갱신한다.
7. 오타 색상을 밝은 모드의 차분한 회갈색, 다크모드의 낮은 채도 분홍회색으로 변경한다. 형광색 오타 배경은 제거한다.
8. 밝은 모드는 밝은 우윳빛 글라스, 어두운 모드는 반투명 짙은 글라스로 표현한다. 브라우저 자동 다크모드가 아니라 사이트의 data-ck-theme 설정을 따르며 모바일도 같은 테마를 적용한다.

## 검증
- 일반/문자만 입력 처리, 공백/줄바꿈, Backspace, 정답 카운트와 입력 진행률 분리, 테마 CSS, 현재 줄 강조, DOM 고정, 스크립트 파싱을 검사한다.
- GitHub Actions 및 자동 Vercel Git 배포는 꺼진 상태로 유지한다. 사용자 승인 시 수동 단일 운영 배포를 시행한다.
- 서체 조합과 한국어 IME를 포함한 실제 브라우저 편집 동작은 실기 사용 시 추가 확인한다.
