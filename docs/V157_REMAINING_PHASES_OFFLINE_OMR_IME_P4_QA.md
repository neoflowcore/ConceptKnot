## v157에서 실제 구현한 기능

### P0 오프라인

- \`sw.js\` 캐시 세대 \`conceptknot-study-v157-resume-offline-omr-ime\`으로 갱신.
- 필수 코어 11개가 HTTP 200으로 등록되어도 JS/CSS/JSON 대신 HTML 오류 페이지면 새 서비스워커 승격 차단.
- 기존 세대의 정상적인 선택 자산은 새 캐시 선택 다운로드 실패시 이전 파일을 보존하는 v155 규칙 유지.
- 오프라인 자가진단은 현재 탭을 **실제로 제어하는 SW 세대**와 캐시 11개를 구별한다. 추가로 칠판·IME·그래프 관련 **선택 자산 6개** 확보 여부를 따로 표시.
- 오프라인 자산 체크 PASS ≠ 실제 Android 비행기 모드/실사용 PASS. 사용자 기기 수기 검증 전까지 NOT_RUN.

### P2 한글 타이핑·모바일 칠판

- IME 종료 뒤 네이티브 \`input\` 이벤트가 먼저 왔어도 **그 이벤트 당시 값**과 후속 확정 값을 비교. 마지막 글자가 조용히 추가됐다면 기존 타이핑 엔진의 \`input\` 경로를 1번 보완한다.
- 최종 입력이 정상 반영되거나 새 조합이 시작된 경우 합성 이벤트는 발송하지 않는다.
- 칠판 높이 조절에서 두 번째 손가락, 손바닥 접촉, 비주 포인터는 원래 드래그를 가로채지 못함.
- \`pointercancel\`, \`lostpointercapture\`, 창 포커스 해제, 페이지 숨김 시 아직 저장하지 않은 높이 변화를 롤백하고 펜 드로잉 CSS 상태 정리. 높이 조절 중 전역 body 잠금 클래스를 매 프레임 변경하지 않음.
- 기존 메모 텍스트·그림·PDF 주석 저장 키는 수정하지 않음.

### P3/P5 공식 실전·혼합 모의고사

- 공식 80문항 실전에 **원본 JSON 백업** 및 **비파괴 병합 복원** 버튼 추가. 기존 미제출 답안과 보류 체크는 우선 보호.
- 복원 전후 같은 탭의 저장 값이 다른 탭에서 변경되면 CAS 검증으로 자동 취소.
- 제출 이력 20건 한도 초과시 예전 이력 삭제 없이 복원 거부.
- 같은 응시 ID의 제출 이력이 완전히 같으면 중복 제거, **응시 ID가 같으나 답안이 다르면 충돌 오류**.
- JSON 손상·지원하지 않는 스키마·용량 500KB 초과·다른 탭 변경은 전체 롤백(원본 유지). 제출 성적을 임의 재계산하거나 공식 정답을 바꾸지 않음.
- 기존 공식 80문항 100분 시험, 숫자키·Ctrl+방향키, 과락/미응답/특수 정답, 혼합 5세트 로직 유지.

## **실물 수기 검증 안내 — PASS 자동 판정 금지**

1. **P0 Android Brave:** 온라인에서 앱을 열어 학습용 자산이 캐시된 상태로 준비한다. 오프라인 진단에서 필수 11/11과 보조 6/6을 **각각** 확인한다. 비행기 모드 → 탭 새로고침 → 2016~2025년 기출/칠판/그래프 열기 → 온라인 복귀/재진입을 시험한다. 검증 도중 브라우저 저장 데이터 초기화 금지.
2. **P2 한글:** ㄱ→가→각→강, 조합 중 커서 이동·뒤로 지우기·선택 영역 교체 후 문자열/커서/타수·정확도가 일치하는지 확인한다. 두 개 손가락/S Pen을 동시에 칠판 크기 손잡이에 올린 뒤 포인터 취소하면 이전 높이가 유지돼야 한다.
3. **P3 공식 80문항:** 답 1~5, Ctrl+좌우, 100분 시계, 학개론/민법 분리 채점을 확인한다. 20번에 답·보류를 남기고 원본 JSON 백업 → 다른 시험 제출 → 병합 복원하여 진행 답안과 이력이 사라지지 않는지 확인한다. 두 브라우저 탭에서 동일 응시 진행 중 겹치는 저장 시 오류 안내 후 기존 답안 보호를 확인한다.
4. **P5 혼합 5세트:** 80문항×5세트(400문항, 중복 없음), 보류/오답/특수정답/복습/JSON 병합을 검증한다. 공식 기출 원문과 정답표는 수정하지 않는다.
5. **P6 시장형 8종:** D/S 가운데 손잡이 좌우 드래그는 **평행이동**, 오른쪽 노란 손잡이 상하 이동은 **기울기** 조절이어야 한다. 도식 E₀/E₁·가격/수량 변화 방향·Undo/Redo를 확인한다. 빈 SVG는 세로 스크롤되고 손잡이 드래그 중 화면이 이동하지 않아야 한다.
6. **P6 관찰형 9종:** PV·환원율·입찰지대·거미집모형·저량/유량·탄력성·허프 등에서 실제 시장균형 도식이 아닌 경우 가짜 가격 결론이 나오지 않아야 한다. 쉬운 설명/심화/기출 함정에서 사용자 변경 조건과 원문 출제 조건이 구분되는지 확인한다.
7. **P4 전문가 검수:** 검수용 CSV에서 정답 특례를 우선 확인하고 시험 시행시점 법령/판례·선지마다 ①~⑤ 근거를 적는다. 사람이 원전과 대조하기 전에는 \`sourceChecked\`·\`published\`로 올리지 않는다.

검증자가 각 항목을 직접 PASS/FAIL/미확인으로 입력해 저장할 수 있지만, 본 개발 작업은 실제 기기 검사 결과를 생성하거나 조작하지 않는다.
