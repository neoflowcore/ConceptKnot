# ConceptKnot v120 · OCR 페이지별 초안 보관함 및 안전한 학습기록 백업

**기준선:** `main` v119 `0a55bf8f2a88f35ec920e75162692ddd20f1ba4d` (2026-11-04). 자동 GitHub Actions, 일반 push에 따른 Vercel 자동배포, EXE/APK/ZIP 설치 아티팩트 생성 금지. GitHub 코드 변경은 승인됨.

> 이 문서는 구현 범위와 **사용자 직접 수기 실기검증 절차**이다. 저장소 코드 검사 통과와 Android Brave/S Pen 실기 PASS는 다르다. OCR 후보는 개인 초안이며 공식 800문항·원문·정답·해설·검수 플래그를 수정하지 않는다.

## 새 기능

- 기존 v118 OCR 단일 편집 초안을 유지하면서 `ck120-ocr-page-drafts-v1` 로컬 페이지 보관함 추가. 최대 **90페이지 기록**, 개별 텍스트 최대 **45,000자**, 전체 페이지 내용 약 **150만 문자**로 제한. 실제 로컬 저장 용량에는 브라우저별 한계가 있으므로 저장 실패를 감지하고 원본 자료를 유지한다.
- 각 항목에 고유 ID, 사용자 OCR 검토 초안, 저장 시각, **원문 출처 문자열**, PDF 출처일 경우 당시 **내용지문 기반 PDF 식별 키**를 저장한다. 다른 PDF의 기존 초안 불러오기 후 재보관해도 **원래 식별 키를 새 파일 키로 바꾸지 않는다**.
- `이 페이지 초안 보관`, `불러오기`, `확인 후 삭제`, `전체 TXT`, `다른 탭 변경 다시 불러오기`, `보관함 원본 JSON 백업` 제공. 삭제와 현재 편집 텍스트 교체에는 명시적 사용자 확인. **자동 오래된 페이지 삭제·원문/정답 자동 반영 없음**.
- 형식 검사: 스키마 버전, 정상 ID·중복 ID 금지, 문자 수·페이지 수·원본 키 길이·저장 시각·총 크기를 검사. 손상된 기록은 기존 원본을 덮어쓰지 않고 사용자가 JSON을 별도 보존할 수 있다. 다른 브라우저 탭의 변경을 감지하면 자동 덮어쓰기를 중단한다.
- **전체 학습 JSON 내보내기·복원과 연결:** `ck120-ocr-page-drafts-v1` 키를 `CK79Study` 백업 범위 및 `CK86Integrity`의 제한·검증 메서드에 추가. 백업에 존재하는 손상된 페이지 기록은 검증 실패로 처리해 다른 개인 기록까지 조용히 덮어쓰지 않는다.
- 기존 `ck118-personal-ocr-draft-v1` 단일 초안과 `ck115-manual-device-verification-v1` 수기 PASS/FAIL 저장 스키마는 변경하지 않음. 수기검증표에 **2항목**을 추가해 총 **21항목**.
- HTML·서비스워커의 OCR 스크립트·스타일·백업검사기·수기검증표 자산 버전 동기화(`?v=120`) 및 캐시 키 `conceptknot-study-v120-ocr-page-queue`.

## 🚨 직접 수기 실기검증 — v120 수동 배포 이후

1. **검증 전 백업:** 개인 학습기록 전체 JSON 내려받기, PDF 필기를 이미 했다면 PDF별 필기 JSON과 필기 PDF를 **별도로 저장**. 파일이 실제 존재하는지 파일 관리자에서 확인. 사용자 브라우저 기록 초기화 금지.
2. **버전 확인:** 운영 배포가 v120 커밋으로 변경됐는지 확인한 경우에만 진행. 운영 사이트가 아직 v115라면 아래 버튼이 보이지 않는 것은 정상이며 v120 PASS로 기록 금지.
3. **페이지별 누적:** PDF 2025년 1쪽 OCR → 원본과 오타 비교 후 직접 수정 → `이 페이지 초안 보관`; 2쪽도 반복. 보관함이 2건인지 확인하고 각각 불러왔을 때 출처와 텍스트가 보존되는지 검증.
4. **문서 식별키:** 파일명·크기가 같아도 내용이 다른 사용자 PDF 2개를 열고 별도 OCR 페이지 보관. 먼저 저장한 초안을 나중 PDF에서 불러와도 해당 항목의 원본 문서 식별키가 바뀌지 않는지 확인.
5. **삭제 보호:** 페이지별 항목 삭제 → 취소하면 그대로 남고, 확인하면 선택 항목만 삭제. 삭제 전 TXT/전체 JSON 백업을 권장.
6. **전체 학습 JSON 복원:** 페이지별 초안이 2건 이상인 상태로 `내 학습 데이터 JSON` 다운로드 → **격리된 테스트 브라우저 프로필**에서 복원 → 보관함 기록과 기존 80문항 시험/오답 기록이 유지되는지 확인. PDF 필기 JSON은 별도여서 자동 복원되지 않음.
7. **다중 탭 충돌:** 같은 보관함을 두 탭에 열고 A에서 페이지 보관, B에서 오래된 상태로 새 페이지 보관 시 B가 덮어쓰기를 차단하고 경고해야 한다. B에서 `다른 탭 변경 다시 불러오기`로 최신 자료 반영 확인.
8. **용량 초과:** 기존 프로필 데이터를 무작정 채우지 말 것. 격리된 테스트 프로필에서 90건 도달 및 큰 페이지(45,000자 초과) 처리 시 원본 자료를 잃지 않고 저장 차단·TXT 안내가 표시되는지 확인.
9. **OCR·터치·성능 회귀:** Android Brave에서 한국어/영어 OCR, PDF 양쪽 페이지, S Pen 지우개·손 터치 복귀, OCR 중단·모바일 화면 잠금 후 worker 종료, 다크모드·설정 메뉴 고정·TTS 1.5배속·시험 80문항/100분 확인.
10. **수기검증표:** 설정에서 21항목 각각 PASS/FAIL/미확인으로 표시, PDF 연도·페이지·이미지 해상도·브라우저·재현 순서를 적어 TXT로 저장. 코드 테스트 PASS를 기기 PASS로 자동 승격하지 않는다.
