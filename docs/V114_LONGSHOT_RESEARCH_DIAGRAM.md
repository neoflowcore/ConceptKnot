## v114 구현 범위

### A. 선지 근거 대기열(기존 CK111)

1. 10개년/5선지의 연도·번호·문제·보기 검색 (대소문자/NFKC 정규화). 한국어 IME 조합 중 재렌더하지 않는 180ms 검색 지연 처리.
2. 검토 우선순위 / 최신순 / 과거순 / 개인 출처 누락순 정렬.
3. 문항 선택 체크박스(최대 5개). ①~⑤ 각각의 CK83 개인 판단·이유·출처와 CK80 개인 해설 초안 판단·이유·출처를 구분한 TXT 검토 묶음 수동 저장. 출처 기록이 공식 검증으로 승격되지 않도록 경고 문구 포함.
4. 조건 필터·선택 항목을 변경해도 기존 공식 문제/정답과 개인 기록은 변경하지 않음. 원본 PDF 링크(등록된 HTTPS URL에 한함) 별도 표시. 기존 800문항/4,000선지 및 필터별 CSV 유지.

### B. 개인 입력 소실 방지(CK78/80/83)

1. 기출 분석 모달의 '내 풀이·오답 원인' 메모는 입력 후 900ms 자동 저장, 초점 해제·문항 전환·종료 시 저장 시도. 저장 실패 때 메시지를 표시하고 이동을 차단.
2. CK78Study 내장 `saveNote`가 localStorage 저장 실패 시 메모리의 이전 메모를 복원(새 기록이면 원복 삭제). 성공하지 않은 쓰기를 보존 완료처럼 보고하지 않음.
3. CK80 개인 해설 편집기, CK83 개념 연결 편집기의 프로그램 코드 이동·모달 닫기·다른 탭·Escape와 미저장 확인 연결. 다른 메모 저장 실패보다 미저장 해설 폐기 경고가 먼저 처리되지 않도록 순서 관리.
4. CK83 로딩/자료 복원 중 임의 재렌더 시 미저장 입력 DOM 보존. 2016~2020 비동기 로딩 완료가 새 문항을 덮어쓰지 않도록 요청 토큰 사용.
5. 기출 문항으로 직접 이동 시 학습 상태 저장 실패하면 이전 연도·과목·문항 선택으로 복귀.

### C. 음성 대기열 데이터 경계

1. 복습 대기열 TTS가 원문 미로딩 문항을 발견하면 일부만 읽지 않고 정지, `incomplete-due` 오류 보고.
2. 읽을 복습 문항이 없는 경우 이전 소리를 정지하고 명시적 상태 표시.
3. 한국어 TTS 엔진·AI 여성 F1~F5·1.5배속·세 모드·백그라운드 실제 소리는 **브라우저/갤럭시 실기 대기**.

### D. 경제 차트 균형점 시각화

1. `ck-charts-v21.js`의 수요/공급 직선에 실제 일치하는 교점 E₀/E₁ 기하 좌표를 계산.
2. 수요↑/↓, 공급↑/↓, 동시 이동 그래프에서 균형점의 이동 방향과 가격·수량의 예시 결과 제공(해당 8개 차트).
3. 수요·공급 동시 증가(같은 폭)의 **예시에서만 균형가격 불변**을 표시. 일반적인 실제 문제에서 균형가격 방향은 불확정임을 별도로 설명.
4. SVG/CSS 전환은 학습자가 누를 때만 일회 실행. WebGL/타이머/상시 rAF를 추가하지 않음. 움직임 감소 설정은 즉시 적용.

## ⭐ 필수 수기 실기검증 (수정사항 동작 확인 전 PASS 금지)

1. 먼저 `내 데이터 → JSON 백업`으로 기존 기록 보존. 모바일 Brave/PC의 기존 저장공간은 그대로 두고 본인 데이터로 테스트하세요.
2. v114 수동 운영 배포에 접속하여 `자료·분석 → 선지 근거 검토 대기열` 열기. 검색에 ‘2019’, ‘수요’, 한글을 입력하면서 조합 글자가 지워지거나 커서가 튀지 않는지 확인. 연도/과목·검토 단계·4가지 정렬 확인.
3. 2019·2025년 등 1~5문항 선택 → `선택 문항 개인 근거 TXT` 저장. ①~⑤별 CK83과 CK80 출처가 **동일 번호끼리** 대응되는지, 전원정답은 ‘모두 참’으로 해석하지 않는지 확인. 6번째 선택이 차단되어야 함.
4. `문항 분석 → 내 풀이 메모`를 수정하고 1초 이상 경과 → 저장 버튼 없이 닫기/다른 문제 이동 → 같은 문항 메모가 복원되는지 확인. 저장 공간을 가득 채우는 실험은 **기존 자료 백업 후 격리 프로필**에서만 수행.
5. CK80 개인 해설과 CK83 선지 개인 근거를 쓰다가 접기, 원문 분석 이동, 닫기, ESC, 상단 탭/로고 클릭 → 미저장 확인 취소 시 작성 화면이 보존되는지 확인.
6. 2016~2020년 1문항 로딩 중 2025년 다른 문항으로 빠르게 이동해 오래된 결과가 마지막 선택을 덮지 않는지 확인.
7. `비교 도형 → 차트`의 수요 증가·감소, 공급 증가·감소, 동시 증가에서 ‘차트 움직임 보기’ 클릭. E₀와 E₁, 균형점 가격/수량 방향 및 동시이동 가격 불확정 경고, ‘시작 상태로’ 복귀를 확인.
8. 음성: 1.5배속/3읽기 방식/40문항/TTS 일시정지·이어듣기/복습 대기 TTS 확인. 등록 원문 중 미로딩 상태는 일부 문항만 잘못 재생하지 않아야 함.
9. 모바일 Android Brave에서 상단 오른쪽 설정 고정·가로 탭 현재 위치 유지·S Pen on/off 후 터치 복구·물리 버튼 지우개, PDF 두 페이지와 오른쪽 필기 보존, 배경 GPU 정지를 확인.
10. PC/모바일 결과를 PASS·FAIL·미확인으로 기록하고, FAIL의 기기/화면 폭/문항 ID/재현 순서를 남겨 이후 수정.
