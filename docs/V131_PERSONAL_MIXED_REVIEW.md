# ConceptKnot v131 — 혼합 모의고사 제출 기록 기반 개인 약점 복습

기준: 2026-11-07. 기준 GitHub `main` v130 `84a608aadf1c4735993da2545d57f891b62b7407`.

## 범위
- **모의고사**의 10개년 공식 A형 혼합 5세트 바로 아래에 **개인 약점 분석 · 다시 풀기**를 추가했다.
- 새 `ck129` 로컬 저장 키, 공식 문제/선지/정답/출처를 **전혀 수정하지 않는다**. 최대 최근 10회의 **제출된 시험**만 원본에 대한 읽기 전용 집계로 분석한다. 개인 검토의 다시 풀기 선택은 휘발성 화면 상태로, 기존 성적/OMR에 기록하지 않는다.
- 각 과목 정답/전체 제출 문항, 오답·미응답·보류 수, 회차별 평균 점수의 상대 막대, 문항별 우선순위 대기열(최대 20개), 공식 A형 5선지 개인 다시 풀기, 정답 인정 번호 확인, 최근 5개년 CK78 / 이전 5개년 CK76 개인 근거 진입 및 공식 PDF 원문 링크를 제공한다.
- 우선순위는 **오답 횟수×5 + 미응답 횟수×3 + 보류 횟수×1**이라는 단순 학습용 가중치다. 성적 예측·공식 검수·법령의 진위 판별이나 해설 자동 생성이 아니다.
- 과목별 통계의 **전체**는 응시 횟수별 합계(최대 400문항)가 아니라, 제출된 기록의 과목별 문항 노출 횟수 합계다. 동일 문항이 여러 회차에 등장하면 노출 횟수만큼 포함한다. **고유 문항 수**는 별도 표시한다.
- 시험을 아직 제출하지 않았거나 일시정지한 상태에는 정답 정보를 노출하지 않는다. 수상한 세트 번호/문항 배열/채점 인정 또는 다른 탭과 불일치하는 개인 저장소는 분석을 중단한다. 원본은 남겨 두고 사용자에게 백업을 안내한다.
- 다운로드는 필터에 따른 최대 20문항의 `TXT`로, 실제 브라우저 저장 여부는 사용자가 확인해야 한다. 다운로드 전 다른 탭 변경을 재검사한다.

## UI·오프라인·검증
- 신규 `assets/ck-mixed-review-v131.js`, `assets/ck-mixed-review-v131.css`, `tests/v131-mixed-personal-review.test.cjs`. 기존 모의고사 마운트 완료 이벤트에만 부착하며 별도 상시 인터벌·애니메이션을 만들지 않는다.
- 서비스워커 세대 `conceptknot-study-v131-mixed-review-queue`; 신규 JS/CSS를 **선택 캐시**로 추가. 최소 필수 11개는 그대로 유지하므로 11/11만으로 v131 전체 오프라인 기능을 보장하지 않는다.
- 기존 수기 실기검증표 28개 ID 및 사용자 PASS/FAIL 기록은 유지. 혼합 세트 확인 항목의 설명에 약점 복습 동작을 덧붙였다.
- 모든 수정은 GitHub 소스 작업이며, Vercel 운영 자동배포 비활성/Actions 워크플로 미추가/EXE·APK·ZIP 미생성 원칙 유지.
- 구형/신규 테스트가 실제 기기·Chrome/Brave·S Pen·음성·GPU·모바일 UI 실행을 증명하지 않는다. 공식 800개 원문·정답 구조 등록은 법령/판례 의미 감수 완료와 별개다.

## 수기 실기검증
1. 기존 통합 학습 JSON, 공식 연도별 CK82 결과, 혼합 시험 JSON, PDF 필기 JSON, OCR·개인 교재 초안을 별도로 백업. 저장된 파일 열기 전 웹 저장소 삭제/초기화 금지.
2. 운영 SHA가 v131 배포 커밋과 동일한지 확인. 현재 v115 환경에서는 신규 기능이 보이지 않음.
3. 5세트 각 80문항·100분, 원문/정답, 숫자키·OMR·일시정지·회전·탭 이동을 확인. **진행 중 복습 창에서 정답이 보이면 FAIL.**
4. 1회 제출(오답 1개, 미응답 1개, 보류 1개 이상) 후 우선순위, 필터, 회차 평균과 TXT를 비교. ①~⑤ 선택 후 정답 공개는 기존 성적/원본에 반영되지 않아야 함.
5. 2016~2020, 2021~2025 근거 화면 연결, 원문 PDF 링크와 빈 필터, 미완료 원문 로드 안내를 확인.
6. 두 탭 간 기록 변경·백업 병합/손상 데이터를 **별도 브라우저 프로필**에서 시험. 원본 기록 자동 덮어쓰기나 잘못된 성적 생성이 없어야 함.
7. 설정에서 현재 서비스워커 v131, 최소 11/11, 혼합 시험 JS/CSS 2/2 그리고 v131 복습 JS/CSS 오프라인 상태를 확인. 비행기 모드·온라인 복귀 후 개인 자료 보존 확인.
8. Android Brave에서 360px 가로 탭 유지, 설정 고정·TTS 세 모드 1.5배속, S Pen 지우개/탭 전환, PDF 두 페이지 필기, 다크모드·GPU 유휴를 실물로 확인하고 **28개 수기검증표**에 PASS/FAIL/미확인 기록.
9. 수동 `node --test tests/v131-mixed-personal-review.test.cjs` 및 `node scripts/check-release-readonly.cjs` 수행. 자동 CI 사용 금지.
