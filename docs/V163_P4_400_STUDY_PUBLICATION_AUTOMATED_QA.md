## 사용자 요구 및 결정

사용자는 수기검증 요청을 뒤로 미루고 **이전 미완료 코딩·전체 공식기출 해설 표시·자동검증의 전수화**를 먼저 요청했다. 2021~2025 원본 A형 400문항은 이미 400건 모두 `summaryEasy`·`answerReason`를 포함하지만, 실제 각 선지별 독립 AI 설명은 200/2,000개, 기존 후보 포함 886/2,000개뿐이다. 개별 선택지 1,114건은 실질 풀이·조문/판례 검독이 없으므로 이를 해설 작성 완료로 간주하지 않는다.

Q-Net의 공적 게시 자료는 문제지 공고와 별도 최종정답 공고이다. **Q-Net에서 직접 작성·감수한 해설로 오인할 수 있는 '공식 해설 100%' 문구를 금지한다.** 앱에서는 '공식 기출 A형 + 자체 작성 미검수 학습용 해설' 400/400을 확인·열람·TXT 내보내기 가능하게 한다. 법리·참/거짓 검수·원본 첨부 PDF/판례 전체 대조가 확인되지 않은 항목은 원래 `quality.status='draft'`를 유지한다. 전문가 감수 및 정부 인증 해설 게시 수치는 **0/400·0/2,000**으로 변경하지 않는다.

4. **실행 가능한 전수 자동 QA:** `scripts/audit-p4-v163.cjs --gate=structure|study|expert|official`. 불일치/누락·중복/정답 바뀜·ID 잘못 연결·일부 미작성·Q-Net 원문 링크 오류가 있으면 **전체 출력 차단**. `structure`는 400문항·2,000선지 기계적 원전 데이터 1:1 매칭; `study`는 400문항별 자체 정답 근거 설명의 존재까지 확인. `expert`와 `official`은 현재 **FAIL(차단)**: 원전 증거·전문가 검수·진위 확정이 아직 없음.
5. **출시 직전 자동검증:** 자동 GitHub Actions 및 Git 연결 배포는 OFF(`vercel.json: git.deploymentEnabled=false`). 기존 승인 범위에서 수동 배포를 수행할 때에만 `buildCommand`가 P4 `study` 게이트와 관련 Node 테스트를 실행해 **실패 시 배포 차단**하도록 설정. 중간 자동 Actions / 설치파일 생성 없음.
6. **기기 실기검증 나중에:** 서비스워커·진단·수기 QA에서 P4 선택 자산을 9→11로 확대하고 v163 세대 동기화. 필수 11개·P2/P6 9개는 변경하지 않음. 기존 개인 메모·필기·학습 키·공식 800문항·정답·TTS 모델에는 변경 없음.
