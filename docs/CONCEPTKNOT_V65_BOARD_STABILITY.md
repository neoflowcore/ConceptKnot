# ConceptKnot v65: 칠판 타이핑 깜빡임 및 선택 팝업 개선

입력 중 타이핑 미러에서 발생하는 DOM 변경을 루트 화면 변경으로 오인해 메모 판의 스타일·메트릭을 다시 처리하던 경로를 줄였다. 모바일 보드/테마 관찰기는 #main 직계 교체에만 반응하며, 칠판 S펜 캔버스는 실측 해상도가 변경된 경우에만 재설정한다. 타이핑 탭에서는 칠판 글라스의 실시간 backdrop-filter 합성 대신 유사한 정적 반투명 배경으로 경계를 안정화한다.

칠판 선택 우클릭 팝업에는 제목 드래그/터치 이동, 크기 변경 시 화면 안으로 위치 조정, 명시적인 완료 버튼을 추가했다. 선택 B·색상·복사는 창을 닫지 않고 순차 적용하며, 붙여넣기 뒤에도 새로운 선택 범위를 유지하여 추가 서식을 적용한다. 클립보드 차단 시 단축키 안내 유지. JSON 및 개별 글자 서식 기록은 보존한다.
