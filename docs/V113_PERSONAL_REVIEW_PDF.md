## 개선 내용

1. 개인 해설 편집기: 작은따옴표 HTML 이스케이프 수정. 초안을 접었다 열어도 저장하지 않은 텍스트 DOM을 새로 생성하지 않고 유지. 상단 내비게이션/페이지 이동/해설 모달 닫기/ESC/창 종료 시 작성 중 변경사항 확인을 보강. 현재 문항 ①~⑤ 판단·이유·출처 기입 상태를 저장 전 상태로 실시간 표시.
2. 선지 검토 대기열: 4,000선지 CSV에 CK83 개인 판단·이유·출처와 CK80 개인 초안의 판단·이유·출처를 **구분된 열**로 내보냄. 연도·과목·검토조건 필터를 적용한 문항/선지 CSV 추가. 800문항 전수 로딩에 성공한 경우에만 내보내기 허용. 오래된 자료 복원 및 공식 정답 변경 없음.
3. PDF 필기: 페이지 이동/도구 변경 시 사용자가 켠 S Pen 모드를 그대로 두면서 진행 중 획을 저장. 두 페이지 펼쳐보기의 오른쪽 필기 레이어 제거 직전 획 저장. S Pen을 직접 끌 때는 진행 중 획을 저장한 뒤 해제. 탭 밖 클릭/브라우저 숨김·포커스 해제 시 자동 비활성화 정책 유지.
4. 시각 스타일: 개인 해설 완성도 표시 및 모바일 CSV 내보내기 버튼 레이아웃을 작은 폭에 맞춤.
5. 오프라인 서비스워커 캐시 이름을 v113으로 분리. 이 파일 변경만으로 Vercel 운영 배포는 되지 않음.
6. `tests/v113-personal-review-pdf.test.cjs`: CSV 열 정합성·스프레드시트 수식 주입 방어, 초안 접기/이탈 확인, PDF 획 저장과 펜 모드 지속 회귀 테스트.

## 반드시 직접 실기 검증

1. 기존 `내 데이터 → JSON 백업`으로 학습기록을 먼저 내보내 보관.
2. v113을 **수동 배포한 환경**에서 `자료·분석 → 해설 검토 작업대`에서 2019년 23번 편집. 예문·①~⑤ 근거 입력 후 접었다 펴서 값 유지, 저장 및 새로고침 후 복원. 2025년 1번 기존 초안 훼손 없는지 확인.
3. 해설 입력 미저장 상태에서 `이전 문항`, `닫기`, `ESC`, `오답 복습` 탭 이동을 시도해 경고가 나오는지 확인. 취소하면 편집이 남아야 함.
4. `선지 근거 검토 대기열` → 전체 800문항/4,000선지 CSV, 현재 필터 문항·선지 CSV 내보내기. 연도 2019, 민법 등 조건별 출력 수와 ①~⑤ 출처/근거 열 정렬 확인. Excel에서 `=...` 같은 사용자 메모가 실행되지 않는지 확인.
5. 갤럭시 S Pen으로 2페이지 펼쳐보기 활성화 → 오른쪽 페이지에 쓰면서 왼쪽 페이지 이동/펜 색·지우개 전환 → 필기 보존. 다른 메뉴로 이동하면 S Pen 자동 해제 및 손터치 정상 확인.
6. Android Brave 화면 폭에서 상단 오른쪽 설정 고정, 가로 탭 스크롤 위치 유지, 오답 복습 탭 정확한 이동 확인.
7. 한국어 TTS 1.5배속, 3모드, 40문항 연속, 일시정지/재개와 PDF 원본 로딩, GPU 백그라운드 중지를 실제 기기에서 확인.
