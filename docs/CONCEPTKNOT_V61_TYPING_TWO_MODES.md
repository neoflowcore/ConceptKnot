# ConceptKnot v61: 일반 키보드 + 문자만 타이핑

작성일: 2026-10-31. 범위: 타이핑 탭.

## 사용자 입력 방식

- 일반 입력(기본값): 실제 textarea 편집을 유지합니다. Enter는 한 줄 내려가기, Backspace는 이전 문자 삭제 및 줄 시작에서 이전 행으로 이동, Space는 띄어쓰기입니다. 방향키·마우스 선택·붙여넣기도 기본 동작을 따릅니다.
- 문자만: 공백, 줄바꿈, 문장부호와 무관하게 원문의 글자·숫자만 순서대로 입력합니다. Enter와 Space는 입력·진도에 영향을 주지 않습니다. Backspace는 항상 이전 글자를 삭제하며 진행도가 역방향으로 갱신됩니다.
- 두 모드 모두 원본 텍스트/행 배열은 고정입니다. 일반 모드는 별도 잉크 레이어가 원문 위에 덧씌워지고 문자만 모드는 원문 각 글자 위치에 실제 입력 글자가 덧씌워집니다. 틀린 글자도 원문 대신 실제 입력 글자가 보입니다.
- 두 모드의 초안, 색, 경과 시간, 완료 상태를 분리 보관합니다. 기존 원문 및 학습 기록을 유지하고, 레거시 정답 단락 점프 기능과 Enter·Space 개별 토글 UI는 제거했습니다.

## 입력기(IME)와 조작

- 한글 IME 조합 중 텍스트를 강제 정리하지 않습니다. 조합 종료 후 문자만 모드에서만 공백·기호를 제거합니다.
- 모바일 가상키보드 beforeinput와 물리 키보드 keydown에서 문자만 모드의 Enter·Space만 억제합니다. Backspace 및 일반 입력의 편집 키는 건드리지 않습니다.
- 두 입력 방식 선택은 접근성 aria-pressed를 사용하고, 선택값은 ckTypingInputMode에 저장합니다.

## 운영/검증

- 오프라인 캐시 v69에 새 스타일시트를 포함합니다. 실제 인라인 코드와 보관용 자산 JS 코드를 동기화합니다.
- 테스트에서 기본 Enter·Space·Backspace, 문자만 편집, 한글 기호 건너뛰기, 모드별 초안, 칠판 배치, 스크립트 파싱을 검사합니다.
- Actions/자동 배포는 비활성 상태로 유지합니다. APK·EXE·ZIP 생성 없음.
- 실물 키보드와 모바일 한글 IME 실기는 별도 브라우저 확인이 필요합니다.
