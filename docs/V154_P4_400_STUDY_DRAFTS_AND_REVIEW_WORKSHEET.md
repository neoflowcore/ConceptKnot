1. 운영 사이트의 **자료·분석 → 해설 검토 작업대**를 열어 '최근 5개년 해설 초안 400', '미작성 해설 0', '공식 해설 근거 검수 0', '선지 5개 출처 검수 0' 표시 확인. 2016~2020 해설 미제공 상태와 혼동하지 말 것.
2. 새 초안 2021년 학개론 **4번(탄력성 0.5·교차탄력성 0.8), 8번(균형가격 차이 24만원), 19번(NPV 100만원), 27번(원금균등 3회 4,240만원), 38번(수익가액 3억9,900만원), 40번(공시지가 13,860,000원/㎡)**을 열고 설명이 원문과 같은지 살펴보기.
3. 민법 2021년 76번(계약갱신요구 행사기간), 2022년 45번(제한능력자의 취소), 2023년 70번(매매 비용)을 확인. 각 설명은 *학습용 초안*, *미검수*임을 표시해야 한다.
4. 특수정답 **2021년 77번 ①~⑤ 전원정답 / 2022년 56번 복수정답**에서 **정답 처리와 선지 진위 미검수**가 분리되는지 확인. 전원정답은 5개 진술이 모두 진실이라는 의미가 아님.
5. 작업대 상위 문항 1~5개 선택 후 '해설·근거 대조 TXT'를 눌러 **원본 보기 5개·공식 정답·초안·근거 검수 미완료·PDF 링크**가 제대로 담기는지 확인. TXT가 검증 완료 문구를 만들어내거나 사용자 저장 OMR·개인 초안을 변경하면 FAIL.
6. 그래프의 **수요 D/공급 S 선을 직접 손가락/펜으로 잡아 좌우 이동**. 그림 내부 선을 잡고 움직일 때 페이지 전체가 스크롤되면 FAIL. 곡선 E₀ 점선/E₁ 실선, 가격·수량 변화, 개념→쉬운 예시→심화 설명, Undo/Redo 확인.
7. 26개 도형의 사례 5개씩에서 예측 전 정답 비공개/적용 버튼 잠금, 채점 후 전후 그래프 반영, 오답 다시 풀기, 같은 문제 중복 학습 집계 방지를 확인.
