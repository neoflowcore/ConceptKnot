## 개발 요구 변경 이력

사용자의 최우선 목표를 P4 원전 검수 400문항/2,000선지로 변경하였다. 이전 v160은 원본 문제·채점 인정정답·선지 연결 및 검수표를 마련한 단계였으므로, v161에서는 **새로운 내용을 가진 선지별 풀이와 법령·이론 근거 초안**부터 추가한다. 기존 공식 답안과 비검수 콘텐츠를 직접 덮어쓰지 않으며 AI 작성 내용은 전문가 검수와 엄격하게 구분한다.

### 원본 PDF 검증 한계

Q-Net [2025년 제36회 문제지 게시글](https://www.q-net.or.kr/cst003.do?artlSeq=5247125&boardId=Q004&gId=08&gSite=L&id=cst00302&menuType=cst00309)과 [최종정답 게시글](https://www.q-net.or.kr/cst003.do?artlSeq=5249925&boardId=Q004&gId=08&gSite=L&id=cst00302&menuType=cst00310)은 별도 확인하였으나, **공식 ZIP 첨부 문제지와 정답 PDF 실제 각 페이지의 최종 대조를 완료하지 못했다.** 이 차이는 개발 데이터의 `sourcePdfRead=false`, `sourcePinpointVerified=false`, `independentExpertSignoff=false`로 명시된다.

기존 830개 근거 후보(선지별 664개 + 문항 수준 정답 설명 대입 166개)와 신규 v161 100개를 **실제 문항·선지 ID로 교집합 대조**한 결과 76개가 기존 후보를 별도로 재작성한 항목이고, **24개는 기존에 어떤 근거 초안도 없던 선지**였다. 따라서 원전 검수와는 무관한 **학습용 근거 후보 총보유는 830→854/2000(42.7%)**, 아직 근거 후보가 없는 선지는 **1170→1146/2000(57.3%)**이다. 전문가 선지 검수는 **0/2000**을 그대로 유지한다. ## **사용자 직접 실기검증 — 반드시 PASS/FAIL 수기 기록**

1. 기존 개인 답안/필기/해설 기록을 백업한다. 브라우저 저장·캐시 초기화를 수행하지 않는다.
2. 운영 사이트의 개인 검토 작업대에서 **'2,000개 선지 하나씩 검토'**를 연다. 'AI 독립 근거 초안' 지표가 **100/2000**으로 나오고 '전문가 검수 완료'는 여전히 **0/2000**인지 확인한다.
3. 연도=2025, 과목=학개론, 검토 그룹=**AI 개별 근거 초안 있음**을 선택한다. 1~15번의 선지 총 75건을 확인한다. 과목=민법으로 바꾸면 41~45번 25개가 나와야 한다.
4. 2025-3번 ③의 확장 패널에서 **건축법 시행령 별표1 다중주택** 근거 및 해당 정부 법령 링크를 확인한다. 2025-44번 ⑤에서 **민법 제122조** 확인. 원문·정답 공식 PDF는 원본 사이트에서 별도로 개봉하고 각 쪽을 대조한다.
5. **AI 독립 근거 초안 100선지 TXT**를 눌러 100개 선지의 원문·초안·참고 링크·'미검수' 경고를 내보낸다. AI 근거를 자동으로 정답 해설로 게시하지 않으며 개인 작성내용도 변하지 않는다.
6. 오프라인 진단에서 필수 11종·P2/P6 9종·P4 8종 파일과 현재 **v161 서비스워커** 여부를 확인한 뒤 비행기 모드에서 선지와 초안을 다시 연다. 실제 보관 파일 존재만으로 기기 검증 PASS 처리하지 않는다.
7. 기존 80문항/100분 OMR, 복원, 17종 그래프 직접 드래그·스크롤, Android Brave/S Pen 칠판 및 한글 IME를 주요 회귀 점검한다.
8. P7 'v161-ai-100-option-notes', 'v161-pdf-law-source' 항목을 **실제 기기에서 조작한 결과**로만 PASS/FAIL 표시한다.
