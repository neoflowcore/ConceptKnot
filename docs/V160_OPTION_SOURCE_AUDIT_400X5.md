## 일치 검사와 실제 검수의 차이

**자동 대조 완료**:
1. 2021–2025 각 연도 80문항 × 5년, 각 연도 학개론 40문항·민법 40문항.
2. 문제 \`verified=true\`, 문제 ID·과목·연도·번호와 해당 해설 \`questionId/examYear/subject/number\` 연결.
3. 공식 정답 배열과 해설의 공식 인정정답 배열 일치, ①~⑤ 5개 선지번호 유지.
4. 중복·누락·정답 불일치·선지번호 변조 시 내보내기 차단.
5. CSV 수식 인젝션 시작 문자 방어, HTML 이스케이프, URL HTTPS 검증, PDF 미확인 설명 명시.

**독립 전문가 검수 미완료**:
1. 각 선지의 주장, 인용할 수 있는 공식 법령/판례 조문/쪽수/사건번호.
2. 각 시험 시행일 당시 효력이 있던 조문과 이후 개정 구분.
3. 각 문항의 공식 문제지 PDF와 정답 공고 PDF 원문 자체 대조.
4. 계산/탄력성/환원율/현금흐름 등 대입·단위·반올림의 실제 수치 검산.
5. 복수정답·전원정답이 허용된 배경 공고와 개별 선택지의 실제 진위 분리.
6. 외부 검수자 서명·검수 일시·증거 URL/문서의 쪽수 및 공개 승인.

위 항목들을 수행하거나 확인할 독립 원전 근거가 없이 "검수 완료"나 "전문가 검수"라고 표시해서는 안 된다.

2. 개인 검토 작업대를 열어 400문항 7/216/57/120, 2,000선지 연결, 기존 근거 초안 830/2,000과 미작성 1,170/2,000 표시를 확인한다. 이 수치는 기준 데이터에서 계산된 것이고 브라우저의 실제 사용자 작성 내역에 따라 별도 변경될 수 있다.
3. **2,000선지 보기**에서 연도 2021~2025, 학개론/민법, 근거 누락, 법령/판례, 계산/그림, 복수·전원정답 필터를 순서대로 바꾼다. 다음/이전 버튼이 20개씩 움직이는지 확인한다.
4. 2,000선지 CSV와 400문항 CSV, 각각 상위 5문항 TXT를 내보내기한 뒤 해당 ID·문제·선지·정답 인정·근거 초안/미검수 표기 및 Q-Net **문제지 게시글 vs 최종정답 공고 링크가 다르게 기재되었는지** 확인한다.
5. 선지별 개인 근거 편집을 열어 의견·출처를 입력한 뒤 다른 탭/새로고침 후 보존되는지 확인한다. **개인 노트 작성 = 전문가 검수 완료**로 표시되지 않아야 한다.
