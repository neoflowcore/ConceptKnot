# v116 PDF 필기 보존 보강 (2026-11-04)

기준선: v115 `4a12a9fb7dbc0e9191539cc3b6d8bbeed92dc1f2`. 변경은 PDF 모듈만 적용하며 공식 800문항/선지/해설 데이터는 수정하지 않음.

## 수정
- 양쪽 펼쳐보기의 오른쪽 필기가 부모 세션에 의해 저장되는 경로에서 원본 문자열을 비교해 다중 탭 변경/삭제 덮어쓰기를 차단.
- 읽기 오류 또는 JSON 손상 시, 비어 있는 필기로 간주해 기존 자료를 덮어쓰지 않도록 차단.
- S Pen 몸통 버튼을 누른 상태로 pointerup 이벤트가 발생해도 획을 확정. 획 완료를 onPointerMove로 오인하던 경로 제거.
- 오른쪽 페이지를 재렌더한 뒤에도 부모의 S Pen 활성화를 반영.
- 다른 탭의 필기 갱신 시 손실 경고, CKPDF15 상태에 `inkIssue` 노출.

## 코드 수준 제한된 검증
연결 GitHub의 수정 blob으로 JS 구문, 오른쪽 페이지 필기 부모 저장, 다중 탭 수정시 덮어쓰기 차단, 버튼 누른 상태에서 S Pen pointerup 획 완료를 V8 인메모리 모의 검사함. **Android Brave, PDF 두 페이지 실물, SPen 버튼, 필압, 저장공간 부족, 실제 레이아웃은 수기 미검증.**

## ⭐ 수기 검증 (운영 배포 후)
1. `내 데이터` → 전체 JSON 백업, PDF 내 필기는 별도 `PDF 저장`으로 먼저 백업.
2. 모바일 Brave로 2025년 PDF 두 페이지 펼쳐보기 → 오른쪽 페이지 1획 → 페이지 전환/복귀 → 획 유지 확인.
3. 오른쪽 S Pen 사용 중 몸통 물리 버튼을 누른 상태로 지우기와 pen pointerup을 반복 → 획 끊김/이상한 새 획 없는지 확인.
4. 같은 사이트를 두 브라우저 탭으로 열어 PDF 필기를 각각 수정 → 이전 탭은 저장 충돌 경고를 보고 기존 필기를 자동 덮어쓰지 않아야 함.
5. PDF를 새로고침해 원본 필기 복원 확인. 문제가 있으면 해당 연도·페이지·기기/브라우저 버전과 재현 순서 기록.
