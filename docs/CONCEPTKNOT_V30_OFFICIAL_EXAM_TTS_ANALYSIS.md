# ConceptKnot v30 · 공식 기출 즉시 피드백 · 여성 AI 음성 · 5개년 분석 착수

작성일: 2026-10-29 | 상태: 코드 반영 / 운영 배포 별도 요청 / 실제 음향·화면 실기 검증 대기

## 1. 공식 기출 답안지 즉시 정답 토글

- 제목 옆 체크박스형 아이콘(`data-ck30-instant`), title 툴팁과 `aria-pressed` 사용.
- 기본 OFF: 정답 선택 시 기존처럼 다음 문제로 이동.
- ON: 현재 문항 유지, 정답 선지 연녹색·선택 오답 연분홍색, 최종 A형 정답 번호 즉시 표시.
- 복수정답 인정; 전원정답은 채점상 인정으로 표시하고 모든 선지가 참이라는 뜻으로 표시하지 않음.
- 기존 답안·PDF 필기·최종 성적 판정 경로 보존.

## 2. 공식 기출 음성 경로

### 이전 문제 원인

- `ttsPlay`가 `engine === 'neural' && !continuous` 조건으로 **연속재생을 기기 TTS로 강제 우회**.
- 공식 문서의 `data-tts-exam`은 `changeView('listen')`만 호출해 직접 낭독하지 못함.
- AI 여성 음성 합성은 단일 항목에 `qa`만 적용하여 정답만/전체 선지 모드와 연계되지 않음.

### 변경

- `engine`: 기기 기본 음성 / 로컬 AI 여성(Supertonic 3, F1~F5).
- `marathonMode`: 문제+정답 문장(`qa`) / 정답만(`answer`) / 문제+전체 선지(`all`).
- `playScope`: 현재 문항(`single`) / 선택 연도·과목 전체(`all`).
- 공식 문서의 **현재 문제 듣기**는 바로 낭독; 옆 **⚙**는 설정 화면 이동.
- `speechSegments` 공유, 큰 문장은 분할. 준비된 모델은 그대로 사용, 페이지 갱신 후 필요한 경우 로딩 경로 재진입.
- `ttsBatchActive`와 중지 토큰을 AI 엔진 연속재생에도 적용. 뷰 전환 중 모델 로딩이 끝난 경우 오래된 재생 요청은 취소.
- AI 모델 약 380MB는 외부 출처의 가중치; 브라우저 캐시와 연결 환경에 따라 로딩이 필요할 수 있음. 다운로드만으로 **완전한 영구 오프라인 사용을 보증하지 않음**.

## 3. 단축키

- Ctrl 단독 탭 → 상단 KeyTip 1~13 표시 → Ctrl에서 손을 뗀 뒤 숫자 입력.
- Ctrl+숫자는 브라우저 탭 전환과 충돌 가능하므로 사용하지 않음.
- Ctrl+Z/X, Ctrl+WASD, Ctrl+Enter, Alt+Shift+WASD, F2는 유지.

## 4. 2021~2025년 400문항 해설 착수

| 항목 | 진행 |
|---|---|
| 기출 본문·선지·최종정답 기존 등록 | 400/400 |
| 문항별 새 쉬운 해설 **초안** | 4/400 (1%) |
| 초안 선지 판단 근거 | 20/2,000 (1%) |
| 전체 400문항의 출처별 최종 검수 | 별도 완료 기록 없음 |
| 출제빈도 기반 시험 직전 정리본 개편 | 미착수 |

초안 ID: **2025-9**(수요/공급), **2025-11**(개별수요 합산), **2025-12**(수요 탄력성), **2025-21**(임대료상한·초과수요).

- `assets/ck-official-explain-v30.js`에 **초안** 상태로 저장.
- 최근 5개년 연도 버튼에 연한 골드 앰비언트, `문항 해설` 모달 제공.
- 해설 없는 문제는 '작성 대기'로 표시, 이유를 지어내지 않음.
- 모든 정답은 기존 검증된 A형 최종정답 기반. 출제 시점 법령과 2026년 현행 법령을 혼동하지 않음.
- 향후 분석은 2025→2024→2023→2022→2021 순서. 정상답/복수답/전원정답 판별 로직과 판례·조문 출처 기록.

## 5. 정리본 후속 단계

- 현재 A4 1~5장 자동 초안과 TXT/PDF·수정 저장 기능은 유지.
- 이번 단계에서 정리본이 완성됐다고 주장하지 않음.
- 문항별 개념 빈출도·중복 함정·계산식·시험장 최종 암기법을 검증한 뒤 A4 5장 고밀도 구성으로 다시 생성.
