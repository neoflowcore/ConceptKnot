# ConceptKnot v105: 상단 설정 고정과 10개년 원문 검토 작업표

대상: neoflowcore/ConceptKnot main, v104 이후.

## 변경 사항
1. ck-navigation-v5.js가 오른쪽 날짜/시계/타이머/설정 묶음을 ck-v7-nav-pill의 스크롤 영역 밖으로 옮기고 글로벌 내비게이션의 오른쪽 독립 영역으로 배치한다.
2. ck-dot-landing-v57.css는 글로벌 nav 전체 한 줄을 유지하고 왼쪽 로고·탭만 가로 스크롤하며 오른쪽 설정은 화면 끝에 남기도록 한다. 850/420px 구간의 버튼 폭과 간격을 조정한다.
3. 개인 자료 안전 점검에 2016~2025년 연도별 시각검토·OCR 유사도·특수정답·개인 선지 판단/출처 준비도 매트릭스를 제공한다. 모두 읽기 전용이다.
4. 안전한 CSV 내보내기는 등록된 공식 800문항이 모두 로드되고 스키마 검사를 통과한 때만 가능하다. 개인 선지 메모는 검증된 공식 사실로 승격하지 않는다.
5. 캐시 버전과 핵심 수정 파일 no-cache 응답 지시를 갱신한다. Git 자동배포(false)와 Actions 미사용 및 아티팩트 금지는 유지한다.

## 현재 확인된 기준선과 미완료
- 기존 Phase 운영 체크포인트는 P0 80%, P1 80%, P2 80%, P3 60%, P4 40%, P5 40%, 총 19/30=63%다. 2026-10-29 측정 기준선이며 v105 실제 제품 전체 구현율이나 실기 PASS 비율로 표시하지 않는다.
- 공식 기출 구조 2016~2025년 800문항; 최근 2021~2025년 해설 400건 중 초안 32건, 미작성 368건, 검수된 근거 0건(기존 보고 수치). 실제 법령·선지별 근거 검수는 별도.
- 디자인 초안 정량 일치율 미측정.
- 실제 PC/모바일 Brave S펜·IME·TTS·PDF·GPU·교차 탭 저장/복원은 실기 검증 전.

## 실기 수동 검증
1. 로고의 CONCEPTKNOT 문구가 접히고 펼쳐져도 설정 패널 오른쪽 모서리가 움직이지 않는지 확인.
2. 1600px/1024px/768px/360px 폭에서 로고·탭 가로 스크롤과 고정 타이머·시계·날짜·설정을 확인.
3. 다크모드 전환·가로 터치 스크롤·Ctrl 탭 이동 및 시계 버튼을 확인.
4. 기존 백업을 보존한 뒤 설정 화면의 10개년 검토 매트릭스를 열어 CSV 800행·현재 개인 출처 건수를 확인한다. 400문항 일부만 로드된 경우 CSV가 차단돼야 한다.
5. 공식 OCR, 표·그림, 판례 근거, Android/삼성 S펜/음성/배경 GPU는 실제 기기에서 별도로 확인한다.

코딩 및 스키마 점검 결과는 수동 기기 실기 검증 결과와 별도로 기록한다.
