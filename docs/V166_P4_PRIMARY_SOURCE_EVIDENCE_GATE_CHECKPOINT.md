  - `node scripts/p4-evidence-gate-v166.cjs --check evidence-local.json`: 전체 행 개수·중복·원문 SHA 변조·검독 필수 필드·문항 서명 조건 검사(실제 인용 내용의 진위는 별도 인간 판정).

## 후속 필수 작업
1. CLI 자가검사·전체 데이터 `--init` 및 `--check` 실행하여 실증; 누락·중복·원본 훼손 차단 확인.
2. 2021–2023 미작성 942선지 학습용 근거를 실제 선지마다 작성하고 원본 잠금 및 매핑 테스트 연결.
3. Q-Net 공식 문제지·정답 **첨부 파일 본문** 400문항 / 2,000선지 직접 검독. 원전 법령은 해당 시험일 유효 조문/개정 전후 확인, 판례는 사건번호·선고일·판시, 계산형은 독립 재산출. 특수 인정정답 7문항의 사유 별도 검독.
4. 별도 전문가 검독자 확인·정정·승인 후에만 감수 해설 표시. 공식 기관 인증은 실제 기관의 서면 확인 없이는 표시 금지.
5. 향후 UI에 검독 원장을 연결할 때 원장 검증 성공/실제 심사/게시 권한을 별도의 fail-closed 상태로 표시하고, Android Brave/S Pen 수기 QA는 후순위로 수행.
