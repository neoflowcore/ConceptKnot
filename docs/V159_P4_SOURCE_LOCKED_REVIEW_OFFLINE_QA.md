## **수기 실기검증 필수 — 사용자가 직접 PASS/FAIL 기록**

1. **기록 보호를 먼저 확인**: 운영 사이트 새 탭에서 접속. 기존 공식·혼합 OMR 답안, 내 해설, 오답 기록, PDF 칠판 필기·S Pen 기록이 있는지 확인. 브라우저 데이터 초기화/강제 로그아웃 금지. 개인정보 기록의 JSON 백업을 준비한 후 필요 기능 검증.
2. **P4 정확히 400건**: 앱의 개인 검토 작업대를 연다. '최근 5개년 400문항 · 원전 검수 우선순위'의 특수정답 7 / 법령·판례 216 / 계산·수치 57 / 기타 120, 원전 검수 0/400, 선지 0/2000 표시 확인. '특수정답 7건부터 보기'를 누르면 7문항만 표시되고, 정렬/연도/검색 필터가 정상 결합되어야 함. 원문 누락 시 내보내기 차단되어야 함.
3. **CSV**: '400문항 원전 검수표 CSV' 클릭 → UTF-8 CSV의 열/총 400문항/7·216·57·120 기준 일치 확인. 검수자·적용기준일·출처링크는 **미작성/미확인**이어야 하며, 아무 행도 자동으로 '게시 가능'이 되어서는 안 됨. 문항·정답 자료와 비교하고 공식 인정정답을 선지 진위로 해석하지 않음.
4. **TXT**: '우선 5문항 해설 대조 TXT' 클릭 → 우선순위 1의 문항 5건의 원문·선지 ①~⑤·공식 정답 처리·해설 초안과 미검수 선지 표시 확인. 법령/판례의 시험 당시 적용 여부와 전원/복수정답 의미를 사람이 별도로 대조.
5. **개인 검토 기록**: 상태를 '근거 확인 중/보류/개인 대조 준비'로 바꾸고 탭 이동·새로고침 후 유지되는지 확인. 기존 기록이 덮이지 않고 '개인 준비'를 '전문가 검수 완료'로 승격하지 않아야 함. 다른 탭 변경시 경고 및 원본 유지 확인.
6. **오프라인**: 먼저 온라인에서 전체 파일 준비 → 오프라인 진단에서 필수 11/11, 그래프/칠판 9/9, P4 3/3 및 현재 v159 SW 세대 확인. 비행기 모드 → 새로고침 → P4 필터/CSV/TXT·P6 그래프·기출 열기 → 연결 복귀. 파일 3개 확보는 작업대 실제 PASS가 아님.
7. **P6/P2/P3 회귀 실기**: Android Brave·S Pen으로 17개 차트의 직접 드래그·기울기·최고가격/최저가격, 빈 영역 세로 스크롤, E₀/E₁ 및 Undo/Redo를 검증. 타이핑 '가→각→강' 마지막 조합, 칠판 두 손가락 개입/취소 복구 확인. 공식 80문항/100분 모의고사와 1~5 선지·Ctrl+방향키·JSON 답안 복원을 검사.
8. **수기 PASS 기록**: P7 수기 검증표의 v159 2개 항목과 기존 기기 항목을 직접 실행한 후 PASS/FAIL/미확인으로 표시. '캐시 준비'는 실사용 PASS 아님. 자연스러운 AI TTS는 마지막 단계로 유지하고 실제 음성 테스트는 별도.
