### P2 — 한글 타이핑·IME

- 이미 로드되는 `ck-study-p6-v76.js`에서 브라우저용 `ck-typing-ime-guard-v155.js`를 주입.
- Android Brave 등 일부 한글 IME가 `compositionend` 뒤에 마지막 글자를 갱신하면서 최종 `input` 이벤트를 보내지 않는 경우만 한 프레임 안에서 감지하고 누락 입력 이벤트를 보완.
- 정상적인 네이티브 `input`이 도착하면 합성 이벤트를 보내지 않으며, 다른 입력칸과 분리된 편집기에는 관여하지 않는다. 앱의 타이핑 글자 색·정확도·학습기록은 기존 로직 유지.
- 실제 Android IME의 조합, 커서, S Pen 터치, 글라스 경계 점멸 문제는 실물 검증 전 **완료라고 단정하지 않음**.

### P3/P5 — 공식 연도별 80문항, 기출혼합 5세트 조작

- 앱 시험 작업영역 밖·텍스트 입력·IME 합성 중에는 단축키 비활성화. 브라우저의 Ctrl+숫자 탭 이동을 가로채지 않음.
- 100분 카운트다운, 일시정지, 제출 전 정답 보호, 채점 및 보류/오답/기록 데이터 구조 유지.

### P6-B — 모바일 그래프 직접 조작

- 17개 SVG 도형 내 움직일 수 있는 곡선에 **시각적인 D/S 손잡이(원형)** 와 44px 투명 손잡이 통로를 추가한다. 손잡이는 곡선의 변형 그룹 안에 위치해 곡선이 움직일 때 같이 이동.
- SVG 전체의 터치 차단을 없애고, 손잡이 또는 곡선 통로에서만 직접 조작. 빈 그래프 영역에서는 세로 페이지 스크롤 가능.
- 수요 D/공급 S를 구분하여 드래그하고, 모바일에서 직접 잡기 어려운 경우 **왼쪽 10 / 오른쪽 10** 버튼으로 독립적으로 도식 이동.
- 음수 방향 전환·영점 통과·Undo/Redo/초기화는 기존 80단계 한계의 히스토리에 묶는다. '10단위'는 실제 경제통계의 %가 아닌 도식적인 이동 정도.
- 기존 26개 도형/130개 사례 등록 및 예측→채점→전후 그래프 반영 구조 유지.

## 꼭 필요한 실제 수기 검증

1. **Android Brave + S Pen:** 도형차트에서 D/S 손잡이를 잡아 움직인다. 손잡이에서는 선만 움직이고 화면은 멈추며, 비어 있는 그래프 영역은 세로 스크롤할 수 있어야 한다.
2. **그래프 대체 버튼:** 수요 D/공급 S를 각각 선택해 10단위로 좌우 이동하고 E₀/E₁, 가격·수량 방향, 쉬운 설명·심화 설명, Undo/Redo/초기화가 일치하는지 확인.
3. **한글 타이핑:** 정상/문자만 모드에서 빠른 ㄱ→가→각 등 한글 조합을 입력·삭제·선택·수정하여 마지막 자모 누락, 커서 불일치, 글라스 경계 점멸이 없는지 확인. 문자만 모드에서 Enter·Space가 입력을 오염시키지 않는지.
4. **실전 모의고사:** 공식 80문항과 혼합 5세트 각각 숫자 1~5·Ctrl+←/→, 100분 시계, 과목별 40문항 채점, 과락 및 보류, 미응답, 백업·복원 확인. 입력칸에 커서가 있을 때는 Ctrl+방향키가 해당 입력칸 내 편집에만 쓰여야 한다.
5. **PWA:** 먼저 온라인으로 연습 기능을 로드한 다음 오프라인 전환·새로고침·재접속·부분 다운로드 실패를 비교한다. 사용자의 오답·필기·답안·PDF 개인 자료 삭제 금지.
6. **P4 해설:** 최근 5년 학습용 초안 400건과 실제 전문가 검수 0건이 명확히 구별되는지 확인하고, 2021년 전원정답·2022년 복수정답을 선지 전체의 참으로 오해하지 않도록 한다.
7. **P7 개인 실기 체크리스트:** PASS/FAIL/미확인으로 직접 기록. 다른 브라우저 탭에서 자동으로 서로 다른 기록을 덮지 않는지 확인한다.

실제 Android/Windows 기기 수기 확인은 진행 전까지 **NOT_RUN**. TTS는 최후 단계, Windows 실행파일은 이 웹 프로젝트에 필요 없으며 생성하지 않는다.
