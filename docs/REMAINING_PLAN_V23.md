# 원래 계획 대비 현재 운영 코드와 잔여 작업 · v23

기준일: 2026-10-29. 10월 27일 P0~P5 Phase Ledger와 현재 `index.html`, `engine.js`, 보조 모듈을 대조했다. 과거 다른 구현 폴더의 완료 문구만으로 현재 운영 기능을 완료로 인정하지 않는다.

## 이번에 끝낸 범위

- 공식 기출 본문·5선지·A형 최종정답 **800/800 (100%)**.
- 10개년 자동채점, 과거 5개년 타이핑 연도 선택 확대, 정답 지문 타이핑/TTS 792개. 전원정답 8개 제외.
- 기존 분필·S Pen·그림연상·17종 차트·계산문제·5세트 응용·뽀모도로·다크모드·PDF 펼쳐보기 유지.

## Phase별 확인표 기반 진행률

이전 66%/83% 추정치와 측정 기준이 달라 직접 비교하지 않는다. 아래는 각 Phase의 핵심 확인 항목을 5개씩 동일 가중치로 센 **운영 통합 체크포인트 비율**이다. 작업시간·제품 전체 품질·합격률을 뜻하지 않는다.

| Phase | 확인 완료 | 진행률 | 미완료 핵심 |
|---|---:|---:|---|
| P0 브라우저·저장 | 웹 공개/2과목/로컬저장/백업 = 4/5 | 80% | 장애·이전·복구 통합 검증 |
| P1 문제→개념 인출 | 기본 문제/150근거/전이/회상카드 = 4/5 | 80% | 800문항 전체 선지 근거·반례 확장 |
| P2 공식 기출 연동 | 본문/정답/예외처리/타이핑·TTS = 4/5 | 80% | 전체 다중 개념·관계 연결 |
| P3 오답·간격 반복 | 오답메모/기본 복습/수동 해소 = 3/5 | 60% | 적응형 연결·이력 기반 약점 선정 |
| P4 실전·통계 | 응용세트/과목별 채점 = 2/5 | 40% | 통합시험·보류/복원·장기분석 |
| P5 검증·확장 | 코드/배포 점검·기출 대조 = 2/5 | 40% | 기기 실기·범용 OCR·학습효과 검증 |
| 합계 | 19/30 | 63% | 위 잔여 항목 |

다음 개발 순서는 1~6의 실제 학습 흐름 통합 → 7~8 입력·저장 강화 → 9~10 기기·효과 검증이다. 동기화/계정 서버는 현재 로컬·서버비 없는 운영 원칙을 고려해 필수 범위에 자동 추가하지 않는다.
