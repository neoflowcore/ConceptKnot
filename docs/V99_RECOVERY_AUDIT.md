명칭 `verified: true`는 내부 스키마상 등록·확인 플래그입니다. 위 통계만으로 800문항의 그림, 수식, 법령 및 공식 시험지 전체가 전문가에게 검수됐다고 판단할 수 없습니다. 완전한 원문·형별·특수정답 검수는 계속 필요합니다.

재현: `node scripts/audit-official-bank.cjs` (사람 읽기용); `node scripts/audit-official-bank.cjs --json` (표준출력 JSON). 스크립트는 파일을 작성하거나 원본 문항·정답을 수정하지 않습니다.

## v99 구현 범위

- 집중 복습 상태(문항 ID·진행 위치·기억/재복습/건너뛰기·정답 공개 여부)를 해당 브라우저 탭의 sessionStorage에 자동 보존.
- 같은 탭 새로고침 후 복원, 중단/이어하기, 명시적 종료·임시 상태 삭제, 진행 요약 TXT.
- 기억 평가 직전 pending 기록을 남기고 정상 복원 시 최근 평가 시각과 대조해 중복 진행을 줄이기.
- 임시 저장 실패와 손상 기록은 사용자에게 구분하여 알림. 이미 저장한 실제 회상 평가는 메인 학습기록에 기록하며 임시 세션은 **전체 학습 JSON 백업에 포함하지 않음**.
- 집중 복습 자동 초점 복원, 과거 공식 문항 재로딩, 새 세션 시작 전 기존 진행 확인.
- 개인 학습 통계(7일/30일, 연도별 정답률, 점수 추이, 일별 활동) TXT 내보내기.
- 백업 restoreExtras가 알 수 없거나 선택 범위를 벗어난 키를 조용히 생략하지 않도록 검증. 16MB 파일 크기 상한(브라우저 저장공간의 실제 한도와 별개).
- 서비스 워커 설치의 병렬 리소스 요청을 최대 4개로 제한하고 캐시 데이터가 있을 때 오류 응답을 완화.
- 읽기 전용 기출 품질 진단을 화면과 CLI에서 확인 가능하게 구성. 2016~2025년 선택, 원문 검토 후보 상위 12문항, 해당 연도 전체 후보 TXT 추출.
- 기존 학습 화면에서 오답을 올바르게 해소한 3개 경로는 처리 시각도 갱신하도록 수정해 최신 복습 기록과 시간순 비교가 가능하게 함.

검증 표시 `visualReview: true`인 문항도 OCR 점수가 낮을 수 있으며, 이 값만으로 원문 불일치라고 단정하지 않습니다.
