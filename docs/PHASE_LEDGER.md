**종합 MVP 추정 약 66%** (위 Phase의 단순 평균 반올림). 사용자가 내일 바로 공부할 수 있는 '창작 연습문제→개념 인출' 루프는 동작하지만, **10개년 공식 800문항의 완전 자동 분석·복습은 미완료**입니다.

## Action Economy

- 개발 소스는 큰 묶음으로 기록하고 GitHub 커밋을 최소화합니다.
- `.github/workflows`를 추가하지 않습니다. push 기반 자동 CI, EXE/APK/ZIP 빌드, Vercel 자동배포를 활성화하지 않습니다.
- 사용자의 명시적 실기 검증/설치 아티팩트 요청 전에 릴리스 아티팩트를 만들지 않습니다.

## 다음 작업 우선순위

1. 2016~2025년 1차 두 과목 문항 800개 원문/답안, 형별·복수정답 검증 및 출처 메타데이터 확보.
2. OCR 분리 규칙 강화(원문 번호/선지 번호 혼동 방지)와 PDF 내장 텍스트 직접 추출 실험.
3. 1문항:다중 개념 연결, 5개 선택지:개념 근거 관계를 저장하고 연도별 반복 빈도 분석.
4. 실제 정답률과 복습 시점을 반영해 약점 문제 선정 개선.
5. 80문항 모의고사, 과락/평균 판정, 모바일 Chrome 실제 사용 실기 점검.

## S2 · 2026-10-27 칠판 및 그림 연상 구현

- 터키시 블루 칠판 배경, 흰 글자 상단 메뉴. 오늘의 카드가 홈에서 가운데, 학습 탭에서 왼쪽 고정 위치로 배치되며 작은 화면에서는 위쪽으로 전환.
- Inspora ticket-stub의 티켓 모티브를 참고해 별도 SVG 기하학 마크, 절취선, 양옆 홈, 카드 진입 움직임 구현. 정확한 물리 시뮬레이션 복제는 아님.
- 그림 연상 메뉴: 토지 특성을 네 개의 독립 SVG 장면으로 표시. 정답 확인 전 렌더된 화면과 접근성 대체문구에 정답 단어를 포함하지 않음. 의도적인 확인 후 개념 연결 공개.
- 핵심이론의 해당 카드에도 같은 그림 삽입. 애니메이션 정지/재생, 시스템 움직임 감소 설정, 사용자가 누를 때만 네 박자 소리 단서 제공.
- `node tests/visual.cjs`, `node tests/keyboard.cjs` PASS. Chromium 실행파일 부재로 시각적 브라우저 실기 미실행. 코드 구현과 실제 기기 검증을 구분.
- 추가 요청 S1/S2 코드 구현 2/5 단계(40%). S3 타이핑, S4 펜 필기, S5 TTS 미착수. 전체 MVP 수치는 기존 잔여 과제와 별도로 관리.

## S3 · 2026-10-27 분필 타이핑 기억

- 분필 타이핑 탭: 과목별 핵심이론 문장 선택, 따라 쓰기, 문장을 가린 능동회상, 명시적 원문 확인, 재작성.
- 모든 페이지 아래 경계 없는 자유 필기 공간과 얇은 회색 가로줄. textarea 기반 한글 IME 입력, SVG/이미지 아닌 실제 텍스트 미러에 분필 질감·등장 애니메이션 적용.
- 하양/노랑/분홍/연두 분필. Ctrl+1~4와 색 버튼 제공. 브라우저가 탭 전환으로 예약한 단축키는 웹앱에서 완전히 보장할 수 없어 버튼 대안 유지.
- 삽입·수정·삭제 시 글자별 색 유지. 과목별 자유 필기와 개념별 연습문장 로컬 저장, 기존 JSON 학습 백업에도 포함. 회상 모드로 바꿀 때 해당 연습문장 입력은 비움(자유 필기는 유지).
- `node tests/keyboard.cjs`, `node tests/visual.cjs`, `node tests/typing.cjs` PASS. 실제 브라우저 시각 검증·기기 IME·단축키 실기는 미완료. 기억 효과 개선의 실험적 측정은 하지 않음.
- 추가 범위 S1~S3 코드 3/5 단계(60%). S4 필압 필기, S5 TTS 남음. 빌드·배포·Actions 없음.

## S4 · 2026-10-27 S펜 손글씨 풀이

- 모든 페이지 하단 칠판의 텍스트 필기 아래 손글씨 캔버스. 10개년 OMR에는 연도·과목·문항별 독립 풀이 칠판 추가.
- Pointer Events의 pen pressure, coalesced input, pointer capture 사용. 필압 켜기/끄기, 기본 굵기, 4색 분필, 획 기반 실행 취소·다시하기, 지우개/펜 뒤집기(button 5), 현재 필기 삭제.
- 기본 touch 입력 배제(손바닥이 획으로 기록되는 것 방지). 명시적으로 손가락 입력도 허용 가능. 기기 수준 팜리젝션을 보장하지 않음.
- 문제+필기 전체화면: PDF 뷰어와 풀이 칠판을 함께 확대. 모바일에서는 세로 배치. 전체화면 API 미지원 시 화면을 덮는 CSS 모드 사용. PDF 내부에 직접 덧그리기/삼성 노트 앱 연동은 아님.
- 획 종료·화면 전환·앱 비활성화 시 로컬 저장. JSON 학습 백업에 손글씨 획 포함. 저장 용량 부족 시 실패 표시. 외부 PDF 자체는 로컬 저장하지 않음.
- `node tests/ink.cjs`, 기존 keyboard/typing/visual 검사 PASS. 실제 갤럭시 S펜 필압·지연·팜리젝션·브라우저 전체화면 실기는 미완료.
- 추가 요청 S1~S4 코드 4/5 단계(80%). S5 TTS 남음. Actions·빌드·설치파일 생성 없음.

## S5 · 2026-10-27 문제·정답 TTS 및 웹앱

- 문제·정답 듣기 탭: 한국어 음성 선택/미리듣기, 기본 1.5배속(0.75~2), 정지·일시정지·이어서 재생, 창작 연습 개별/과목 전체 재생.
- 음성 순서는 연도·과목·번호·문제 문장 → 최종정답 지문만. 오답 선택지/해설은 낭독하지 않음. 브라우저 기기 음성 사용, 여성/연령/음질은 기기 음성 제공 범위에 의존.
- 공식 기출은 PDF만 존재하는 문항을 추측해 읽지 않음. 원문 문제/5개 선지 등록·대조 확인 후 공식 답안으로 지문 선택. ①~⑤ 붙여넣기 분리, 복수정답 지원, 모두정답 문항 제외, 등록 문항 이어듣기.
- 800개 전체 지문 자동 구조화는 여전히 미완료. 음성 기능 구현 완료와 콘텐츠 확보 완료를 구분.
- 웹앱 manifest/아이콘/오프라인 앱 껍데기 캐시 추가. PC 로컬 index.html도 단일 파일 실행 가능. 외부 PDF와 일부 음성은 인터넷 필요. 기기/출처별 저장소는 별도이며 JSON 백업으로 이동.
- 테스트: keyboard/visual/typing/ink/tts 로직 검사 PASS. 실제 음색, S펜, 모바일 설치·백그라운드 오디오는 기기 실기 대기.
- 추가 요청 5단계 코드 구현 5/5. 전체 제품의 공식 기출 콘텐츠·기기 실기 완료율을 의미하지 않음.
- Vercel 정적 수동 배포 대상: neoflowcore's projects / conceptknot. Git 자동배포 비활성, GitHub Actions 없음, APK/ZIP 미생성.
