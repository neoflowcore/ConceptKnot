# ConceptKnot 개발 진척 / 현재 제한

2026-10-27 · v0.3 · 실제 로컬 구현과 미완료 범위를 분리한 내부 추정치. %는 테스트 통과율도, 합격 가능성도 아닙니다.

| Phase | 목표 | 구현된 내용 | 잔여 작업 | 추정 |
|---|---|---|---|---:|
| P0 | 브라우저 MVP/저장 | 단일 HTML, 2과목 전환, 로컬 저장, 10개년 시험 링크 | 배포 환경 실기 확인 | 95% |
| P1 | 문제→개념 인출 루프 | 30 기본문항, 150 선지판별근거, 30 전이문항, 기억 평가, 최초·재도전 구분 | 학습 난이도/반례 콘텐츠 확대 | 90% |
| P2 | 공식 기출 연동 | 10개년 원문 링크/OMR, 개념 매핑, OCR TXT 가져오기, 400문항/과목 커버리지 | 공식 지문 전체 구조화, 출제 근거 검증, 복수정답 재검토 | 65% |
| P3 | 오답·간격 반복 | 15분/1일/3일 복습, 오답 기록, JSON 백업 | 인출 데이터 기반 자동 난이도 조정, 동기화 | 70% |
| P4 | 종합 모의고사/통계 | 연도별 40문항 OMR, 기본 점수·진행 통계 | 자체 80문항 합격 모의고사, 장기 분석 대시보드 | 35% |
| P5 | 검증·자료 품질·확장 | 21개 로컬 Chromium 흐름 검사, 출처·실기 문서, 모바일 레이아웃 | 전 회차 원문 정확성 검수, 기기 실기, PDF 자동 OCR | 40% |

**종합 MVP 추정 약 66%** (위 Phase의 단순 평균 반올림). 사용자가 내일 바로 공부할 수 있는 '창작 연습문제→개념 인출' 루프는 동작하지만, **10개년 공식 800문항의 완전 자동 분석·복습은 미완료**입니다.

## Action Economy

- 개발 소스는 큰 묶음으로 기록하고 GitHub 커밋을 최소화합니다.
- `.github/workflows`를 추가하지 않습니다. push 기반 자동 CI, EXE/APK/ZIP 빌드, Vercel 자동배포를 활성화하지 않습니다.
- 사용자의 명시적 실기 검증/설치 아티팩트 요청 전에 릴리스 아티팩트를 만들지 않습니다.

## 다음 작업 우선순위

1. 2016~2025년 1차 두 과목 문항 800개 원문/답안, 형별·복수정답 검증 및 출처 메타데이터 확보.
2. OCR 분리 규칙 강화(원문 번호/선지 번호 혼동 방지)와 PDF 내장 텍스트 직접 추출 실험.
3. 1문항:다중 개념 연결, 5개 선택지:개념 근거 관계를 저장하고 연도별 반복 빈도 분석.
4. 실제 정답률과 복습 시점을 반영해 약점 문제 선정 개선.
5. 80문항 모의고사, 과락/평균 판정, 모바일 Chrome 실제 사용 실기 점검.
