## 1. 최종 UI 결정 — v178의 설명 단일 축약안을 대체

**위에는 기본 차트 하나만 남긴다.** 현재 `CK21Charts`의 17개 SVG 중 선택된 차트 1개가 실제로 조작 가능한 유일한 차트다. 아래에 중복 표시됐던 `CK141ConceptLab`의 차트, `CK142Theory`의 차트와 `CK158PolicyLab`의 별도 차트는 학습 기본 화면에서 숨긴다. 계산·교점·전후 비교 엔진과 학습 데이터는 삭제하지 않는다.

기본 차트의 선·끝점·곡선 위 점을 손이나 S펜으로 움직이거나, 평행이동·기울기·조건·방향을 조절하면:
1. **쉬운 예시 (1단계)**: 바로 아래에 전/후 P·Q (해당되는 경우)와 1~2문장의 생활 예시, 왜 바뀌었는지를 실시간 반영. 기본 펼침.
2. **심화 설명 (2단계)**: 클릭하면 같은 차트의 기울기·절편·탄력성/변화 방향과 주의할 원리를 짧게 표시. 기본 접힘(과도한 설명 방지).
3. **적용 문제 (3단계)**: 클릭하면 현재 변화 상태에 연계된 방향 판단 문제나 기존 기본 개념 문제 1개. 답을 선택하면 즉시 채점하고 해설 표시. 기본 접힘.

별도 '개념 → 쉬운 예시 → 심화 → 예측·채점 → 적용' 5단계와 중복 5문제 카드, 여러 SVG가 동시에 펼쳐지는 구성을 기본 화면에서는 제외한다. 예전 데이터·엔진은 향후 필요에 대비해 보존한다.

### 전후 수치의 근거·오해 방지
- 시장형에서는 `CK149GraphMotion.outcome()`의 이전 E₀/이후 E₁ 교점을 가상 좌표 `P=(315−y)/5`, `Q=(x−86)/5`로 표현. **실제 시장 가격이나 검증된 기출 정답·수치가 아님**을 반드시 병기.
- 관찰형(가격만 변화, 탄력성, 지대, 수익가격 등)에서는 수학적으로 계산하지 않은 실제 지표를 만들어내지 않고 **도식상 관찰 단계**만 제시한다.
- 수요·공급 동시 이동/기울기 변경 시 이전 공식 문항의 정답을 새 그래프에 강제 적용하지 않는다. 현재 두 직선 교점의 방향을 적용 문제에 사용한다.
- 적용 문제의 정답은 기존 800문항 원본을 수정하지 않으며 현재 세션의 퀴즈 답변만 일시적으로 저장한다. 별도의 시험 답안·오답기록과 혼합하지 않는다.

## 2. 검증·자료: 독립 고정 버튼 → 설정 내부

- 화면 오른쪽에 뜨는 `검증·자료` 독립 드로어의 바깥쪽 버튼을 학습·차트·오늘의 학습 화면에서 제거.
- 동일한 `#ck103-tools-dock` 내용, `CK115QA` 수기 검증기록, 오프라인 캐시 검사, 400문항/2,000선지 검수 도구를 **설정** 화면 하위 접을 수 있는 영역으로 이동한다. 이때 **내용을 복제·초기화하지 않고 같은 DOM을 이동**한다.
- 기존 저장 키와 PASS/FAIL 기록, 해설 초안, 오답 데이터, 공식 문제 원문은 변경하지 않는다.
- 설정 페이지가 새로 렌더링되어도 도구의 DOM을 복구한다.

## 3. 좁은 화면: 칠판 이동 버튼 위·아래만

- 기준은 기기 종류가 아니라 **브라우저/웹앱 가시 폭 850px 이하**. Android 모바일과 PC 창을 좁힌 경우 동일.
- 좌우 교환 버튼과 좌우 폭 조절, 칠판 접기 버튼은 숨기고 **칠판 위로 · 칠판 아래로** 2개만 남긴다. AI 보조/필기도구 등 칠판 이동 기능 밖의 버튼은 보존한다.
- 폭이 좁아질 때 보드와 학습 본문을 한 열에 배치. 기존 좌우 교환 상태가 저장돼 있어도 화면 순서를 뒤집는 부작용 금지.
- 오래된 `칠판 접기` 상태 때문에 화면 좁힘 시 칠판이 사라지지 않게 하고, 상·하 위치 버튼은 각각 직접 위치를 확정한다.
- 850px 초과에서는 기존 가로 2열 UI와 관련 이동·폭 조절 기능을 유지한다.
