- 2020년은 이전 원본 PDF 본문 대조·검증 기록을 복원하고 최종정답 80개를 다시 확인. 9번의 두 열 항목, 30번의 분수·지수식은 이번에도 원문 이미지 확인. PUA 특수문자 없이 읽을 수 있는 텍스트를 사용.

## 범위와 해석
