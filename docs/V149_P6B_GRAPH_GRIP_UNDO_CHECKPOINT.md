# ConceptKnot P6-B v149 — 17 도식 선 직접 조작 및 E0/E1 정확화

**프로젝트**: ConceptKnot (DoCut 제외)
**기준선**: \`main\` v148 \`be69daf364ccf42dd6d1fed143327819433b3b0f\`.
**범위**: 기존 17개 SVG 경제학 도식과 P6-B 비교 학습 UI. 현재 전체 학습 앱을 새 엔진으로 교체하지 않음.

## 문제와 개선

v148에서는 **17개 기본 도식의 화면 아무 곳이나 터치해도 스크러버가 이동**할 수 있었다. 드래그로 선의 방향을 뒤집었을 때 균형 E1 표시가 원래 가정의 정적 이동량을 재사용해 해설과 어긋날 여지가 있었다. 이전/다시/초기화도 통합 도식 17개에는 없었다.

v149는 다음 계약을 적용한다.

1. SVG의 실제 곡선 \`getTotalLength/getPointAtLength/getScreenCTM\`을 사용해 **잡은 선의 주변**만 터치 타깃으로 처리한다. 브라우저에서 해당 API를 지원하지 않으면 각 도식의 학습용 폴리라인 좌표로 대체한다. 빈 공간 터치 시 그래프 상태는 수정하지 않는다.
2. 스마트폰 뷰포트 크기·레터박스 보정과 35px 터치/20px 마우스 허용 거리. 가로·세로 포인터 움직임을 곡선 방향에 맞춰 도식 위치로 환산한다. 실수로 다중 포인터가 들어오면 기존 드래그를 유지한다.
3. 수요·공급 단일 시나리오는 선이 왼쪽/오른쪽으로 넘어갈 때 방향을 자동 변경. 양쪽 선이 있는 동시 변화 도식에서는 **수요 D와 공급 S를 개별적으로 선택·이동**하고 서로 다른 상태를 유지한다.
4. 수요·공급 SVG에서 E0와 E1 교점의 위치를 도식 선 이동량에서 **매번 새로 계산해 시각적으로 표시**한다. 고정된 균형점을 실제 데이터로 표기하거나 도식 진행률을 실제 가격 변화율이라고 주장하지 않는다.
5. 이전 E0 곡선 점선, 현재 E1 곡선 실선, 두 교점 연결선으로 변화가 보인다. 나머지 비이동형 도식은 곡선 자체를 억지로 바꾸지 않고 **곡선 위의 관찰점**을 움직이며 전후 E0/E1로 구분한다.
6. 도식별 메모리 상태(최대 80회 Undo/Redo), 초기화, 스크러버·키보드 입력 동기화. 포인터 취소·앱 비활성화·창 포커스 이탈 시 커밋되지 않은 드래그는 원복된다. 시험/노트 저장소 키를 읽거나 쓰지 않는다.
7. 3단계 설명은 그대로 **① 개념 ② 쉬운 예시 ③ 심화** 전개. 동시 이동은 실제 D/S 선택 방향과 움직임 상태에 따라 시나리오를 나눠 기출 원문의 원래 정답을 잘못 일반화하지 않는다.
8. 기존 3주제 수치 실험실과 6개 심화 계산 모델, 공식 A형 800문항, 개인 칠판·OCR·타이핑, 여성 TTS(최종 단계)는 수정하지 않는다.

## 검증 경계

**프로그램의 시뮬레이션 테스트와 사용자의 실물 Android/Brave·S Pen 사용성 PASS는 다르다.** 배포가 READY여도 HTTP 200뿐 아니라 실제 메인 HTML·모듈·CSS·SW를 전체 바이트 크기로 확인한다.

수기 실기: 17개 차트마다 선 가까이에 손가락을 놓고 좌우 및 위아래 이동, 빈 공간의 움직임이 값에 영향 없는지, E0 점선·E1 실선·3단계 설명, 단일 D/S 반대 방향, 둘 다 있는 차트에서 D와 S 별도 이동 및 초기화·이전·다시, 탭 이동 후 상태 보존, 다크모드, 페이지 바깥 스크롤, TTS/시험 답안 불변을 확인한다. 실제 기기 테스트 전에는 \`NOT_RUN\`으로 기록한다.
