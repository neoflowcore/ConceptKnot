# ConceptKnot v133 · 모의고사 3대분류 통합 선택 UI · 100분 카운트다운

작업 기준: 2026-11-07, 기준 `main` v132 커밋 `51e6e0d9b43592cf65576f1cb5af82f1c3d10f86`.

## 변경 목적과 원칙
기존 모의고사 탭에서 CK20 자체 기출 응용 연습 5세트, CK129 10개년 공식 기출혼합 5세트, CK82 공식 80문항 실전 10개 연도가 별개의 큰 카드로 수직 누적되어 스크롤이 길어지고 시험 선택 UX가 혼동되던 문제를 해결한다. 사용자가 첨부한 원래 2열 시험 화면(문제 카드 왼쪽, OMR 문항 버튼 오른쪽)의 스타일은 재사용한다.

## 세 대분류 · 선택 후 2차 단계
- **모의고사**: 기존 기본 15문항, 1~5세트(각 80문항)의 연습을 원본 CK20 UI에서 그대로 보여준다. 조합형/선지재배열 방식은 기존 선택과 기록을 유지한다.
- **기출혼합**: 기존 CK129 공식 A형 2016~2025에서 고정 배정한 1~5세트(각 80문항), 100분 OMR/채점/백업 및 기록 복원을 그대로 사용한다. 변형 창작 문제가 아닌 공식 A형 원문 재배열이다.
- **공식 통합 실전**: 기존 CK82 2016~2025 연도별 A형 80문항/100분 OMR/과락·평균 채점·성적 이력을 그대로 사용한다.
- 새 대분류 카드에는 각각 아이콘과 간단한 제목만 표기하며, 선택한 대분류에 해당하는 2차 세트 또는 연도 버튼만 표시한다. **하나의 유형만 화면에 표시**한다.
- 통합 시험 선택 바로 아래 선택한 원래 문제+OMR UI를 유지한다. **개인 약점 분석·다시 풀기 CK131 영역은 이들 모든 화면 아래**에 보이도록 앵커를 옮겼다. 개인 약점 분석은 기존 CK129 제출 기록 기반이며, 공식 채점 또는 원본 기록을 변경하지 않는다.

## 시간 / 개인기록 안전
- CK82와 CK129 실전의 남은 시간은 각 엔진의 실제 `remainingMs`로만 표시한다. 이를 별도 100분 타이머로 다시 시작하거나 덮어쓰지 않는다.
- 원래 CK20 모의고사는 시간 기능이 없으므로, **100분 연습 카운트다운**을 `sessionStorage['ck133-practice-clock-v1']`에 따로 추가한다. 사용자 직접 시작·정지·재개·초기화로 조작하고, `deadlineAt`에 따라 렌더/탭 왕복에도 시각을 복구한다. **CK20 답안·채점은 자동 제출하거나 변경하지 않는다.** 타이머의 `0:00`은 시간 만료 알림이다.
- 세 시험의 기존 `localStorage` 답안 키(`recallgraph-first-exam-v1`, `ck82-exam-sessions-v1`, `ck129-mixed-sessions-v1`)와 CK131 분석 키는 보존한다.
- 선택 중인 대분류만 `sessionStorage['ck133-exam-mode-v1']`에 보관한다. 새 탭에 기존 선택이 없을 경우 진행 중인 CK129 또는 CK82 시험을 우선 표시해 재개 길을 열어 둔다.
- 페이지 전환, 별도 유형 전환 또는 비활성 탭은 공식 실전 데드라인을 멈추지 않는다. 별도 모의고사 타이머의 '시간 정지'만 동작을 일시 정지한다.

## 수동 실기검증
1. **먼저** 통합 학습기록, CK82 공식 실전 답안, CK129 혼합 시험 JSON, PDF S Pen 필기, CK80 해설·개인자료 등을 각각 백업한다. 브라우저 사이트 데이터·Storage/캐시를 일괄 삭제하지 않는다.
2. 모의고사 탭에서 **정확히 세 개 아이콘 대분류**가 표시되는지 확인: 모의고사(기본+1~5), 기출혼합(1~5), 공식 통합 실전(2025~2016).
3. 유형별 첫 번째/마지막 세트 선택, 현재 세트 강조 유지, 다른 유형으로 이동 후 되돌아오기를 시험. **한 번에 한 시험 문제판만 보이고 OMR은 오른쪽에** 있어야 함.
4. 모의고사 100:00 시작→1분 뒤 99:00→시간 정지→다른 탭 왕복→재개→초기화. 채점된 원래 모의고사 답안에는 변화 없어야 함.
5. 기출혼합 2세트 80문항, 공식 2020년 A형 80문항 선택·시작, 실제 100분 계수·일시정지·응답 저장·OMR·제출·채점·기록 복원·브라우저 새로고침 확인. 공식 인정 정답은 제출 전 보여주면 안 됨.
6. CK129 1회 이상 제출 후 개인 약점 분석·다시 풀기 섹션이 선택된 시험 문제판 **아래**에 보이는지 확인. 오답 필터와 선지 다시 선택, 근거·원문 링크와 TXT 저장, 기록 불변 확인.
7. Android Brave 360px/Windows Brave에서 3개 분류, 반응형 2열/1열 OMR, 상단 설정 고정, S Pen/펜버튼 지우개와 TTS를 확인하고 사용자가 수기 실기검증표에 결과를 기록.
8. 설정 오프라인 진단에서 현재 `v133` SW, 최소 11/11, 혼합 2/2, 복습 2/2, 통합 선택기 2/2를 확인. 신규 소스에서 변경한 HTML/JS/CSS 경로가 모두 200 응답인지 확인.
9. Node 로컬 수동 실행 시 `node --test tests/v133-unified-exam.test.cjs` 와 `node scripts/check-release-readonly.cjs`를 한 번 실행한다. 코드 격리 테스트는 실제 기기 검증과 분리해 기록한다.
