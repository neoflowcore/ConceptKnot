# ConceptKnot v124 — 4,000선지 근거 패킷·안전한 교차감사·오프라인 캐시 정합성

**복원 기준:** 2026-11-05, GitHub `main` v123 `0605f26ad6f846ce8d42d51e52c0fc1d059a15d5`. 브라우저 운영 배포는 마지막 조회 시 v115 `4a12a9fb7dbc0e9191539cc3b6d8bbeed92dc1f2` READY. GitHub 코드 업로드와 운영 배포는 별개이다.

## 수정한 구체적 오류

- v123의 `renderCrossAudit`에서 `(row.special='all'?...)` **대입 연산**을 발견. 16개 카드 출력 시 일반 문항도 전원정답이라고 잘못 보이고, 교차검사 스냅샷이 변형되어 내보내기를 실패시키는 오류였다.
- 이를 `row.special==='all'`로 고쳤다. 저장한 교차검사 보고서의 문항·선지 배열을 `Object.freeze`로 동결해 이후 다른 화면 코드가 검수 유형과 출처 상태를 임의 변형하지 못하도록 했다.
- 회귀 검사: 모의 800문항 중 실제 전원정답 1건만 전원정답으로 표시, 화면 렌더 전후 개인 교차 보고서 비교 유지, TXT 다운로드 정상 요청 확인. 채점 인정 5개와 선지의 법적/사실적 참·거짓을 동일시하지 않는다.

## 사용자가 직접 진행할 수 있는 800문항·4,000선지 근거 연구 도구

화면: **내 학습 데이터 안전 점검 → 800문항·4,000선지 개인 근거 교차점검**. 검사 버튼을 사용자가 직접 눌러야 데이터를 읽고 결과가 표시된다.

1. 연도별/필터별 검사 목록의 각 카드에 `①~⑤ 상세 비교`를 추가했다. 원래 문제의 5개 선지, 공식 채점 인정 번호, CK83 개인 진위판단·근거·출처, CK80 개인 해설 판단·근거·출처를 **서로 구분**하여 표시한다. 어떤 개인 메모도 공식 검증 완료로 승격하지 않는다.
2. 양쪽 출처 미입력/참-거짓 판단 충돌/출처 문구 차이가 있는 선지를 구별한다. 사용자 작성 텍스트는 DOM `textContent`로만 출력한다. 단순한 출처 문자열 차이는 오류 확정이 아니라 대조 후보이다.
3. `CK83 선지 메모`, `CK80 해설 초안` 버튼을 별도로 제공한다. CK80은 기존 공식 분석 대화상자를 연 뒤 개인 해설 편집기를 열며, 기존 미저장 이동 차단 가드를 그대로 적용한다.
4. 검토할 문항을 목록에서 **최대 5문항 선택**할 수 있다. 선택이 없으면 현재 연도/조건 필터에서 상위 **1·3·5문항**으로 TXT 검토 패킷을 생성한다. 패킷은 공식 문제 원문·5개 선지·채점 인정·기존 개인 메모 양쪽·원문 URL·시험 당시 시행일과 PDF 페이지의 수기 확인란으로 구성된다.
5. 빈/중복/6개 이상/지원하지 않는 문항 ID 또는 일부 공식 원문 누락 시 패킷 생성 금지. 별도의 공식 해설을 합성하거나 개인 기록을 두 저장소 사이에 복사하지 않는다.
6. TXT/CSV 다운로드 직전에는 800/800 공식 등록, 미저장 편집 상태, CK83의 브라우저 원본 저장값과 앱 메모리 상태, CK80 개인 기록, 기존 교차 보고서의 일치 여부를 다시 검사한다. 오래된 보고서는 무효화해 손상된 개인 데이터가 검증된 것처럼 내려받아지지 않도록 한다.
7. TXT/CSV는 **명시적 클릭에만 생성**된다. 원본·정답·사용자 학습 기록의 자동 삭제·초기화·원격 전송·스키마 이행 없음.
