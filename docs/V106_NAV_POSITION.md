# ConceptKnot v106 · 모바일 상단 탭 위치 보존

- 증상: 오른쪽으로 스와이프한 뒤 '오답 복습'을 누르면 본문만 해당 탭으로 전환되고 상단 탭은 첫 번째 '오늘의 학습'으로 이동.
- 원인: v56 드래그 모듈이 새 DOM에 바인딩할 때 이전 scrollLeft를 보존하지 않음. v5 내비게이션에도 별도 활성 탭 가운데 정렬 코드가 남아 있었음.
- 해결: scrollLeft와 클릭 탭의 화면 X 좌표를 캡처하여 탭 전환 DOM 재생성 시 복원; 브랜드 로고 너비 애니메이션 중 이벤트 기반 ResizeObserver/1회 지연 보정; 새 수동 터치/드래그 시 보정 취소.
- 키보드/프로그램 탐색에서는 임의로 선택 탭 중앙 정렬을 하지 않고 사용자 설정 스크롤 위치를 유지.
- CSS scroll anchoring 비활성, 신규 유휴 requestAnimationFrame 루프 없음, 기존 오른쪽 설정 메뉴 고정 유지.
- 서비스워커 v106 갱신 및 nav-drag 소스 무캐시로 배포 뒤 구 JS 잔존 위험 낮춤.
- 기존 학습 데이터, 공식 800문항, 4,000선지, 해설과 TTS/PDF는 수정하지 않음. GitHub Actions/자동 Vercel 배포 금지 및 설치 아티팩트 없음.

## 실제 기기 검증 대상

1. Android Brave / 작은 PC 화면: 리본을 오른쪽으로 스와이프하고 '오답 복습' 터치 → 같은 가로 지점에 해당 탭이 남고 오답 노트가 열려야 함.
2. 다음 '학습 계획', '정리본' 선택 후에도 0px로 복귀하지 않는지 확인.
3. 터치 드래그·마우스 드래그·키보드 단축키·로고 펼침/접힘·다크모드·화면 회전 재검증.
4. PC/모바일 실제 브라우저 확인은 소스 모의 테스트 결과와 구분한다.
