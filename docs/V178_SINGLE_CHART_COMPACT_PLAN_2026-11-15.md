## 1. 이번에 확정한 개발 목표

**현재 앞에 보이는 차트 하나를 잡아 움직이면, 변화 전후의 예시값과 그 이유가 즉시 바뀌는 화면.**

기존 ① 개념 ② 쉬운 예시 ③ 심화 설명 카드, 반복되는 상세 해설, 다섯 가지 사례·퀴즈, 불필요한 장문 설명을 기본 화면에서 없앤다. 이 기능들을 위해 만든 계산 코드·데이터는 삭제하지 않는다.

기본 UI:
1. **차트 1개** — 점선 E₀(변화 전)와 실선 E₁(변화 후)을 한 좌표계에서 비교, 곡선/점/손잡이 직접 드래그.
2. **결과값 1~2개** — 전 값 → 후 값과 상승·하락·불변. 시장형은 가격·거래량, 다른 계산모형은 해당 모형의 대표 값.
3. **짧은 변화 설명 한 줄 + 실생활 가상 예시 한 줄** — 심화 단계를 기본으로 강제하지 않음.
4. **초기화 / 이전 / 다시** — 유지. 고급 기울기·세부조작 버튼은 '추가 조작' 선택 영역에 접기.

전체 화면에서는 더 많은 도식을 나열하는 대신 이미 보이는 한 도식을 조작한다. Android·Brave·S펜에서는 선/점에 실제로 손을 놓았을 때만 조작하며, 빈 곳에서는 페이지가 정상 스크롤되어야 한다.

## 2. 적용 범위와 계산 규칙

| 범주 | 기존 코드 | 변경 표시 |
|---|---|---|
| 기본 SVG 17종 중 시장형 8종 | `CK149GraphMotion.outcome` | E₀/E₁ 균형교점의 가상 가격 P·수량 Q, 변화 방향 |
| 기본 SVG 중 관찰형 9종 | `CK149GraphMotion.explainObservation` | 움직인 관찰점 및 도식 단계. 거짓 시장가격을 산출하지 않음 |
| 계산형 3주제(수요공급·탄력성·비례) | `CK141GraphMath`, `CK144ChangeExplain` | 계산 결과 핵심값 1~2개와 간결한 기존 예시 |
| 추가 계산형 6주제 | `CK142Models`, `CK144ChangeExplain` | 해당 모형의 계산 결과 핵심값 1~2개와 간결한 기존 예시 |

시장형 SVG는 이미 존재하는 직선 교점을 기반으로 하며, x축의 가상 수량 Q는 `(x−55)/5`, y축의 가상 가격 P는 `(315−y)/5`로 환산한다. **이것은 그림의 임의 학습 좌표를 숫자로 표현한 예시이지, 실거래 가격·검수된 기출 수치·경제적 변동률이 아니다.** 유효한 범위를 벗어나면 '도식 밖'으로 표시한다.

- 수요만 이동, 공급만 이동, 둘 동시 이동, 기울기 변경은 기존 E₀/E₁ 계산을 재사용해 실시간 표시한다.
- 기존 관찰형 차트는 도식 단계만 표기한다. 잘못된 탄력성·지대·가격·현재가치 숫자를 만들어 넣지 않는다.
- 3+6 계산형에서 실제 계산한 전후값은 기존 모형의 계산을 재사용한다. 그림을 움직일 때 숫자 카드가 동기화되어야 한다.
- 학습용 가정은 공식 800문항 정답·선지·법령 검수 완료 자료로 포장하지 않는다.
