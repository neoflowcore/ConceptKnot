# ConceptKnot TTS 전면 재구축 — 실행표 v2.0 / T0–T8

**기준:** 2026-11-08, 기존 v136 설계의 실제 구현 게이트화. 코드 기준선 `8a5408591273c1060c37a0ab38733cda26bcf65c`.  
**제품 목표:** '음성학습'에서 **재생 누르면 소리**. 별도 'AI 여성 음성 준비' 단계를 강요하지 않는다. 사용자 기기에 한국어 음성이 없으면 사유와 대안을 명확히 알린다. **모델 파일이 없는 첫 방문에 0초 오프라인 AI 합성을 약속하지 않는다.**

## A. 현재 장애원인 분해표

| 경로 | 코드 관찰 | 가능한 실패 | 1차 처리 |
|---|---|---|---|
| OS TTS | `speechSynthesis.getVoices()`에서 ko 음성 못 찾으면 시작 전 종료 | 비동기 목록·미설치·언어 선택 | 보이스 목록 지연과 미설치를 구분, 언어 기반 즉시 시도와 시작 감시 |
| Supertonic | `neural-tts.mjs`가 외부 허깅페이스에서 약 380MB ONNX와 F1~F5 스타일 로드 | CORS·네트워크·저장·메모리·모델 초기화 | 새 관리형 모델 URL/고정 SHA·실패 복귀·다운로드 정책 |
| 재생 상태 | 구형 `ttsPlay`, v76 `ttsPlay` 재정의, `neuralSpeak` 재정의·토큰 복수 | 중지 후 늦은 재생, 이어듣기 범위 불일치 | 한 세션ID로 통합, 중복 이벤트 가드 |
| 음량/배속 | 시스템 TTS pitch/rate + AI 합성 rate | 기기 별 동작 차이 | 실제 소리·자막·재생 이력 측정 |
| 기출 원문 | v125 공식 `RECALL_OFFICIAL` 경로, 특수정답 제외 규칙 | 사용자 메모·OCR로 공식 낭독 오염 | 공식만 재생, 3가지 모드와 예외별 테스트 |

**사실과 추정 분리:** 위는 코드 경로에 대한 점검이다. Android Brave 사용자 기기의 구체적 원인은 실물 로그가 없으므로 **미확정**이다.

## D. UX 화면 계약

1. 화면 이름: **음성학습**; 도형차트 오른쪽에 배치 (v136 완료).
2. 기본 영역: 큰 **▶ 듣기**, 일시정지, 정지, 다시 듣기/이어듣기, **1.5배**, 읽기 방식(정답/문제+정답/전체), 연도·과목, 문항 선택.
3. 음성 표시: '기기 한국어 음성', '고음질 AI 여성 음성(로컬 모델 준비 완료)' 등 실제 상태 중심. 보이스의 성별을 API 이름만으로 확정하지 않음.
4. **'AI 여성 음성 준비' 버튼을 기본 UX에서 제거.** 다운로드가 반드시 필요할 땐 수신량·저장공간·네트워크 안내를 별도 고급 영역에 제공.
5. 재생 진행: 진짜 onstart를 받기 전 '재생 중' 단정 금지. 음성 오류나 시간초과에서 '완료'로 넘기지 않음.
6. 사용자가 음성 학습을 멈추면 모델 준비 중이라도 **늦게 음성이 튀어나오지 않게** 세션 token/cancel 검증.

## E. 콘텐츠·복습 연동
- 공식 A형 `RECALL_OFFICIAL[y-n]` 원문과 `correct`만 재생; 사용자 OCR·정답 입력·해설 초안이 공식 자료를 덮어쓰지 않는다.
- 정답만/문제+정답/문제+전체선지 모드를 공개 명칭과 실제 세그먼트가 일치하게 구현.
- 2021–2025 해설 초안 32/400과 선지 감수 0/2000을 공개된 '검증된 해설'로 안내하지 않는다.
- 북마크는 `year/number/mode/scope/at`로 유지, 다른 시험 화면을 갑자기 덮어쓰지 않는다.

## F. 장치 시험표와 실패·성공의 차이

| 장치/상태 | 기대 | 성공 증거 |
|---|---|---|
| Windows Brave / 한국어 OS 음성 설치 | 첫 클릭 후 음성 | 소리 녹음 또는 사용자 현장 PASS |
| Android Brave / voice 목록 지연 | 목록 비어도 시작시도·정확한 오류 | 이벤트 순서(초기 0→voiceschanged→onstart/error) |
| Android Brave / OS 한국어 음성 없음 | 명확한 안내 + AI 1회 다운로드 선택 | 무음 완료 0 |
| Supertonic 캐시 없음 / Wi‑Fi 없음 | 기본 기능 영향 없음 | 앱 정상 실행·개인 백업 원문 일치 |
| Supertonic 캐시 있음 / 오프라인 | 다운로드 없이 재생 | 실제 AI 음성, 체크섬·캐시 세대 |
| 40/80문항 연속·100분 동안 탭 전환 | 중복 음성·오답 누출 없음 | 재생/중단/북마크 로그와 정답 인수표 |

**성능 측정:** 클릭→첫 음성 onstart(ms), 클릭→실제 audible(ms, 실기), 40문항 누락율, 파일 다운로드 MiB, 최초/재방문 캐시, 평균/최대 RAM. 수치는 측정 전에는 기입하지 않는다.

## H. v137 착수 로그 — T1 일부 코드 반영 (실기 PASS 아님)

- `index.html`의 v76 네이티브 경로: OS 보이스 목록이 빈 배열이거나 예외이면 기존처럼 즉시 종료하지 않고 사용자 클릭 안에서 `lang='ko-KR'` 기본 보이스로 합성 시도.
- 리스트가 이미 제공됐는데 한국어 보이스가 하나도 없는 경우는 외국어 보이스를 자동으로 낭독하지 않고 OS 한국어 설치 안내.
- `SpeechSynthesisUtterance.onstart`를 받은 뒤에만 첫 소리 시작 이벤트를 표시. 7초 동안 onstart/onerror가 없으면 해당 문장 재생을 건너뛰지 않고 오류 표시. start 없는 end 이벤트도 완료로 처리하지 않는다.
- 중간에 보이스 목록이 채워지면 다음 세그먼트에서 선택 보이스를 다시 조회.
- `tests/v137-native-voice-guard.test.cjs`를 신설. 격리 JS 모의 7건(목록 0/예외/외국어만/재생 차단/무응답/시작 없는 종료/3문장 연속) 실행 결과 **7/7 PASS**. 이는 실제 OS가 한국어를 출력했음을 뜻하지 않는다.
- 여전히 `neural-tts.mjs`는 외부 모델을 수신하며, AI 여성 음성 자체 호스팅·원클릭 캐시·실물 소리/메모리 검증(T3–T7)은 **NOT RUN**.
