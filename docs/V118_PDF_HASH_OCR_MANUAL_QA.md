# ConceptKnot v118 — PDF SHA-256 필기 보관함 · 한국어 OCR 초안 · 수기검증 확장

기준선: `neoflowcore/ConceptKnot` `main`, v117 `9fdfd7252c88cd72b938f0a64a08933f06426211`. 개발 승인 범위: 코드 수정·GitHub 업로드. **자동 GitHub Actions·설치 아티팩트(EXE/APK/ZIP)·자동 운영 배포 금지**.

> **구현된 코드 및 제한 검증 기록**이다. 실제 Android Brave·S Pen·PDF·한국어 OCR 실기 PASS를 의미하지 않는다. 공식 기출 800문항/4,000선지의 법령·해설 근거 전문 감수도 완료하지 않았다.

## 구현 변경

1. **같은 파일명·파일 크기의 PDF 필기 충돌 차단:** 사용자 업로드 PDF의 전체 bytes에서 SHA-256을 계산해 `ck15-ink:v118:<연도>:sha256:<해시>` 키로 로컬 필기를 구분. 해시를 계산할 수 없으면 안전을 위해 해당 업로드 파일의 로컬 필기 자동 저장을 중단하고 JSON/PDF 수동 백업을 안내한다.
2. **이전 필기 보존 마이그레이션:** 기존 v117의 `ck15-ink:<연도>:file:<인코딩된 파일명>:<크기>` 보관함에 필기가 있으면 원본을 삭제하거나 자동 이식하지 않는다. 사용자가 현재 PDF 원본과 필기가 맞는지 판단한 뒤 확인할 때만 SHA-256 보관함에 **복사**. 이전 저장본은 원형 유지. 다른 파일이면 취소. 손상된 이전 기록은 원본 백업 기능으로 보존하도록 안내.
3. **OCR용 PDF 렌더링:** 현재 PDF 한 페이지를 최대 1,600 × 2,000 픽셀, 약 300만 화소 이하로 캔버스 생성. 다른 문서로 전환하면 요청을 무효화한다.
4. **이미지/스캔 PDF 수동 OCR:** 이미지 PNG/JPG/WebP/BMP 또는 PDF 왼쪽·오른쪽 페이지를 선택해 한국어+영어 OCR. [Tesseract.js 7.0.0](https://www.jsdelivr.com/package/npm/tesseract.js) API·Web Worker 사용. 최초 엔진/언어 다운로드에는 인터넷 필요. 브라우저에서 문자 인식을 수행하고 사용자 이미지 자체를 별도 서버 API로 제출하지 않음. 탭 전환·숨김·중단 시 worker 종료 시도.
5. **개인 초안 편집:** OCR 추출 글을 직접 수정하고, `①~⑤` 선지 추정 분리 표시, TXT 내려받기. 인식 결과가 공식 원문·정답·해설에 자동 등록되지 않는다. 필기는 PDF와 독립, OCR 초안 역시 원문 검증 전 개인 자료에 불과하다.
6. **OCR 초안 로컬 보존:** `ck118-personal-ocr-draft-v1` 키로 자동 저장·새로고침 복원. 손상된 저장본/다른 탭 편집 충돌 시 덮어쓰기 차단, 수동 TXT 또는 원본 JSON 보존 가능. 일반 `내 학습 데이터 JSON` 백업·복원에 OCR 초안을 포함하도록 `CK86Integrity` 검사기와 HTML 키 목록을 함께 갱신.
7. **수기검증표 19항목:** 기존 15개는 유지, 내용 해시·이전 필기 이관·PDF OCR 중단·이미지 OCR/초안 백업 4항목 추가. 종전 `ck115-manual-device-verification-v1` 저장 키/스키마는 호환 유지.
8. **오프라인 웹앱:** HTML·서비스워커 자산 URL을 v118로 정렬하고 OCR JS/CSS와 수정된 진단 자산을 캐시에 편입. OCR 엔진·언어 파일은 외부 CDN에서 필요할 때 로드하므로 완전 오프라인 OCR은 보장하지 않음. `vercel.json.git.deploymentEnabled=false`, `.github/workflows` 없음 유지.
9. **저장 실패 방지:** 기존 v117의 필기 저장 충돌·수기 백업 보호를 유지하고, 기존 PDF에 미저장 필기가 있을 때 사용자 파일 교체 이벤트까지 캡처 단계에서 차단.

## 알려진 제한

- **OCR의 품질은 이미지 선명도, 도표, 분수, 아래첨자, 스캔 방향에 따라 달라진다.** 반드시 원본 문제·5개 선지·수식·그림을 수기 대조해야 한다.
- OCR은 브라우저 내에서 수행하지만, **Tesseract 라이브러리 및 언어 파일을 외부 CDN에서 다운로드**한다. CDN 차단/오프라인/모바일 메모리 부족 시 실패할 수 있다. 기기별 실행·중단·메모리 회수 실기 필요.
- 변경 파일은 GitHub 소스에만 존재하며, 자동배포가 비활성이라 운영 배포는 **명시적 수동 배포 전까지 v115**이다.
- 사용자 업로드 PDF 파일의 전체 SHA-256 계산은 파일 크기에 따른 지연이 있을 수 있다. 구형·보안 제약 환경에서 `crypto.subtle` 지원이 없으면 자동 저장 대신 수기 백업을 안내한다.
- 저장 키 마이그레이션은 이전 원본을 삭제하지 않고 **복사만** 한다. 같은 이름/크기의 다른 PDF에 잘못 붙은 과거 필기의 소유권은 자동으로 검증할 수 없으므로 복사 여부는 사용자가 원문을 보고 판단한다.
- 일반 학습 JSON에는 OCR 초안을 포함하지만, **PDF 필기 JSON 자체는 PDF 화면의 별도 백업/복원**이 필요하다. 브라우저 사이트 데이터를 삭제하면 두 종류의 로컬 자료가 사라질 수 있다.

## 코드 검증 기록과 검증 명칭

- GitHub HEAD 원문과 파일/모듈이 결합된 자산 경로·JS 파싱·별도 V8 함수 모의 시나리오 검사.
- `tests/v118-pdf-fingerprint-ocr.test.cjs`에서 같은 이름·크기 PDF의 다른 SHA-256 분리, 이전 필기 확인 복사·취소, 불가능한 해시 차단, 캔버스 치수 제한, 선지 추정 분리, 백업 검사기, PDF 파일 교체 보호 검사를 위한 **수동 Node 테스트 정의** 추가.
- v115·v117 정적 자산 기대 버전과 수기검증표 19항목을 갱신. **실제 Node 실행, Android Brave GUI/펜/한국어 음성, 실제 스캔 인식은 별도 수행 결과가 있는 경우에만 PASS로 보고**한다.

## 🚨 필수 수기 실기검증 절차

1. **기존 백업부터:** 운영 사이트의 `설정 → 내 학습 데이터 다운로드`로 전체 JSON 다운로드. PDF 필기가 있으면 해당 PDF에서 `필기 JSON 백업` 또는 `PDF 저장`을 추가로 수행. 파일이 실제 저장됐는지 파일 관리자에서 확인. 기존 사이트 데이터 초기화 금지.
2. **v118 운영 배포 확인:** 먼저 **수동 배포** 후 Vercel Production 커밋과 GitHub HEAD가 같은지 확인. v115 운영 사이트에서 v118 버튼을 못 찾는 것은 정상이며 v118 실기 PASS로 기록하지 않음.
3. **같은 이름·크기 다른 PDF:** 테스트 프로필에서 파일명과 크기가 같은 다른 PDF 2개를 순서대로 열고 필기. 필기가 서로 붙지 않고, 이전 원문을 임의로 덮어쓰지 않는지 확인.
4. **이전 PDF 필기:** 이전 버전에서 작성한 필기가 존재할 때 새 버전에서 같은 PDF를 열어 이관 팝업 확인. 취소 시 새 보관함 비어 있고 이전 기록은 유지, 확인 시 새 해시 보관함에 필기가 복사되고 이전 기록도 남는지 확인. 다른 원문이면 복사하지 말 것.
5. **OCR PDF 왼쪽·오른쪽:** PDF 원문을 열어 `내 이미지·PDF OCR 연구 도구` → 왼쪽 페이지 OCR, 펼쳐보기 오른쪽 페이지 OCR. 한국어/영어 문자, 수식·도표·①~⑤ 번호·원문과 비교하여 정확도 수기로 메모.
6. **이미지 OCR:** PNG/JPG 사진 1장 선택해 추출, 선지 분리와 수정 후 `검토 초안 TXT` 다운로드. 새로고침 후 개인 초안 보존 확인.
7. **중단·CPU 복구:** 인식 중 중단 버튼, 탭 전환·창 숨김, 모바일 화면 잠금 후 워커 중지 및 입력/스크롤 동작 확인. 초기 언어 파일 네트워크 오류와 저장공간 부족 시 안내 확인. **GPU·CPU 수치는 사용자가 직접 측정한 경우만 PASS**.
8. **전체 JSON 복원:** OCR 초안 저장 후 `내 학습 데이터 다운로드`를 실행, **격리 테스트 프로필**에서 JSON 복원하고 초안 보존 확인. 백업에 PDF 필기 JSON이 자동 포함된다고 오해하지 말 것.
9. **기존 주요 기능 회귀:** 모바일 탭 위치·상단 설정, 80문항 100분 자동 채점/과락, TTS 여성 음성 1.5배속/3모드, S Pen 몸통 지우개·손 터치 복귀, PDF 오른쪽 획 보존, 다크모드·GPU 배경 정지 확인.
10. `설정 → 실기검증표`에서 19항목 각각 **PASS/FAIL/미확인** 표시하고 실패는 기기 모델·Brave 버전·화면폭·PDF 연도/쪽·이미지 조건·재현 순서까지 기록해 TXT로 저장.
