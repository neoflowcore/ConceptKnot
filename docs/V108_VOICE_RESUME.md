# ConceptKnot v108 · 문제별 음성 이어듣기

2026-11-04. v107에 이어 한국어 기기/AI 음성의 과목 40문항 연속재생을 문항 단위로 복원한다.

- 기존 학습 상태 tts.bookmark에 연도, 문항, 모드, 범위, 시각만 저장한다. 별도 서버·음성 파일 저장 없음.
- 문항이 바뀔 때만 기록하고 세그먼트마다 쓰지 않는다. 중지 및 페이지 이동 뒤에도 저장 지점 유지, 완료 시 해제.
- 사용자가 명시적으로 '중단 지점 이어 듣기'를 눌러야 재생된다. 자동 백그라운드 시작 없음.
- 오답·근거 개인 메모, 공식 800문항, 원본 최종정답 파일은 수정하지 않는다.
- 3모드 및 Supertonic F1~F5, 1.5배속, 정지/재개 시뮬레이션은 실제 음질 실기와 구분한다.
- 해설 대시보드의 오프라인 대체 숫자는 기존 32건 초안/368건 미작성에 맞춤.
- push 기반 Actions/자동배포, EXE·APK·ZIP 생성 금지.

## 실기
1. Android Brave에서 2024년 학개론 40문항 연속 시작, 5번을 읽을 때 정지한다.
2. 새로고침 후 '중단 지점 이어 듣기'로 5번부터 다시 시작하는지 확인한다.
3. 민법 41~80번, 모두정답 제외, 복수정답, 문제+5선지에서도 반복한다.
4. AI 여성 1.5배속의 실제 음색·정지·일시정지·복원은 별도 실기 확인한다.
