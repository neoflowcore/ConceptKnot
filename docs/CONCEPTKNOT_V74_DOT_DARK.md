# ConceptKnot v74 — 다크모드 전용 도트 홈 배경
- 홈 화면의 라이트/다크 테마 분리. 기존 테마 패리티 CSS가 배경을 양쪽 모두 하얀색으로 고정한 규칙을 최후단 CSS에서 다크모드에 한해 덮어쓴다.
- 메인 배경 #111518, 도트 #737B80, 구름/잔디/꽃 중간 회색으로 변환. 사과 RGB 유지, 색상 외에 좌표·운동·GPU 루프는 변경하지 않는다.
- 웹프 도트 배경은 어두운 도트를 중간 회색으로 바꾸는 CSS 필터, 구름/부엉이 이미지는 screen 혼합으로 검정 배경에 검정/흰 사각형이 남지 않게 한다.
- 하단 SVG 흰색 매트를 차콜로 변경하여 하단만 흰색으로 남는 현상 방지. 검색/스크롤 컨트롤도 은은한 다크 글라스.
- 초기 HTML에서 테마 저장값을 읽어 첫 프레임 화이트 플래시 최소화. 라이트모드 렌더링은 그대로 유지.
