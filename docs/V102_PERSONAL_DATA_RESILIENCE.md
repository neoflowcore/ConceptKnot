# ConceptKnot v102 · 비파괴 개인자료 복원 및 교차 탭 안정화

대상: `neoflowcore/ConceptKnot` `main`, 기준: v101 `5b85ca270cc10d9991defd1bb898ee8830503727`.
코드 변경 전 자동배포 비활성, GitHub Actions 워크플로 없음. 이번 단계에서도 자동배포를 켜거나 EXE·APK·ZIP을 만들지 않음.

## 실제 코딩 변경

1. **v101 치명적 파싱 오류 수정**: 해설 작업대의 `async const bundleCache`를 올바른 상수 선언으로 고쳐 JS 로딩 시작 오류를 없앰.
2. **공통 타임스탬프 기반 병합**: 해설 편집기 v80 내부에 `CK102Restore`를 먼저 등록하여 해설 작업대·개념 링크·교재 자료실이 최신 개인 기록을 보호하도록 통일. 새 항목은 추가, 신규 백업 타임스탬프가 현재보다 엄격하게 클 때만 덮어씀. 같은 시각·시각 미기재는 현재 자료 보존.
3. **개인 해설 초안**: JSON 복원 시 원래 시각 보존, 근거 없는 `review_hold` 상태 차단, 편집 중 가져오기 차단, 다른 탭 변경 직후 쓰기 차단, 최대 1MB 개인 초안 제한. 공식 정답/공개 해설 자동 변경 없음.
4. **해설 파일 출처 무결성**: 2021~2025년 연도별 80문항·5선지·공식 채점 인정·과목과 연결된 해설 데이터만 편집 대상 로딩.
5. **해설 검토 작업대**: v101 문법 복구, 동일 시간 백업 덮어쓰기 방지, 가져오기 결과 상세 설명.
6. **개념 연결 자료실**: 미저장 개인 선지 판단·다중 탭 충돌 중 가져오기 차단, 새/갱신/보존 건수별 통합 병합.
7. **교재/OCR 자료실**: 스캔이나 편집 중 가져오기 차단, 기존 문서 최신판을 보존하는 문서별 병합, 중복 ID·35건·총 용량 확인. `storage` 이벤트를 `document`에서 `window`로 수정하고 교차 탭 미저장 입력을 보호.
8. **학습계획**: `storage` 이벤트를 실제 브라우저 대상인 `window`로 변경, 미저장 폼은 백그라운드 재렌더로 지우지 않고 동시 수정 시 쓰기 차단, 닫기 시 미저장 경고.
9. **서비스 워커**: 캐시 버전 v102, 핵심 프리캐시를 HTML에서 실제 로드되는 37 JS + 40 CSS 및 중요 JSON·아이콘 중심 **88개**로 줄임(기존 프리캐시 대상 최대 약 142개). 그 외 동적/레거시 파일은 요청 후 캐시. 처음 방문 전 모든 콘텐츠가 오프라인에서 보장되는 것은 아님. 공식 5개년 해설 JSON·개념 JSON을 직접 캐시에 포함.
10. **Vercel 정적 파일 재검증**: HTML의 기존 JS 쿼리 이름은 유지하되 변경된 주요 5개 JS 응답에 `no-cache, must-revalidate`를 적용. Git 자동배포 설정은 `false`.

## 검증 범위

- 테스트 파일 `tests/v102-personal-restore.test.cjs`: 9개 수동 실행 Node 테스트. 공통 병합, 서로 다른 타임스탬프, 35건 한도, 편집기 가져오기 검사, 모듈 초기화, 복습 작업대, 저장 이벤트 대상, 학습계획 갱신, 정적 캐시/자동배포 차단을 확인.
- 읽기 전용 배포 점검: `node scripts/check-release-readonly.cjs`. 테스트 실행과 실제 통과 여부는 별도 기록. 파일 생성/네트워크/Actions 없음.
- `index.html`의 스크립트 src 쿼리 버전은 변경하지 않았으므로 새 수동 배포 뒤 강력 새로고침 및 SW v102 활성화 확인. 기존 운영사이트가 최신 코드라는 뜻 아님.

## 정확도 및 남은 범위

- 공식 10개년 800문항 구조 등록과 Q-Net 원문·법령·그림 전문가 감수는 별개.
- 2021~2025년 400해설 중 공식 근거/선지 검수 완료 표시는 v100 마지막 읽기 전용 점검에서 0건. 새로 자동 승격하지 않음.
- 온라인 CDN에서 가져오는 PDF.js 및 한국어 OCR 모델은 사용자 동작 때만 사용하며 완전 오프라인 OCR을 보장하지 않음.
- PC Chrome/Edge, Android Brave, S펜 필압·지우개·팜터치, 한국어 TTS, PDF 2쪽, GPU/배경 애니메이션, 저장·복원 장기 실기는 미검증.
- 마지막 공식 Phase 운영 체크포인트 19/30(63%)는 과거 측정 기준선이며 v102 최신 제품의 실제 완성률/실기 PASS율이 아님. 디자인 초안 일치율 미측정.

1. 현재 브라우저 개인 데이터 JSON 다운로드, 별도 안전한 위치에 보관.
2. Chrome 개발자 도구에서 새 서비스워커 `conceptknot-study-v102-nondestructive-restore` 활성화/JS 정상 로드 확인.
3. 해설 작업대를 열고 닫아 시작 오류가 없으며 2021~2025 해설 400개가 로드되는지 확인.
4. 해설 초안·개념 연결·교재 메모 각각에 최신 시각의 현재 자료를 만들고 과거 JSON을 가져와 기존 내용이 그대로 유지되는지 확인. 다음으로 새 문항이 추가되는지 확인.
5. 별도 탭에서 학습계획/교재 메모를 바꾸어 원래 탭 갱신·미저장 입력 보호·저장 거부를 검증.

7. 갤럭시 Brave 실제 S펜·한글 IME·PDF·TTS·GPU 확인, 실패 화면·동작 순서·기기 정보를 기록.
