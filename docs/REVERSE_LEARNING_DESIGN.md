# Question-first 역추출 학습 구조

## 목적

시험 직전에는 모든 기본서를 읽는 것보다 **문제가 요구하는 판단 규칙을 뽑아 즉시 재사용하는 연습**을 우선합니다. 본 버전은 학습법의 일반 원리(연습시험, 간격 복습, 능동 인출, 혼동개념 구별)를 제품 흐름에 적용한 것이며, 이 앱의 합격률 상승 효과를 별도로 실험 검증했다는 뜻은 아닙니다.

## 문제 1개의 세션

| Step | 사용자 행동 | 엔진 기록 | 다음 행동 |
|---|---|---|---|
| 1 문제 먼저 | 선택지 5개 중 1개 선택 | 최초 답, 최초 오답, 횟수 | 정답과 선택지별 판별 근거 공개 |
| 2 이론·함정 해부 | 해당 정답의 판단 규칙과 흔한 함정을 확인 | 문항↔개념 매핑 사용 | 필요 개념만 가림 |
| 3 능동 인출 | 문제 없이 규칙을 소리 내어 설명 | 주관적 기억 수준 0/1/2 | 다음 복습 시각 설정 |
| 4 동일 규칙의 전이 | **별도 제작된 30개 전이문항**에서 다른 상황 적용 | 전이 응답 | 원문제 재도전 |
| 5 원문제 재도전 | 해설 없이 처음 문제 다시 해결 | 재도전 성공 여부(최초 답과 별도) | 취약점 우선 큐 |

기본 복습 구간: 0=15분, 1=1일, 2=3일. 시험일에 가까우면 해당 시험 시작 시각을 넘기지 않도록 상한을 둡니다. 이는 임시 경험적 설정입니다.

## 실제 기출 데이터 파이프라인

```
Q-Net 공식 PDF ──────> 사용자 육안 확인 / OMR 답안
         └──(외부 OCR TXT)──> 문항 번호별 후보 텍스트
                                  ↓ [반드시 미리보기]
                           연도·과목·문항 번호 확인
                                  ↓
                       키워드 주제 후보 1~4개
                                  ↓ [사용자 검토]
                           단일 핵심개념 연결
                                  ↓
                   같은 개념의 다른 회차 문항 탐색
```

**제한**: 문항마다 하나의 핵심 개념만 직접 연결합니다. 복합 출제개념·오답 선지별 개별 개념 매핑, 800개 공식 문항의 본문 확보, PDF 자동 OCR, 자동 해설의 신뢰성 검증은 다음 단계입니다. 키워드 일치만으로 정답이나 공식 해설을 확정하지 않습니다.

## 학습지표와 오해 방지

- `firstWrong`: 최초 문제 오답 여부이며 재도전 성공 후에도 지워지지 않습니다.
- `lastCorrect`: 재도전이 맞았는지 별도로 보관합니다.
- `recallRating`: 사용자가 스스로 평가한 0/1/2 등급이며 객관적인 기억 측정 점수가 아닙니다.
- `due`: 다음 복습 시각. 시험 전 단기 학습용입니다.
- `officialLinks`: 사용자가 추가/확인한 실기출 텍스트와 개념 매핑입니다. 기출 해설의 저작권이나 검증성을 자동 보장하지 않습니다.
