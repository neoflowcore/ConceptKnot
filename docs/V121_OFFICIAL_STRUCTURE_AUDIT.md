## 구현 기능

- 기존 `내 학습 데이터 안전 점검`에 **사용자 클릭으로만** 원문 2개+해설 5개 JSON을 읽어 구조 불일치, 원문 해설 연결, 연도별 문항, 특수 정답과 검수 미완료를 표시하는 기능.
- 검사 결과의 수동 TXT 저장. 데이터는 안전한 `textContent`로 출력, 원본·개인 기록 자동 변경 없음.
- 개인 저장소 원본 진단 대상 **9→12종**: 수기검증표, OCR 단일 초안, OCR 페이지별 보관함 추가. `12종 원본 백업`은 **복구용 JSON**으로 정식 통합 학습 JSON과 구분.
