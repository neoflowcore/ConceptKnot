# ConceptKnot v129 · 10개년 공식 A형 혼합 실전 5세트

기준일: 2026-11-06. 기준선: GitHub `main` v128 `bf1046f57b5348c9d493d7242fe7c88c9980feaf`.

## 이번에 실제 추가한 기능 (P3 중심)

- 기존 `80문항·100분 연도별 공식 A형 모의고사`를 유지한 채, 별도의 **10개년 혼합 실전 5세트**를 `모의고사` 화면에 추가했다.
- **혼합·재배열만** 수행한다. 법률 문장의 맞음/틀림을 AI가 뒤집거나 공식 선지를 자동 변형하지 않는다. 따라서 원래 계획의 *새로운 응용·변형 모의고사 5세트*와 구별하여 표시한다.
- 각 세트 **80문항(부동산학개론 40, 민법 및 민사특별법 40)**. 두 과목 각각 2016~2025년 **매년 4문항**으로 구성한다. 1~5세트의 문항이 서로 겹치지 않아 **400개 서로 다른 원문**을 제공한다.
- 세트 추출은 연도별/과목별 고정 배정 + 시드 고정 재배열 방식이며 사용자/기기/새로고침에 관계없이 동일한 5세트 문항 순서를 재현한다.
- 공식 `RECALL_OFFICIAL`의 `verified:true`, 연도, 원문, 5개 선지, 정답 인정 번호, 과목, `https` PDF 출처를 확인한 문항만 사용한다. 자료가 부족하면 시험 시작·채점 모두 차단하고 `CK89OfficialBank.loadAll()`로 읽은 후 재확인한다.
- 답안 선택·OMR 80칸·보류 표시·일시정지/재개·100분 타이머·시간 만료 후 채점·오답/미응답 결과·원문 대조 링크·개인 TXT 결과를 제공한다. 숫자키 1~5·좌우 방향키 지원.
- 과목별 40문항 × 2.5점, **각 과목 40점 이상·평균 60점 이상**을 개인 연습 기준으로 표시한다. 전원정답(선택한 ①~⑤)·복수정답은 기존 공식 최종 채점 인정 배열을 그대로 사용한다. 미응답은 자동 정답 처리하지 않으며 진위 설명을 지어내지 않는다.
- 연도별 CK82 시험 기록과 분리된 `ck129-mixed-sessions-v1` 저장 키 사용. 최근 10회 제출 이력·중단 이력·현재 답안 자동저장·멀티탭 충돌 보호·저장소 손상 시 덮어쓰기 차단.
- 병합 시 **같은 시작·제출 시각에 답안 내용만 서로 다른 제출 기록**은 중복 제거하지 않고 충돌 오류로 거부한다. 같은 미제출 세션이라도 보류표시·남은시간·진행 상태까지 완전히 같지 않으면 저장을 거부한다. 원본과 가져온 백업을 별도 보존한다.
- 전체 JSON 원본 다운로드와 **비파괴 병합 복원** 제공. 현재 미제출 시험과 가져온 미제출 시험이 충돌하면 거부한다. 완료 이력을 중복 제거해 병합하고 10회 초과 시 이전 기록을 잘라내지 않고 복원을 거부한다.
- 백그라운드/타 학습 탭에서 불필요한 1Hz 타이머를 중지한다. 화면을 다시 열면 `Date.now()`와 저장된 마감시각으로 남은 시간을 계산한다.
