# ConceptKnot Android APK 개발 마스터 계획
> 문서 버전: v174 · 작성일: 2026-11-14 · 우선순위: **ANDROID FIRST** · 상태: **개발 계획 / 일부 공통 코드만 구현**

## 1. 제품 목표
기존 ConceptKnot 공인중개사 **1차 학습 기능**을 Android 네이티브 앱으로 이관한다. 범위는 부동산학개론·민법이며, 단순 웹뷰 포장 앱이 아닌 Kotlin 기반 오프라인 학습 앱을 목표로 한다. TTS는 **기기 내 로컬 AI 모델**을 1회 설치하고 기출·이론·임의 텍스트를 끝까지 낭독하도록 구현한다. Android 우선이며 Brave 웹앱 개발은 별도 문서에 따라 잠정중단한다.

## 3. 기술 설계
- **앱:** Kotlin, Android SDK, Compose UI 우선 검토, Gradle 버전 고정, 단일 APK 앱부터 시작.
- **음성:** sherpa-onnx Android SDK의 실제 지원 API 확인 후 어댑터 구현. 한국어 여성 음성·라이선스·모델 크기·재배포 조건을 검증하고 모델을 선택한다. Supertonic ONNX 가중치를 sherpa-onnx와 호환된다고 가정하지 않는다.
- **모델 설치:** 최초 사용자 동의 → 신뢰 가능한 HTTPS 원본 다운로드(필요 시 GitHub Releases/R2) → 파일 크기 및 SHA-256 검사 → 임시 파일에서 앱 전용 저장소로 원자적 이동 → 로컬 실행. 이미 설치된 동일 버전은 다운로드하지 않는다. 네트워크·저장공간 부족·부분 다운로드·파일 변조 시 복구한다.
- **낭독:** 원문은 수정하지 않고 발음용 복사본만 전처리. 법조문·판례·㎡·%·LTV/DSR 등을 한국어로 읽는다. 긴 글은 청크별로 처리하고 재생이 끝난 뒤 커서를 이동한다. 실패 시 같은 청크 재시도, 중단 위치 보존, 오디오 포커스·블루투스·알림 미디어 컨트롤·백그라운드 재생 지원.
- **데이터:** 기출·선지·해설·기본이론은 앱에 적합한 구조화 포맷으로 이관하고 Room/SQLite 등 로컬 DB에 저장. 공식 원문과 AI 생성 해설·전문가 검수 상태를 구분한다.
- **그래프:** 수요·공급 이동, 균형가격/거래량 자동 계산, 가격상한·하한, 탄력성, 비교 전후·설명 패널. 선을 잡고 드래그할 때 화면 스크롤이 개입하지 않도록 제스처 우선순위 분리.
- **필기:** Android MotionEvent에서 stylus/finger 구분, S펜 버튼 지우개, 두 손가락 줌·이동, 지연 최소화 및 해상도/반응속도 설정.
- **보안·프라이버시:** 사용자 텍스트와 학습 기록은 기본적으로 기기 내부 처리. 외부 모델 전송·유료 서버 추론은 사용자 동의 없이는 도입하지 않는다.

## 4. 데이터 이관 및 품질 원칙
1. 웹앱의 원본 데이터는 변경·삭제하지 않는다. 기존 학습기록이 브라우저 로컬에만 있는 경우 별도 내보내기/가져오기 경로가 필요하다.
2. 10개년 공식 기출 **800문항**은 기존 목표/구조 현황으로 취급하고, 앱에 들어간 실제 파일·문항 수는 이관 단계에서 재검증한다.
3. 2021~2025년 400문항/2,000선지의 전문가 법리·원문 검증을 완료로 간주하지 않는다. 미검수 해설은 명시적으로 표시한다.
4. 모의고사 5세트 및 기출 혼합/공식 실전 세트는 실제 데이터·정답 검증 후 게시한다.
5. 웹의 기존 사용 흐름과 단축키, 그래프 학습 연결, 약점 복습 기능을 요구사항 대조표로 관리한다.

## 5. 검증 시나리오
- **오프라인:** 설치 → 모델 1회 다운로드 → 앱 종료 → 비행기 모드 → 재실행 → 새로운 한국어 긴 글 완독. 모델 재다운로드 0회.
- **낭독 신뢰성:** 최소 40문항 연속 낭독, 오류 주입 시 동일 문장 재시도, 완료 전 커서 이동 금지, 중지 후 이전 음성 재생 금지.
- **성능:** 실제 Android 기기에서 첫 합성 시간, 문장 사이 무음, RAM 최고치, 배터리, 발열, 화면 잠금·복귀 측정. 수치 목표는 실측 후 결정.
- **학습:** 80문항 100분 카운트다운, 채점·과락·오답, 그래프 제스처/전후 설명, S펜과 손가락 구분.
- **회귀:** 원문·정답 데이터 불변, 앱 데이터 재설치/업데이트 전후 보존, 오프라인 복원.

## 6. 개발 운영 규칙
- 작은 커밋 남발 금지. 기능 단위로 묶고, 중간 CI 자동 실행 없이 최종 일괄 검증.
- 실기검증 직전 사용자 지시 시 APK 생성. 평시 APK/ZIP/EXE 아티팩트 생성 및 자동 Actions 실행 금지.
- 기존 웹 배포를 강제 변경하지 않는다. 웹 관련 개발은 [중단 문서](V174_WEB_APP_PAUSE_AND_PRESERVATION.md)를 따른다.
- 단계 완료 보고는 **요구사항 ↔ 코드 ↔ UI·사용 흐름 ↔ 테스트 증거**를 대조하고, 미완료를 완료로 표시하지 않는다.
