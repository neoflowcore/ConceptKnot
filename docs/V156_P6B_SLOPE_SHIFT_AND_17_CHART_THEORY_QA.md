2. 기울기 조절은 선의 중앙을 고정한 각도 변경이며, 좌우 평행이동은 고유 직선 기울기를 유지하는 별도 동작으로 구분.
3. 모형은 교점 E₀→E₁을 수요/공급 **기울기와 이동 위치를 모두 반영하여** 재계산. 픽셀 단위 도식값을 실제 수요량·가격 변화율로 단정하지 않도록 표시.
4. **관찰형 차트 9종**: 자체 가격 변화와 곡선 위 이동, 탄력성, 최고가격제, 거미집모형, 입찰지대·거리, 현재가치, 저량·유량, 환원율, 허프모형의 주제별 문장과 기본 관계·공식·함정 제공.
5. **전체 17종**: 쉬운 설명(기본 수준), 심화 설명(비례·반비례/수식), 기존 학습 예시·기출 개념 연결(조건 분리)을 즉시 갱신.
6. Undo/Redo/초기화에 기울기값까지 포함. 이 학습 상태는 현재 페이지 세션에만 존재. 기존 시험/개인 필기 기록은 건드리지 않음.
7. 실행형 테스트와 P7 개인 수기 QA 목록 확장.

### 교점 계산 모델

- 원점 SVG의 X축이 수량(Q), Y축이 가격(P)이라는 도식 전제 유지.
- 원래 D·S의 두 끝점을 기준으로 midpoint를 고정하고 기울기를 55~160% 배율로 표시. **55~160은 도형 기울기 배율이며 가격탄력성이나 공식 변동률이 아니다.**
- 수요·공급은 각각 \(y=y_{center}+m(x-x_{center}-\Delta x)\) 형태로 표현한다.
- 각 선의 \(m\)과 \(\Delta x\)가 바뀔 때 새 교점을 다시 계산한다.
- 실질적 시장 교점과 무관한 1px 이하 도식 오차는 "불변"으로 표시.
- '조건이 동일'한 수요 단독 증가 / 공급 단독 증가의 방향은 기존 비교정태 방향과 일치시킨다.
- 수요와 공급이 함께 변화하거나 기울기도 바뀌면 두 직선의 교점과 상대적 크기를 함께 검토해야 하며 원래 조건의 정답을 무조건 옮기지 않는다.

### 기본/심화 설명 원칙

- **쉬운 설명:** 변동 전과 후, 수요·공급 상대 변동, 조건 변화와 결과 방향을 생활용어로 연결.
- **심화 설명:** P–Q 직선 방정식, 현재가치 \(PV=FV/(1+r)^n\), 환원율 \(V=NOI/R\), 가격탄력성 수량 변화율 / 가격 변화율, 저량·유량의 시간 단위 등을 실제 주제에서만 표시.
- **기출 함정:** 재화 자기 가격의 변화는 기존 곡선 위 이동이고 비가격 요인의 변화는 곡선 이동이다. 기울기를 바꾸는 도식 자체가 원래 공식 문항의 정답을 변경하는 것이 아님.
- 전체 예시는 도식적 개념 학습이며 **법률·판례 검수 완료 자료로 게시하지 않는다.**

## 사용자 수기검증 — 반드시 기기에서 수행

1. **Android Brave + S Pen:** 수요 D 가운데 원을 잡고 좌우 이동하면 선만 평행이동한다. 끝의 노란 점을 위아래 움직이면 경사만 바뀌고 곡선이 통째로 미끄러지지 않는다.
2. **빈 그래프 스크롤:** SVG의 빈 영역에서 세로로 스크롤 가능. 손잡이 드래그 중 화면 페이지는 움직이지 않음.
3. **독립 수요·공급:** D 기울기 변경 때 S는 기존 상태 유지, S 변경 때 D는 유지. 양쪽 동시 이동·기울기 변경 때 E₀/E₁ 위치가 조합에 따라 달라짐.
4. **대체 조작:** 완만하게 −15 / 가파르게 +15 / 좌우 10 버튼으로 동일 결과 구현, Undo/Redo/초기화 모두 정확.
5. **설명 동기화:** 쉬운 설명·심화 설명·기출 함정 접기를 번갈아 열어 정상재 소득 증가/건축비 상승/대체재 가격 변화 조건과 현재 변경 도식이 구분되는지.
6. **관찰형 9종:** 할인율↑ ↔ PV↓, 환원율↑ ↔ 수익가격↓, 거리↑ ↔ 입찰지대↓, 가격 자체 변화 ↔ 곡선 위 이동을 확인. 관찰형 차트에 가짜 균형가격이 표시되면 실패.
7. **일반 기능 회귀:** 공식/혼합 시험 100분, Ctrl+좌우 이동, 숫자 1~5, 오답기록·백업/필기 복구, 한글 자모·커서·다크모드와 오프라인 앱 캐시.

검증 상태는 **NOT_RUN**이며, 코드 테스트 PASS를 실기 PASS로 바꾸지 않는다.
