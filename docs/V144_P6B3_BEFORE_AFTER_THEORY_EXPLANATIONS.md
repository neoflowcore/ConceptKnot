## 1. 요청을 구현 계약으로 정의

**그래프 안에서 선을 직접 잡고 평행이동·기울기 회전을 수행하면, 이전(점선)과 현재(실선)를 동시에 보며 바뀐 변수/고정된 변수/계산 결과/경제학 기본개념/쉬운 예시/기출 혼동 포인트를 실시간으로 설명한다.**

- 한 차트 위에서 `⇄ 선 평행이동`과 `↷ 선 기울기 변경`을 선택하여 D/S 선 본체를 조작한다.
- **평행이동**: 다른 곡선과 계수 일정. 수요 u, 공급 v의 비가격 변화이며 곡선 위 가격점 이동과 다르다.
- **기울기 회전**: 회전 전과 후에 P=25의 해당 곡선 수량을 유지하는 모형의 고정점을 명시한다. 드래그 위치의 가격좌표를 기준으로 반응계수 b/d를 계산하고 그래프 형태를 갱신한다.
- **가격점 이동**: 자기 가격만 바꿔 동일 곡선 위 수요량 Qd와 공급량 Qs를 계산한다. 새 균형가격/거래량이라고 혼동하지 않는다.
- **동시 이동**: 수요·공급 양쪽 이동이면 계산한 값으로만 가격 방향을 판정하며 상대 이동 폭에 따라 불확정임을 설명한다.
- **원상태 비교**: E₀ 점선 및 E₁ 실선 중첩; 바뀐 변수와 유지한 변수를 나누어 이전 값과 새 값, 증가/감소/불변 표시.
- **자동 이론패널**: 이번 조작 / 변경한 조건 / 고정된 조건 / 결과 비교표 / 무엇이 일어났나 / 연결된 기본이론 / 생활 예시 / 기출 혼동 포인트.
- **초급·심화 양립**: 새 설명 패널은 양쪽 학습 수준에서 열람 가능. 기존 초급 생활 예시, 심화 수식·값 패널 유지.

## 3. 경제학 검증 한계

- 수요 함수 예시 `Qd = a + u − bP`, 공급 `Qs = c + v + dP`; 가로 Q·세로 P인 SVG에서 시각적 기울기는 `dP/dQ=-1/b`(수요), `1/d`(공급). **b 값과 차트 기울기를 같은 숫자로 설명하지 않는다.**
- `b` 또는 `d` 변경은 **P=25를 회전축의 가격으로 둔 예제**이며 보편적 경제학 법칙상 회전축이 25라는 뜻이 아니다.
- 예산선 소득 증가에서는 양쪽 절편 증가·기울기 불변(평행이동); X 가격 증가에서는 Y절편 불변·X절편 감소(회전). 무차별곡선 최적점은 제약과 선호조건을 따른다.
- PPF 생산점 이동 vs 곡선 능력 변화 구분, 수입/비용 단일 생산자의 MR=MC·경계해, 입찰지대 거리저항, 거미집의 시차·수렴 조건, 호탄력성의 중간점 가정을 각각 유지한다.
- 자동 설명은 **학습 예시이며 검수된 공식 기출 정답/법령 해설이 아니다.** 미검수 개념 후보를 공식 정답으로 링크하지 않는다.
