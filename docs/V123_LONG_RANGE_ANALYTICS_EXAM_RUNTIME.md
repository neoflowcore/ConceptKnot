# ConceptKnot v123 — 장기 학습통계·모의고사 타이머·교차근거·오프라인 보강

기준: 2026-11-05, GitHub `main` v122 `9cdac6e685febd8e840a7d5c7d13fa3314acb3e6`.
최종 운영 배포 조회 시 v115 `4a12a9fb7dbc0e9191539cc3b6d8bbeed92dc1f2` READY: **현재 운영 배포에 v123 코드가 반영된 상태가 아님**.

## 검증된 요구·경계

- 2016~2025년 공식 기출 800문항은 등록 구조 및 정답 연계 대상으로 유지한다. 해당 기록에 표시된 `verified:true`는 법령·공식 PDF 선지별 독립 법률 검수와 별개다.
- 2021~2025년 해설 400건 중 초안 32 / 미작성 368 / 공식 출처·선지 검수 완료 0건(이전 v121 파일 감사 기준). 이를 임의의 완성된 내용으로 대체하지 않는다.
- 기존 브라우저의 학습기록·개인 해설 초안·PDF 필기는 자동 변환, 초기화, 원격 전송하지 않는다.
- `vercel.json.git.deploymentEnabled=false` 유지. GitHub Actions workflow 추가 및 빌드·설치 아티팩트 생성 없음.

## 1. 학습 데이터 분석: 7·30·90·365일

- 기존 7/30일 계산은 유지한다. 통계 화면에 90일과 365일 직접 선택 버튼 추가.
- 90일 시각 차트는 연속 7일 구간별(마지막 구간은 6일), 365일은 달력 월별로 합산. 원본 개별 일수·이벤트는 그대로 보존한다.
- 장기간 표시에 최대 365개 촘촘한 막대를 생성하지 않는다. 기존 통계의 합격 가능성 예측은 하지 않는다.
- 통계 TXT: 장기 구간 합계와 원본 일별 기록을 함께 내보내며, 실제 기록만 집계한다.
- 연계 개념명을 ID 대신 표시하도록 `CK83Links.getLabels/loadLabels` 제공, **사용자가 통계 화면을 열 때만** 필요한 분류 데이터를 불러온다.
- 동일 브라우저에서 80문항 모의고사를 제출하면 `ck:exam-submitted` 이벤트로 이미 열린 통계 화면을 새로 계산한다.
- 실전 기록 보존 한도는 원래대로 최근 20회이며, 365일 통계는 **저장된 20회 이외 과거 시험 성적을 복원하거나 추정하지 못한다.**

## 2. 80문항·100분 모의고사 타이머 절전

- 영구 `setInterval(tick,1000)` 호출 제거. 진행 중인 시험이 있고 브라우저 페이지가 보일 때에만 1Hz 업데이트를 실행한다.
- 시험 미시작·일시정지·제출·브라우저 숨김·pagehide에서는 타이머 중단, 복귀·재개 시 시작한다.
- 시간 판정 자체는 기존 `deadlineAt-Date.now()`를 사용하므로 숨김 상태 경과시간을 누락시키지 않는다. 만료 상태의 제출은 다시 열거나 visibilitychange/pageshow 때 검토한다.
- 다른 탭의 답안 변경 후 복원 과정에도 타이머 상태를 동기화한다. CPU/GPU 절감량은 실측하지 않았다.

## 3. 800문항 개인 선지 출처 교차 점검 추가

- CK83 선지 메모와 CK80 개인 해설 초안의 **①~⑤ 미출처·진위충돌·서로 다른 출처 문구의 번호**를 독립적으로 계산한다.
- 목록에서 출처 없는 선지 번호 및 판정 충돌 번호를 식별하고, CSV에는 세 유형의 번호 열을 추가한다.
- CSV 내보내기 순간에도 미저장 개인 변경·기타 탭 충돌·기존 보고서와 현재 수치 불일치를 재검사한다. 오래된 교차 보고서를 실수로 내려받지 않도록 막는다.
- **개인 메모의 판정/출처 일치는 법령·판례 정확성을 보증하지 않는다.** 복수·전원정답 인정은 참/거짓 검수와 구분한다.

## 4. 오프라인 캐시·수기 검증표

- Service Worker 캐시 세대 v123. 기존 index.html에서 `?v=117`, `?v=115`, `?v=121`로 요청한 자산과 최근 HOT/ASSETS 캐시의 버전 쿼리가 달라도 오프라인에서 경로 기준 동일 자산을 검색하는 `ignoreSearch` 보조 경로 추가.
- 서버 재배포 전 기존 서비스워커가 새 캐시를 사용한다고 보장하지 않는다. 수동 배포 후 온라인 방문과 새로고침이 선행돼야 한다.
- 설정의 사용자 수기 실기검증표 **21→24항목** 확장: 90/365일 장기 통계, 4,000선지 교차 감사, 시험 타이머 숨김/복귀. 기존 저장소 키·스키마를 유지해 과거 수기 메모를 읽는다.
- 테스트 코드 `tests/v123-long-range-runtime.test.cjs` (명시적 수동 실행). `tests/v122-personal-crosscheck.test.cjs`의 캐시 세대 고정 검증은 세대별 호환 검증으로 수정.

1. 원래 브라우저에서 학습 기록 통합 JSON, PDF 필기/이미지 등 따로 저장해야 하는 자료를 각각 백업. 원본을 변경하기 전 격리된 브라우저 프로필에서 테스트.

4. **모의고사 80문항 100분:** 2025년 시험 시작→수기 OMR 선택/일시정지/재개→브라우저 백그라운드/복귀→남은 시간과 답안 유지→제출. 학개론·민법 40점 과락과 평균 60점 동시 요건 확인. 제출 후 열린 통계 화면이 갱신되는지 확인.
5. **개인 근거:** 2016년/2025년 임의 문항에서 CK83/CK80 개인 초안에 일부러 다른 참·거짓 기록(격리된 프로필에서만)을 넣은 뒤 교차 감사. 해당 선지 번호와 CSV 번호 일치 여부를 확인. 미저장 편집/다른 탭 변경 시 다운로드를 차단하는지 확인.
6. **오프라인:** 온라인에서 사이트를 열어 새 서비스워커 설치를 확인한 뒤 완전 오프라인→재접속. 기존 페이지의 query version이 있어도 CK88/CK83Analytics/CK82 자산이 요청에 응답하는지 확인. 원본을 저장하지 않은 상태에서 스토리지 초기화는 금지.
7. **화면·모바일:** Android Brave 작은 폭에서 상단 설정 오른쪽 고정, 오른쪽으로 스크롤한 탭 클릭 후 위치 보존, 다크모드 배경, 학습 탭 진입 후 백그라운드 GPU 정지 확인.

9. 설정의 **24개 수기 실기검증 항목**에 직접 PASS/FAIL/미확인과 기기/문항/재현 순서를 적어 TXT로 보관한다. 자동 PASS 처리 없음.
