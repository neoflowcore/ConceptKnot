## 0. 변경 관리 원칙

- 이 시안은 추가적인 AI 이미지 창작이나 임의의 테마 전환 없이 **화면 구조 기준**으로 고정한다.
- 주요 참고: **clay.com**(흰 캡슐형 상단 통합 메뉴, 초록 구릉과 푸른 하늘, 매끄러운 3D 분위기, 입체감·강한 명암 대비), **typing.works**(상단 통계·기록 격자, 문장형 흐릿한 원문, 입력 위치 고정·타자 진행/오류 즉시 표시).
- 모네 **책 표지 카드 UI 삭제**. 기존 모네 그림은 **왼쪽 필기판의 배경**으로만 사용한다. 그림과 콘텐츠가 겹치므로 어두운 반투명 오버레이로 가독성을 확보한다.
- 불필요한 홍보성·감성적·AI 티가 나는 문구 금지. 아이콘·짧은 기능명·실제 학습 데이터 중심으로 구성한다.
- 기존 공식 기출 데이터(최근 5개년 400문항), TTS, 복습, 시험, 개념 연결, 계산, 오답, 타자 기록은 보존한다. 실제로 계산하지 않은 수치를 임의 표시하지 않는다.
- 기존 브라우저 `localStorage` 키 `recallgraph-first-exam-v1` 및 기존 필기/타이핑/JSON 백업과의 호환성을 유지한다.

## 1. 전역 화면 구조

### 1.1 상단 내비게이션

- 최상단에 **흰색 라운드 캡슐 형태의 메뉴 바 1개**. ConceptKnot 로고 왼쪽, 모든 학습 메뉴를 동일한 바 안에 배치한다.
- 메뉴: 오늘의 학습 / 핵심 이론 / 그림 연상 / 분필 타이핑 / 문제·정답 / 기출→이론 / 문제 풀이 / 계산 집중 / 10개년 기출 / 비교 도형 / 오답 복습 / 학습 계획.
- 현재 탭은 검정에 가까운 짙은 색의 채운 캡슐. 나머지는 흰색 바탕과 검정 텍스트. 오른쪽 날짜·내 데이터.
- 작은 화면에서는 탭을 가로 스크롤로 제공하고 메뉴 기능을 삭제하지 않는다.

### 1.2 배경

- 상단의 푸른 하늘과 구름, 초록 잔디 언덕 및 나무의 **Clay.com 계열의 입체적인 풍경**.
- 카드 작업면은 흰색/아이보리. 강조색은 잔디 녹색, 밝은 하늘색, 차분한 파랑, 네이비 블랙.
- 3D 이미지는 설명 문구 대신 분위기를 형성하되 기능·버튼·문제 글자가 묻히지 않도록 시각적 밀도를 통제한다.
- 전체 폰트는 Pretendard. 별도 불필요한 슬로건을 생성하지 않는다.

### 1.3 학습 2분할(가로)

- 넓은 화면: 왼쪽 **약 1/3**, 오른쪽 **약 2/3**. 12px 정도의 드래그 구분선으로 가로 폭 조절.
- 왼쪽의 최소 너비를 확보해 필기 내용을 가리지 않는다. 오른쪽도 실제 문제와 답안이 손상되지 않는 최소 너비를 유지한다.
- 키보드 방향키로도 크기 조절 가능하며 조절한 폭은 로컬에 저장한다.
- 태블릿·모바일은 가로폭과 터치를 고려해 세로 배치; 화면 전체가 가로로 넘치지 않아야 한다.

## 2. 왼쪽: 모네 그림 자체를 메모·칠판으로 통합

- 화면의 위부터 아래까지 이어지는 하나의 큰 그림 필기판. 별도 모네 *카드*, 별도 메모장, 별도 S펜 패널을 만들지 않는다.
- 메모 텍스트 레이어와 손글씨(Canvas) 레이어를 **동일한 칠판 영역에 중첩**한다.
- 키보드로 즉시 입력하면 글자 메모, S펜으로 즉시 그리면 손글씨. **모드 전환 버튼을 두지 않는다**.
- PC 마우스 일반 클릭은 커서·키보드, 보조적으로 Shift+드래그는 그리기. S펜은 Pointer Events의 `pointerType=pen`으로 자동 분기한다.
- 분필색 변경, 실행취소, 다시실행, 필기 삭제, 문항별 JSON 내보내기 버튼을 칠판 아래 작은 아이콘으로 배치한다.
- 현재 문항의 고유 키(예: `official:2025-47`, `practice:...`)로 **문항별 독립** 텍스트·손글씨 자동 저장.
- 기존 `state.questionNotes`의 메모는 삭제하지 않고 새 칠판으로 첫 표시 시 안전하게 병합·이전한다.
- JSON 내보내기에는 텍스트·텍스트 색·펜 획·수정 시간·문항 키를 포함한다.

## 3. 오른쪽: typing.works형 학습 화면

### 3.1 위쪽 조작 패널

- 작은 줄의 과목 버튼 + 기출 유형(창작 연습 / 공식 5개년 / 핵심 이론) + 연도(2021~2025) + 현재 문항 선택.
- 통계: 시간 / 타수(분) / 정확도 / 입력 수. **현재 실제 값**만.
- typing.works 모티프인 **작은 활동 격자(heatmap)**로 최근 타이핑 완료 기록을 표현한다. 기록이 없으면 회색.
- 구획은 얇은 테두리·부드러운 모서리·확실한 여백으로 정돈한다.

### 3.2 문제 패널

- 실제 등록된 문항의 연도·과목·문제 번호와 문제 본문.
- 공식 기출에는 실제 ①~⑤ 보기 표시. 타이핑은 **문제와 정답 선지만** 대상으로 하고, 나머지 보기는 학습용 원문 열람으로 제공한다.
- 페이지에 같은 본문을 두 번 크게 반복하지 않는다.
- 긴 문제는 읽기 가능한 줄바꿈/스크롤 처리, 모바일에서 오버플로 금지.

### 3.3 타이핑 패널

- 넓은 밝은 작업 영역, 원문은 **같은 자리에 흐릿한 회색**으로 표시.
- 입력된 문자가 해당 위치를 채움: 맞음은 진한 색 또는 초록, 틀림은 붉은 배경. **입력에 따라 원문이 이동하지 않음**.
- 실제 입력은 textarea로 받아 한글 IME 조합 완료 때 기록 반영.
- 정확도·타수·학습 시간·완료 기록은 기존 엔진과 JSON 저장을 사용.
- 재시작 / 다음 문항 / 원문 가리기 / 기록 조회를 짧은 버튼과 아이콘으로 제공.
- 별도 어두운 남색의 위아래 두 칠판, 중복된 '원문 박스와 나의 입력 박스' 디자인은 폐기.

## 4. 현재 기능과 연결

- `typingItems()`, `typingConcept()`, `chalkRecord()`, `typingFeedback()`, `typingHistoryHtml()` 재사용.
- `inkRecord()`, `inkDraw()`, `chalkMount()`, `save()`, `download()` 재사용. 기존 데이터 변경/삭제 금지.
- 다른 탭도 같은 전역 메뉴·왼쪽 통합 메모판·오른쪽 기존 기능 영역을 적용. 기능 코드를 새로 구현하지 않고 화면 계층을 교체한다.
- 앱 기록은 기본적으로 로컬이며 기기 간 자동 동기화하지 않는다. JSON 백업을 통해 이동할 수 있다.
