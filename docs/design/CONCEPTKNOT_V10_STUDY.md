# ConceptKnot v10 — Study glass, chalk tools, five-page final note and AI dock

- Glass cards: ambient colored shadows replacing hard top/left accent borders
- Dark typing panel with high-contrast white text
- S Pen button moved into chalk swatch row; prompt text removed
- Chalk font slider, fifth custom-color swatch/color picker
- Board TXT export and browser PDF print flow
- Five editable A4 exam-final note sheets, local saving, TXT/PDF print
- ChatGPT/Gemini/Claude dock via Ctrl+Alt+left click or icons; question copy & authenticated external site
- Service worker version and 13-step pager updated; no automatic Actions

Provider limits: ChatGPT, Gemini and Claude disallow dependable third-party iframe use; open their sites externally with the user's session and copy a question instead. No tokens or stealth session access. Browser print dialog allows Save as PDF; the app does not silently generate a binary PDF.

Official exam information remains a user-referenced resource; generated 5-page notes include study prompts and locally recorded notes, not a verified legal commentary or guarantee of correct answers.
