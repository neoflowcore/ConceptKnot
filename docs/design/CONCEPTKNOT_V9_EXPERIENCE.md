# ConceptKnot v9 — 사자·공·새 상호작용 및 Galaxy S Pen (2026-10-28)

## 기준과 작업 범위
- 기존 Production main: \`047cffee0c093d57bb08fea6ee1b7ec1a585ed56\`.
- 사용자가 제공한 새끼 사자 사진(둥근 귀, 짧은 주둥이, 밝은 황갈색, 작고 검은 얼굴 점무늬)을 참고하되, 앱 배경에는 **직접 작성한 Three.js 기하형 3D 캐릭터**로 구현한다. 이미지·캐릭터 모델 복사와 API 호출은 없다.
- 기존 17초 중앙 원형 공 레일은 변경하지 않는다. 책·메모장·연필·상승 차트·잔디 구멍·연필 소나무와 공 루프를 그대로 유지한다.

## 새 기능
1. **자는 새끼 사자** \`assets/ck-sleeping-cub-v9.js\`: 앞쪽 잔디에 배를 깔고 작은 푸른 공을 베고 잠든 자세. 닫힌 눈·코·입·6개 볼 점무늬·귀 속 그늘·수염·앞발·꼬리. 호흡 1.28 rad/s, 귀가 가끔 떨리고 꼬리가 약하게 흔들리는 절제된 모션. 배경 3D 모듈의 \`playTime\`을 공유하여 화면 비활성/집중 입력 시 멈춤. SVG 폴백에도 동일한 콘셉트의 원본 일러스트를 작성.
2. **새의 공 쪼기**: 새를 공 레일 앞쪽 x=-5.55,z=-21.8로 배치하고 부리 앞으로 접근하는 공을 3D 세계좌표로 검사. 2.65 단위 이내 접근 시 0.62초 쪼기 시도, 최소 간격 1.15초. 공별 인덱스를 기억하여 같은 공에 대한 중복 시도를 억제. 17초 레일 한 바퀴 동안 공 6개가 부리 가까이 접근한다.
3. **오른쪽 아날로그 시계**: 한국시간(Asia/Seoul) 기준 시·분·초침이 있는 직경 34px 작은 시계. 기존 날짜·설정 버튼 유지. 1초 간격 독립 갱신이므로 전체 앱을 리렌더하지 않는다.
4. **Galaxy Note / S Pen 전용 칠판 모드**: 기존 필기 저장 키를 유지하면서 원터치 토글, 펜·형광펜·지우개, 굵기, 필압, 색상(기존 분필 색상), 실행취소·재실행, 지우기, 확대 필기. 펜의 \`pointerType\` 검사로 손가락을 붓질로 받지 않음. 모드 토글 시 텍스트 입력 초점을 빼고 전용 모드에서 숨겨진 입력칸을 다시 포커스하지 않도록 조치.
5. **스크롤**: PC에서 휠을 통한 강제 탭 전환을 제거, 현재 학습 문서가 끊김 없는 기본 브라우저 스크롤로 내려감. 탭 클릭의 전환 애니메이션은 유지. 모바일은 문서 끝에서 명확한 추가 스와이프(105px 이상)가 있을 때만 다음/이전 탭을 이동하며 입력·필기·내부 스크롤 보호.
6. **모바일 교환**: 칠판·본문을 좌우가 아닌 위아래로 반전하며 340ms FLIP 애니메이션. 실제 버튼은 시각적으로 19px 초소형 원형, 손가락 터치는 투명 영역으로 넓힘. 데스크톱 구분 손잡이도 19px 미세 유리 질감으로 통일.

- 기존 학습 원문 400문항, 분필 기록, S Pen·타이핑·오답 JSON 상태는 수정하지 않음.
- Service Worker 새 캐시 \`conceptknot-living-garden-v9\`: 신규 3D 사자/시계 JS와 CSS 사전 캐시.
- GitHub 일반 Push에서 자동 빌드/Actions를 트리거하는 워크플로는 추가하지 않음. ZIP·EXE·APK 등 설치 아티팩트 생성 없음.
- 검증: 모듈 구문 + Three.js 경량 모의 환경에서 17초 동안 6개의 공이 각각 부리를 지나가는 것 확인. 실제 Chromium/Galaxy 화면의 렌더링·손바닥 방지·애니메이션 프레임 검수는 별도 실기 게이트.
