# ConceptKnot UI 수정 계획 v3.0 — 2026-10-28

**기준:** 확정된 Clay 풍경·글래스 화면과 Typing.works형 타이핑 UI 유지. 기능과 `recallgraph-first-exam-v1` 로컬 기록 보존. 코드 일괄 반영, GitHub Actions·설치파일 생성 금지.

## 1. 칠판 입력 오류 최우선 해결
- 원인: 글래스 CSS가 `.ck-v7-board-overlay`를 `position:relative`로 덮어써 높이가 줄어, 실제 `.ck-v7-writing-surface` 입력면이 접힘.
- 수정: 오버레이를 칠판 전체 높이로 복구. 텍스트 입력·분필 미러·S펜 캔버스의 레이어/포인터 이벤트 정리. 마우스 클릭 후 즉시 키보드 입력, S펜으로 즉시 손글씨(모드 전환 없음).
- 입력 내용은 기존 문항별 로컬 저장 유지. 탭/문항 전환 및 새로고침 후 복원 검증.

## 2. 칠판 UI
- 분필색·실행취소·다시실행·지우기·JSON 버튼 높이·아이콘 크기 **약 1/2**로 축소.
- 제목과 입력면 사이 빈 여백 제거, 툴바를 한 줄에 위쪽으로 타이트하게 정렬.
- 글래스 효과·1:2 드래그 레이아웃 유지.

## 3. 타이핑 UI 및 이동
- 이전 문항 버튼 추가. 처음/마지막에서 비활성, 기존 문항의 입력/기록/메모 복원.
- 시간·타수·정확도·입력 수·**기출 문항 완료율 도트**를 연도 선택 높이 수준인 **한 행**에 표시. 좁은 화면에서는 정보행만 가로 스크롤.
- 완료율은 선택한 자료/과목 범위 내 **고유 완료 문항 수 / 전체 문항 수**로 계산. 반복 완료는 중복 집계하지 않음.

## 4. Typing.works 방식 입력 경험
- 입력 연습의 원문에서는 쉼표·마침표·괄호·따옴표 등 문장부호를 제거, 표시용 질문·보기는 원문 보존.
- 채점 대상은 한글·영문·숫자. 공백·문장부호는 입력을 요구하지 않고 자동으로 건너뜀. 한글 IME 조합 중에는 완료 기록을 확정하지 않음.
- 활성 **한 줄**을 또렷하게 표시하고 입력 진행에 따라 문장이 고정된 자리에서 채워짐. 커서·입력 글자의 짧은 타자기 애니메이션과 오류 표시 추가.
- 타수·정확도·완료 기록은 새 정규화 규칙과 일치시킨다.

## 5. 최소 검수
1. 메모 입력 및 S펜 그리기·자동저장·복원
2. 이전/다음, 연도/과목 변경, 중복 완료율 제외
3. 기호 없는 타이핑, 틀린 글자 색, 한글 조합, 완료 저장
4. 1536×1024 및 모바일에서 입력면·툴바·상단 통계의 배치
