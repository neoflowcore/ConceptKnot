## 1. 오른쪽 학습 패널 크기
- 근본 원인: 바깥 분할 레일은 90px까지 줄지만, 내부 `.quiz-layout`은 `minmax(260px,.7fr)` 때문에 최소 폭 260px을 요구. 결과적으로 문항 번호·안내 카드가 부모 밖으로 튀어나감.
- 해결: `container-type:inline-size`를 학습 본문에 적용. 760px 이하에서 모의고사/핵심이론/음성/그림연상 내부 그리드를 1열로 전환. 번호 그리드는 `repeat(auto-fit,minmax(30px,1fr))`. `min-width:0`, 줄바꿈·오버플로 제어.
- 목표: 좁은 오른쪽 컬럼에서는 옆으로 배치하지 않고 위아래로 놓는 의미 있는 축소. 90px까지 물리적 압축은 지원하지만 극소 폭에서는 가독성을 보장하지 않음.

## 4. 40개 그림연상과 기출 연결
- `assets/ck-visual40-v20.js`: e1–e20(부동산학개론), c1–c20(민법 및 민사특별법), 각기 다른 두 그림·그림 단서 문장·2021–2025년 검증 기출 ID.
- `그림 연상` 메뉴에서 과목을 전환하면 20개씩, 전체 40개를 선택할 수 있음. 그림 카드 → 스스로 설명 → 정답 확인 → 주의할 함정 → 관련 기출(연도/문항) PDF·OMR 이동 → 핵심 이론 재방문.
- `핵심 이론`의 개념 목록 각 20행마다 별도 ◈ 그림 버튼을 제공. 현재 개념의 카드 내에서도 바로 이동.
- 링크는 기출을 분석하기 위한 *연관된 사례* 표시이며 모든 그림이 원문 도해를 재현한 것은 아님. 관련 자료의 개정법령 및 원문 확인 필요.

## 5. 선택 연도·과목 전 문제 자동 이어듣기
- `문제·정답 듣기`에서 과목 탭(두 과목), 연도(기존 2016~2025) 선택 → **연도·과목 전체 연속재생** 단일 버튼.
- 음성 읽기 선택: (가) 문제+정답 지문, (나) 정답 문장만. 기기 기본 한국어 음성으로 40문항 연속 재생. 페이지를 넘겨도 재생 큐 유지. 하단 재생 막대로 진행·일시정지·정지. 실제 정답 키가 확정되지 않은 문항·전원정답 제외, 제외 건수 표시.
- `ttsSaveOfficial` 호출 없이 저장된 정답/문장만 재생하며, 수정 중이던 자료를 자동 덮어쓰지 않음. 긴 글은 190자 안팎의 짧은 조각으로 나눠 TTS 엔진의 긴 발화 오류를 완화.
- 사용자가 AI 여성 음성을 선택했어도 **장시간 연속재생은 저지연 기본 기기 한국어 음성**으로 처리. 별도 380MB 모델을 연속 생성하도록 강제하지 않음.
- 웹브라우저 음성 합성은 Android/Windows 기기 절전이나 잠금 화면에서 계속 재생되는 것을 보장하지 않음. 실제 Brave/Chrome의 백그라운드·화면 잠금 실기가 필요함.

## 6. 최신 5개년 모의고사 5세트 (정답키 검증)
- `assets/ck-mock-v20.js`: 2025, 2024, 2023, 2022, 2021년을 세트 1–5 기준으로 사용. **각 세트 80문항 = 부동산학개론 40 + 민법 40**, 전체 다섯 세트 400문항.
- 정확성 원칙: 검증된 A형 문항의 출제 조건·문제 본문은 그대로 두고 선지 배열을 매 세트 결정적 시드로 재배치. **이것은 ‘선지 재배열형 변형’이며 완전 새로운 문제/해설을 창작한 것이라고 주장하지 않음.**
- 복수정답 문항(2개 선택지 인정)은 새 번호로 모두 매핑해 정답 처리. 전원정답 5문항은 같은 번호의 다른 최근 연도 검증 문항으로 대체하여 매 세트 80문항을 유지, 출처 연도 표시.
- `기출형 연습` 탭에서 기존 15문항 창작 연습(세트 0) 유지, 1~5세트 선택, 답안 진행률/정답·오답/문항 선택/이전·다음/현재 세트 초기화 및 원문 PDF·OMR 이동.
- 문항 출처를 표시하고 자체적으로 새로운 해설 사실을 지어내지 않음. 복수정답 인정, 답안/오답 메모는 로컬 저장.
