# CONCEPTKNOT v8 · One coherent kinetic garden

A 17-second continuous 3D closed rail in the middle of the page carries colored rotating balls past a book, pencil, checklist, rising chart, funnel and grassy hole. All animated elements use one shared phase, not unrelated oscillations. Original procedural Three.js geometry; no copied Clay models, imagery or code. Desktop runs six balls and mobile four. Pauses automatically when the tab is hidden, study-focus is active or reduced-motion is requested.
