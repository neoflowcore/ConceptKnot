# ConceptKnot 디자인·배경 최종 실행계획 v2.0
2026-10-28 · 확정안 · 개발 착수

> 디자인 기준: 사용자가 승인한 1536×1024 타이핑 화면 (wide_colorful_ui_concept_screenshot_illustration.png). 최근 캡처 image(20261028-062544).png은 의도 보조 자료. 직전 v1의 메뉴·1:2 분할·통합칠판·기능을 계속 보존한다.

## 1. 반드시 고칠 두 문제
**A. 레퍼런스 수준의 입체 배경**: 이전 초록색 도형 SVG는 폐기한다. 하늘, 구름, 먼·중간·앞 언덕, 잔디 입자, 꽃과 나무를 독립적으로 합성한다. 균일한 녹색/푸른색 평면, 커다란 빈 공간, 한 장의 UI 스크린샷을 배경으로 쓰는 방식은 불합격이다. Clay.com은 실제 일러스트레이터/애니메이터/프런트엔드 인터랙션의 협업으로 구현된 디자인이므로, 단순 CSS 원형만으로 복제했다고 주장하지 않는다.

**B. 모든 학습 탭의 일관된 유리 재질**: 상단 흰색 메뉴 캡슐, 왼쪽 모네 그림을 대체하는 단일 통합 메모·S펜 칠판, 오른쪽 타이핑·학습·기출·통계·입력·팝오버에 같은 glass 토큰을 적용한다. 반투명 배경과 실제 뒷풍경을 함께 두어 backdrop-filter가 작동하게 한다. 유리 효과는 가독성보다 우선하지 않는다.

## 2. 배경 제작/확장 설계
- **원본 아트 목표:** 고품질 4096×2304 이상 아트 마스터(별도 원본·라이선스·해시 기록). 단일 이미지 cover는 잘림이 생기므로 무한 확장의 해법이 아니다. 원본 생성·검증 전 단계에서는 프랙탈 노이즈/빛/입체 그라데이션이 포함된 풍경 SVG를 하위 품질 폴백으로 운용한다. 배경 화면 전체를 완성된 UI가 있는 스크린샷으로 사용하지 않는다.
- **5+ 레이어:** 하늘의 광원·안개·구름, 먼 동산, 중간 동산, 근경 잔디의 섬유/점무늬, 지면 꽃·나무, 새/근경 장식.
- **대응 화면:** 1536×1024, 1920×1080, 2560×1440, 1280×800, 768×1024, 390×844, 320px. 화면 위·양옆·아래 모두 sky+hill+grass로 채워 빈 배경/흰 띠가 생기지 않게 한다. 멀리 있는 사물과 앞의 사물은 별도 safe area 기준으로 재배치한다.
- **품질:** 섬세한 입자감, 원근·매트한 질감, 같은 방향의 부드러운 그림자, 밝은 가장자리 반사광. 노이즈를 전체에 과도하게 뿌려 학습 글씨를 지저분하게 만들지 않는다.
- **성능:** 가능한 AVIF/WebP 변형 1440/2560/3840, 가벼운 SVG 폴백, 이미지 크기·데이터 전송 예산. 정적 필터 결과 재활용; 매 프레임 fractalNoise/blur를 재계산하지 않는다.

## 3. 생동감 있는 애니메이션
- 나무 바람: 나무마다 5~9초의 다른 주기/위상, 줄기 뿌리 고정, 수관 1~2도만 흔들림.
- 새: 오른쪽 나무/장식에 앉아 있는 개별 SVG 오브젝트. 커서 이동 시 requestAnimationFrame으로 고개 ±9도, 눈동자 ±2px을 부드럽게 보간. 드문 눈 깜박임, 마우스가 벗어나면 정면 복귀.
- 구름: 수십 초짜리 느린 횡이동. 전경 시차 이동 ±10px 내. 타이핑 영역에 포커스하면 움직임 강도를 줄인다.
- 터치 환경: 헤드 트래킹 대신 자연스러운 낮은 빈도의 idle 반응. 화면 숨김/미디어 reduced-motion/저전력에서 정지한다.
- 타이핑 IME, S펜 pointer events, 드래그 리사이즈와 모션이 서로 방해하지 않아야 한다.

## 4. 통합 Glass 디자인 토큰
| 부위 | 기본 투명도 | 블러 | 시각 우선순위 |
|---|---:|---:|---|
| 메뉴 캡슐 | 흰색 90~96% | 10px | 선명한 메뉴 글자 |
| 왼쪽 칠판 | 딥틸 22~35% | 10~14px | 풍경 투과 + 흰 분필 가독성 |
| 오른쪽 기본 작업창 | 흰색 65~82% | 18~24px | 지문 읽기·탭 구분 |
| 문제/선지 카드 | 웜화이트 78~90% | 8~12px | 선택지 대비 |
| 타이핑 입력/통계 | 블루화이트 76~88% | 12~18px | 희미한 고정 원문 + 입력 피드백 |
| 모달/팝오버 | 흰색 92~96% | 20px | 장식보다 포커스 |

- 공통 CSS custom properties: glass fill, blur, border, shadow, highlight, border radius. 탭별 색 변형은 같은 토큰 위에서만 허용.
- 이미지/필터가 글라스 배경을 가리지 않게 backdrop-root 생성 요소를 확인한다. 저사양 브라우저에서는 동일 명암의 단순 반투명 배경으로 graceful fallback.
- 전체 타이포: 영어/숫자 Nunito, 한국어 NanumSquareNeo. 기존 폰트 규칙을 교체하되 타이핑 엔진·문항 데이터 구조는 유지.

## 5. 화면·데이터 불변 조건
- 최상단 흰색 둥근 탭 바 및 짙은 활성 탭 유지. 불필요한 캐치프레이즈/AI다운 문구 금지.
- 왼쪽 1/3 오른쪽 2/3 비율의 드래그 가능한 작업 영역; 320px 이상에서 반응형. 왼쪽 **하나의 칠판** 안에 키보드+S펜 직접 입력, 모드 버튼 없음. 문항별 텍스트·펜획·색상 로컬 저장 및 JSON 내보내기 유지.
- 오른쪽 typing.works형 실제 기출 5개년·문항/정답·타수·정확도·시간·기록 격자. 고정된 희미한 원문 위에 입력만 채색하고 원문이 밀리거나 겹치지 않게 유지.
- home/reverse/theory/visual/typing/listen/quiz/calc/exam/venn/wrong/plan/settings 공통 유리 테마. 문제·기출·메모·타이핑·TTS·계산 등 기능과 기존 로컬 기록 삭제/변형 금지.

## 6. 개발 단계와 검증
| Phase | 작업 | 수용 기준 |
|---|---|---|
| V2-0 | 이 문서 확정 | 요구사항·참조 시안·변경 금지 항목 명시 |
| V2-1 | 새 텍스처 풍경·무한 배경 구조 | 모든 화면비에서 빈 색상 면/흰 띠/자산 단절 방지 |
| V2-2 | 나무 바람·새 시선·구름·시차 | 입력 방해 없고 reduced-motion 대응 |
| V2-3 | 공통 글라스 토큰 및 전 탭 적용 | 뒤 풍경이 보이고 높은 대비로 읽힘 |
| V2-4 | 실물 3D/레스터 아트와 시안 비교 개선 | 실제 페이지 캡처로 차이 측정 후 반복 수정 |

**99% 기준**은 개발 전 보증이 아니라 최종 목표다. 승인 시안과 동일 1536×1024 크기에서 배치·질감·조명·새와 나무·UI 투명도·색상·폰트의 차이를 육안/캡처로 검수한다. 별도 4K·모바일·태블릿 확인. 미완료 부분은 완료라고 표시하지 않는다.
