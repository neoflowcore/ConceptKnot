# ConceptKnot v107 · 문제 분석 및 TTS 경로 통합

**기준**: ConceptKnot v106 main 964db21d278b119c8896a3e64d70730ecdeaa8b6 (2026-11-04).
**범위**: 공식 기출 원문/정답 보존, AI 추측 답안·해설 자동 승격 금지, 로컬 개인 학습 자료 보존.

## 문제 분석
- 기존 2021~2025년 해설 초안·검수 모달을 2016~2020년 등록된 문제로도 확장(추가 해설 파일은 아직 없음).
- 문항의 '옳은/틀린', ㄱㄴㄷ, 계산/수치, 그림/그래프, 법령/판례, 복수/전원정답 여부를 **자동 분류 후보**로 표시한다.
- 각 문항에 체크리스트와 개인 근거/선지 판단 0~5 현황을 명시한다. CK83Links를 통해 개인 개념/근거 편집기로 진입한다.
- 분석 대시보드에 실제 브라우저에서 로드된 10개년 문항 수와 개인 검토/출처 진행도를 표시한다. 800 등록 자체를 내용 전문가 검수 완료로 표기하지 않는다.
- 외부 PDF 참조 링크와 Q-Net 공식 출처 페이지 링크를 별도 표시해 출처 오인 방지.

## TTS
- 분석 모달에서 '문제+정답', '정답만', '문제+5선지' 바로 듣기와 과목 40문항 연속 듣기를 제어한다.
- CK76Voice.playOfficial(year, number, mode, scope) 공통 진입점을 추가, 기존 기기 음성/로컬 AI 여성 Supertonic 3(F1~F5), 0.75~2배속(기본 1.5)을 활용한다.
- 2016~2025년 공식 A형 **등록 정답 배열 q.correct를 우선**. 사용자 입력 답안지로 최종정답이 바뀌지 않도록 한다.
- 8개 전원정답 문항은 정답 암기·문제+정답 재생에서 제외, '문제+5선지'에서는 지문을 읽되 전원정답이 모두 참이라는 오류를 명확히 경고한다.
- 모의·문항 화면과 분석 화면을 같은 음성 경로로 연결. 중단/인터럽트 상태를 침묵으로 숨기지 않고 오류 상태로 표시한다.
- 화면 잠금 상태 재생, Web Speech 음질·모바일 허용 여부, AI 모델 다운로드/음색은 실기 필요. 380MB 모델은 자동 로딩하지 않는다.

## 안전과 실기 기준
- 이번 범위는 원본 문제/정답·법령/해설 JSON을 수정하지 않고 사용자 개인 저장값을 삭제하지 않는다.
- 초안 해설 32/400, 미작성 368/400, 전문가 검수 0/400 및 0/2000(기존 데이터 점검 기준). 위 숫자 자체는 새로 검증·승격하지 않는다.
- 기존 운영 체크포인트 19/30=63%는 최신 제품 완성률이 아님; 디자인 초안 일치율 미측정.
- 수동 Node 문법/모의 로직 검사와 실제 한국어 음성, Android Brave/S펜, PDF, GPU는 별도.
- GitHub Actions / 자동 Vercel Git 배포 / 설치 아티팩트 생성 금지. 명시적 수동 운영 배포만 수행.

## 수기 실기 검증
1. 2016·2024년 문항 분석 열기: 유형 후보/정답 인정/검토 체크리스트와 개인 근거 연결이 구분되는지.
2. 일반·복수정답·전원정답 문항 각각에서 음성 3모드 재생; 모두정답은 정답 암기 모드에서 생략되는지.
3. TTS 연속 듣기(연도·과목 40문항) → 일시정지 → 재개 → 정지 → 다른 문항 재생. 실음성 1.5배속/음질, 안드로이드 백그라운드 제한 확인.
4. AI 여성 모델은 Wi-Fi 환경에서 수동 준비 이후 테스트. 다운로드 도중 종료/화면 전환 시 늦게 시작되지 않는지.
5. 기존 문제 채점/노트/모의고사/칠판 및 공식 정답 변경이 없는지 확인. 개인 데이터 JSON 백업 후 진행.
