# ConceptKnot v63: 초협폭 칠판 및 분필 굵기 조절
작성일: 2026-10-31

## 수정된 동작

1. 칠판 메모 글씨 굵기는 **400(보통)**을 기본값으로 사용한다. 종전 `font-weight:650!important` 강제 스타일을 뒤에서 덮어쓴다.
2. 칠판 기능 행 왼쪽에 `B` 토글을 추가한다. 누르면 글씨가 700(굵게)/400(보통)으로 전환되고 `ck63NoteBold`로 저장된다. 선택 문단별이 아닌 칠판 전체 표시 모드다. 기존 필기 내용/펜 획을 변경하지 않고 전체 `render()`를 호출하지 않는다.
3. 칠판 폭이 **275px 이하**로 줄면 `CONCEPTKNOT / NOTE`, 문항 제목, `● LOCAL`, `✓ 자동 저장`, TXT/PDF 내보내기 UI를 숨긴다. 기능과 저장 데이터는 삭제하지 않으며 다시 넓히면 표시된다.
4. 좁은 폭에서 S펜, B, 분필색상, 커스텀색, 손글씨 뒤로/앞으로/지우기, JSON 다운로드 버튼을 **칠판 상단에 유지**한다. 가로 스크롤 대신 폭에 맞춰 컴팩트하게 줄바꿈한다.
5. 크기 슬라이더(`가`, `data-ck10-font`)를 **기능 버튼 다음, 칠판 도구 모음의 마지막 전체 폭 행**으로 옮긴다. S펜 활성 시 펜 굵기 슬라이더도 마지막 행에 배치한다.
6. 폭이 **156px 이하**인 극단적으로 좁은 칠판에서는 패딩·버튼 간격을 더 줄이고 폰트 크기 출력 숫자만 감춰서 슬라이더 공간을 확보한다. 최소 드래그 폭 86px은 유지한다.
7. `container:ck63-board / inline-size`를 사용하므로 화면 해상도가 아니라 **실제로 드래그한 칠판 폭**을 기준으로 전환된다. 타이핑/문제 영역과 S펜·펜 스코프에는 영향을 주지 않는다.

## 구현 및 안전
- `index.html`: 상태 초기값, B 버튼과 캡처 클릭 핸들러, 크기 슬라이더 DOM 순서 변경, 스타일시트 로드
- `assets/ck-board-compact-v63.css`: 400/700 폰트, 컨테이너 쿼리, 최소 폭·레이아웃
- `sw.js`: 캐시 버전 갱신 및 새 스타일시트 등록
- `tests/board-compact-v63.test.cjs`: B 활성/비활성 및 저장, 레이아웃 규칙, 최소 너비, 타 도구·TXT/PDF 기능 보존 검사
- 자동 GitHub Actions/Vercel Git 배포는 비활성 유지. 실기 검증 필요 시 좁은 너비 86/120/156/275/350px과 SPen ON/OFF 및 모바일 피벗을 확인한다.
