# ConceptKnot v101 · 해설 작업대 복원·재시도 안정화

기준: main v100 (1b68dce), 2026-11-02. 자동 배포/Actions/설치파일 없음.

## 실제 코드 수정

1. **로드 반환값 일관성**: 이미 해설이 로드되었을 때도 Promise를 반환하여 `load().then(...)` 에서 예외가 생기지 않도록 함.
2. **연도별 해설 묶음 검증**: 각 파일의 80문항, 문항 ID·과목·번호·5개 선지·공식 채점 인정 번호의 구조가 실제 등록 기출과 일치할 때만 정상 데이터로 취급. 답안을 자동 변경하지 않음.
3. **연도별 정상 데이터 보존**: 캐시된 정상 해설은 재확인 중의 네트워크 실패/손상 응답 때문에 지우지 않음. 실패 건수·재시도 버튼은 UI에서 표시.
4. **복원 최신 기록 보호**: 개인 검토 진행 JSON 복원 시 백업 레코드의 시각이 현재 레코드보다 오래되면 현재 상태를 보존. 겹침이 있으면 확인 후 저장하며, 새 기록이 없으면 쓰기를 생략.
5. **화면 중복 경고 제거**: 시각 미검토 배지가 두 번 나오는 문제 수정.
6. **배포 캐시 버전**: 페이지 JS 참조와 서비스 워커 캐시 갱신으로 이전 버전과 구분.
7. **자동 실행 비용 유지**: Vercel git.deploymentEnabled=false 유지, .github/workflows 추가하지 않음.

## 한계 및 실기 필요

- 개인 저장은 단일 기기의 localStorage이며 네트워크 동기화/분산 트랜잭션이 아님.
- 원문/법령 검수는 자동으로 완료 처리하지 않음. 공식 기출 800문항 및 최근 5개년 해설 400문항 구조와 전문가 내용 감수는 다름.
- 실제 Android Brave, S펜 물리 버튼, 팜리젝션, PDF, 여성 TTS, 100분 모의고사 장시간 사용, GPU 사용량과 디자인 초안 비교는 별도 실기 검증 필요.
- 이번 변경은 운영 수동 배포 전에는 https://conceptknot.vercel.app 에 반영되지 않음. 사이트 업데이트를 위한 자동배포를 켜지 않는다.
- **실기 검증 전에는 기존 브라우저 학습 데이터를 JSON 백업**하고, 새 정적 HTML을 정상 반영한 테스트 환경에서 해설 작업대를 두 차례 열고 닫아 오류 없이 유지되는지 확인.
- 해설 연도별 파일 요청을 개발자 도구에서 실패 처리하여 재시도 메시지를 확인하고, 네트워크 복구 후 정상 자료가 로드되는지 확인.
- 기존 개인 기록보다 오래된 JSON 복원 시 최신 기록이 유지되는지 확인.
