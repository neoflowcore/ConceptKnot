# ConceptKnot v158 — 가격상한·가격하한 직접 조작과 17종 생활 예시
기준선: main f9b43886a4c810c4b64339a9f7898bd60e47687b (v157). 2026-11-11 (KST). 범위는 ConceptKnot 공인중개사 1차 학습 웹앱만 해당.

## 이번 배포의 변경 사항
- 기존 17개 도식 중 최고가격제 차트에 **독립된 가격상한/가격하한 실험실**을 추가. ① 상한/하한 선택 ② 가격선 SVG 직접 위아래 이동·슬라이더·키보드 조절 ③ E₀와 현재 정책선 비교 ④ Qd·Qs 및 초과수요·초과공급·비구속 판단을 연동.
- 구속력 있는 상한: 균형가격보다 낮은 가격선 → Qd > Qs, 부족. 구속력 있는 하한: 균형가격보다 높은 가격선 → Qs > Qd, 잉여. 비구속적 가격선과 정확한 균형선에서는 부족·잉여 표시 금지.
- 8개 시장형 도식에 소득 증가·인구 감소·건축비 상승·기술 발전의 가상 상황 버튼(그림 종류에 맞는 경우만) 제공. 기존 선 직접 이동, 기울기, E₀/E₁, Undo/Redo는 그대로 이용.
- 17개 도식의 쉬운 설명/생활 예시/심화/기출 개념 분리. 관찰형 9개에서는 교점 가격을 만들어 내지 않고, 환원율·할인율·탄력성·지대·저량/유량 등 개념별 사례만 제시.
- SVG 정책선 조작 도중 화면 스크롤 방지, 빈 SVG 영역에서는 페이지 스크롤, pointercancel/포커스 해제/탭 숨김 시 정책선 위치 원복.
- 화면읽기 도구가 드래그 모든 프레임을 연속 낭독하지 않도록 확정 상태에서만 안내. 정책선 키보드↑↓/PageUp/Down/Home/End 지원, 기존 곡선 노란 기울기 손잡이에 Home/End를 누르면 평행이동으로 오해하지 않도록 제한.
- v158 서비스워커: 기존 필수 11개는 유지하고 P2·P6 선택 학습 자산은 6종 → **9종**으로 확장. 캐시 세대는 `conceptknot-study-v158-policy-floor-scenarios`. 신규 3종 가격정책 파일만 선택 자산, 이전 캐시 보존 로직과 자동 배포 차단 유지.
- 공식 정답 800문항, 최근 5개년 해설 초안 400건, 기존 응시 답안·필기·개인 QA 기록 키, TTS 모델은 변경하지 않음.

## **반드시 사람이 직접 수행해야 할 수기 실기검증**
1. **업데이트·기록 보존:** 이미 로그인/학습한 기기에서 새 배포를 열고 저장된 답안·필기·PDF·오답 기록이 살아 있는지 확인한다. 브라우저 데이터 삭제·강제 초기화 금지. 기존 문항/해설 사용자 JSON 사본을 먼저 백업한다.
2. **Android Brave/S Pen:** 그래프 탭 → 「최고가격제와 초과수요」 → 신규 「가격상한 · 가격하한 직접 비교」. 기본 최고가격을 균형 아래로 내려 Qd>Qs와 부족이 보이는지 확인한다. 상한선을 균형 위로 올리면 비구속으로 바뀌어야 한다. 「최저가격제」 선택 후 균형 위에서 잉여(Qs>Qd), 아래에서 비구속을 확인한다. 노란 가격선으로 드래그할 때만 화면 스크롤이 멈추고 **빈 영역에서는 세로 스크롤** 가능해야 한다. 두 번째 손가락 개입/손 떼기 전 화면 전환 시 값이 잘못 저장되지 않아야 한다.
3. **17개 그래프:** 정상재 소득↑, 인구↓, 건축비↑, 기술발전 버튼과 선 직접 드래그·기울기 변경을 번갈아 사용한다. 기존 E₀/현재 E₁, 가격·수량 변화방향, 이전/다시, 쉬운 설명·생활 예시·심화·기출 주의점을 대조한다. 9개 관찰형은 가짜 시장균형 가격이 없어야 한다. 기출문제 원래 조건과 사용자가 임의로 바꾼 예시 조건을 혼동하지 않는지 확인한다.
4. **공식 80문항·혼합 5세트:** 100분 타이머, 1~5 선지 단축키, Ctrl+←/→, 과락·과목 채점, 원본 JSON 백업/병합/다른 탭 충돌 보호를 확인한다. 기존 답안 삭제 금지.
5. **오프라인:** 온라인에서 오프라인 진단 실행 후 필수 11개와 선택 9개 확보 상태를 구별한다. 비행기 모드 전환 → 새로고침 → 10개년 기출/그래프/칠판 확인 → 연결 복귀. 캐시 목록 확보는 실제 오프라인 기능 PASS가 아니다.
6. **해설:** 400건은 미검수 초안임을 확인하고, 원전 대조 및 선지별 진위 검토 없이 공식 해설로 게시되지 않는지 확인한다.
7. 수기 검증표에서는 직접 조작 후 PASS/FAIL/미확인으로 표기한다. 실제 기기 결과를 테스트 스크립트가 자동으로 PASS 처리해서는 안 된다.

## 배포 안전
- GitHub Actions 워크플로 신규 추가 금지. `vercel.json` 의 `git.deploymentEnabled=false` 유지, Git Push 자동 배포 금지. 검증에 필요한 수동 Vercel Production 배포만 허용.
- 별도 설치 EXE/APK/ZIP 아티팩트 생성·보관 금지, TTS 모델 다운로드·교체 금지.
- UI 학습용 도식의 가격·수량은 임의 좌표이며 실제 통계, 원본 기출 수치, 법률 전문가 판단이 아님.
