## v153 기능 묶음
1. 기존 17개 SVG 도식 × 5개 = 85개의 사례에서 판단 대상·경제적 이유·예상 정답·그래프 적용 여부를 명시한다. 경제적 원인이 바뀌는 수요/공급 곡선의 이동과 자체 가격에 따른 곡선 위 이동을 분리한다.
2. 기존 9개 수치 모형 × 5개 = 45개 사례의 현재 모델 계산은 유지. 통합 130개 사례의 등록 여부를 테스트한다.
3. 사례별 예측 제출 전 정답/해설 미노출, 그래프 적용 금지. 채점 뒤 E0/E1 적용, 마지막 응답 기준으로 정답/오답 통계, 같은 문제 재도전, 다음 미학습, 오답 재학습 버튼 추가.
4. 도형의 역방향 x 관찰이나 변수 자체가 다른 정성적 사례를 단순 스크러버로 거짓 표현하지 않는다. 그래프 적용이 불가능하면 별도로 표시한다.
5. 모바일 터치용 44px 버튼과 접근성 상태 영역 유지. v153 캐시 및 JS/CSS 버전 교체. 기존 PWA 필수 11개 항목 동일.
6. 신규 v153 독립 테스트에서 85개 정성적 상황과 45개 계산 상황의 수학, 중복 채점 방지, 의도하지 않은 저장 방지 및 구버전 캐시 방어를 확인한다.

## 수기 실기검증 필요 (NOT_RUN)
1. Android Brave/S Pen 및 Windows Brave의 차트 화면에서 선 자체를 드래그한다. 그림 안에서는 페이지가 이동하지 않고 실제 곡선만 반응하며 빈 공간/그림 밖에서는 의도치 않은 변화가 없어야 한다.
2. 수요 D/공급 S 각각 좌우 이동, E0 점선과 E1 실선, 균형가격·균형량 전후 비교 및 Undo/Redo를 확인한다.
3. 17개 개념 차트와 9개 계산 모델에서 각각 5개 상황이 보이고, 네 가지 정답 중 하나를 클릭하기 전에는 그래프 적용이 잠겨 있어야 한다.
4. 오답 선택 → 쉬운 이론 해설 → 같은 사례 재도전 → 오답 다시 풀기 순서 및 중복 학습 집계 방지를 확인한다.
5. 사례를 적용한 뒤에도 앞서 푼 해당 사례의 E0/E1 근거와 판정이 남는지 확인한다.
6. 실제 기출 800문항/100분 실전 모의고사/개인 메모, 탭 복귀, PWA 오프라인, 다크모드에 영향이 없는지 점검한다.

운영 배포가 READY이고 소스 검사가 PASS여도 실제 기기 테스트는 NOT_RUN 상태로 유지한다. 최종 커밋 SHA와 운영 배포 SHA가 같아야 한다.
