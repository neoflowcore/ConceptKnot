## 결정 / 계획 변경 이유 및 영향
- **P4의 학습 열람·기출 원문 PDF·2,000선지 학습 후보/검증 UI는 MVP 기능 범위 종료**. 사용자 확인 화면에 따라 기존 원문/이론창을 유지하고, 이제 **기출 문제풀이 → 필요한 기본 이론 → 직접 도형차트 실험 → 해당 기출로 복귀**에 투자.
- 구 마스터의 **“TTS LAST” 순서를 변경**하여 TTS 실사용과 P6-B 도형차트를 다음 우선순위에 병렬 배치. P4 잔여 전문가 검독은 별도 콘텐츠 QA 백로그. 2021~2025 공식 해설 인증·출제 당시 법령/판례 원전 검독을 완료로 간주하지 않음.
- Source-of-truth는 검증된 2016~2025 공식 A형 800문항 ID/선지/인정정답. 개인 오답/필기/시험·개념 링크 저장키는 수정하지 않음.

## MVP 경계와 잔여 작업
- 등록: 공식 A형 800/800. 2021~2025 별도 P4 400문항/2,000선지 구조 정합. 새 사용자 검토 과정에서 2020년 자료를 400문항 계산에 섞는 이슈는 v170 수정됨.
- 학습용 후보: 2,000선지 중 총 1,286개 개별/문항 문맥 후보, 714개 개별근거 미작성. AI 개별 초안 808개, 기존 개별 332개, 문항 단위 문맥만 146개. 구조상 MVP 종료와 **각 선지의 전문가 법리검수 완료는 서로 다름**.
- Q-Net 문제지 원본 첨부 PDF·시험 당시 법령·판례의 **독립 전수 검독 0/2,000**, 전문가 감수 서명 **0/2,000** 유지. 인증된 해설 게시 0. 사용자 원문과 정답/메모/개인 평가 저장기록의 비파괴 원칙 유지.
- TTS: 기존 대형 Supertonic 3 모델 `models/tts/manifest.json.distributionReady=false`; **실제 한국어 AI 여성 음성 다운로드/호스팅/실청취 구현 완료가 아님**. 웹 Speech native 처리 개선 1차 배치이고 Android Brave/Windows 한국어 실청취·긴 40문항 백그라운드·고음질/성능 인수 별도.
- 도형: 기존 P6-B 교점·곡선 조작·전후 비교 도입 상태. 이번에는 실제 원문에서 조작형 개념까지 이동·돌아오기. 차트 17종 전체의 이론 태그 독립 검수, 실제 펜 제스처/기기 QA는 미완.
- 앱 전체 개발률·디자인 원본 일치율: **미측정**.
- 자동 테스트·Preview·Production은 **실제 검사 로그 확인 후에만 완료** 기록; 사용자 하드웨어 실기검증은 미실행.
