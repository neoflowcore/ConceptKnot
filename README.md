## 구현 원칙

- **능동 인출**: 먼저 답을 떠올린 뒤 확인. 정답을 읽기만 하는 방식보다 회상 연습을 우선합니다.
- **선지 대비**: 정답뿐 아니라 왜 나머지 선지가 틀렸는지 학습합니다.
- **간격 반복**: 기억 못함→15분, 부분 기억→1일, 설명 가능→3일의 *기본 설정*. 개인별 최적 간격을 과학적으로 예측한다고 주장하지 않습니다.
- **정답 출처**: 내장 정답과 수동 등록 정답 모두 A형·최종정답·복수정답 확인이 필요합니다.
- **안전한 진행**: 자동 배포, GitHub Actions, EXE/APK 생성, 사용량이 발생하는 CI 설정은 포함하지 않습니다.
- **데이터 보관**: 학습기록은 브라우저에만 저장. `내 데이터`에서 JSON 백업/복원이 가능하며 타 브라우저·기기와 자동 동기화되지 않습니다.
- **레거시 호환**: 기존 MVP의 저장 키 `recallgraph-first-exam-v1`을 계속 사용합니다.
