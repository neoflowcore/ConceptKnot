# ConceptKnot | 개념결

**브라우저에서 바로 공부하는 공인중개사 1차 학습 보조 웹앱.**

2026년 제37회 시험(10월 31일) 직전 집중학습을 위한 웹 우선 MVP v0.2.
원래의 RECALLGRAPH STUDY 마스터 구상을 계승하되, 저장소/사용자-facing 브랜드는 **ConceptKnot**으로 통일합니다.

## 실행하기

```bash
# Node.js 20+ (의존성 설치·빌드·GitHub Actions 필요 없음)
node tools/serve.cjs
# 브라우저에서 http://127.0.0.1:8765
```

`index.html`을 Chrome/Edge로 직접 열어도 기본 학습 기능은 실행됩니다. 파일 직접 열기에서는 서비스워커/PWA 설치 기능은 동작하지 않습니다.
기출 외부 PDF와 Q-Net 링크를 열려면 인터넷 연결이 필요합니다. 학습 입력·오답·필기·백업은 브라우저 내부에서 처리합니다.

## 공부 흐름

1. 학개론 과목 선택 → `핵심이론` 20개 인출 → `비교 다이어그램`의 차이·공통 영역 떠올리기
2. `10개년 기출`에서 최근 연도 A형 PDF 원문 보기 → 1~40번 OMR 마킹 → 채점
3. 민법 과목 선택 → 위 과정을 41~80번으로 반복
4. `80문항 모의고사`에서 원문과 100분 타이머로 두 과목 연속 연습
5. `오답·복습`에서 틀린 원인을 직접 기록하고 단원을 지정해 핵심카드로 돌아가기
6. `오늘의 복습`에서 도래한 카드만 재인출 → `학습 통계`로 약점 확인 → `내 데이터`에서 백업

## 시험 일정과 점수

- Q-Net: https://www.q-net.or.kr/site/junggae (2026년 시험 10월 31일)
- 1차: 부동산학개론 40문항, 민법 및 민사특별법 40문항.
- 두 과목 각각 40점 이상 **동시에** 평균 60점 이상을 만족해야 1차 합격 기준에 해당합니다.
- 기출 출처 안내: https://www.q-net.or.kr/cst003.do?gId=08&gSite=L&id=cst00309
- 2026년 시험의 최종정답은 아직 발표되지 않았으며, 이 앱은 **2016~2025년 과거 기출**만 취급합니다.
- 과거 법령·판례는 2026년 출제 기준과 다를 수 있습니다. https://www.law.go.kr/ 의 현행 법령과 Q-Net 공식 자료 대조가 필요합니다.

## 개인정보와 보안

서버, 추적 쿠키, 로그인을 사용하지 않습니다. 학습기록, 개인 필기, 입력한 답안은 브라우저 `localStorage`에 저장됩니다.
외부 PDF 열기 및 Q-Net 방문은 해당 사이트에 네트워크 요청을 보낼 수 있습니다. 로컬 PDF는 그 탭에서 임시 표시하며 자동 업로드되지 않습니다.
브라우저 저장 데이터를 지우거나 다른 기기로 옮길 때는 JSON 내보내기/가져오기가 필요합니다.

## 개발과 검증

```bash
npm test             # Node.js 내장 모듈만 사용, no build/CI
node tools/serve.cjs # 로컬 정적 개발 서버
```

배포/설치 아티팩트를 만들지 않습니다. `.github/workflows` 디렉터리를 두지 않아 일반 push로 Actions를 자동 호출하지 않습니다.
실제 기기에서 PDF 임베드, 키보드 OMR, 모바일 시각 표시, 사이트 저장 유지 여부는 사용자의 **실기 확인**이 필요합니다.

참고: `docs/PHASES.md`, `docs/DATA_PROVENANCE.md`, `docs/ARCHITECTURE.md`, `docs/QA_MANUAL.md`.
