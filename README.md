# ConceptKnot · 개념결

공인중개사 **1차(부동산학개론 / 민법 및 민사특별법)** 시험을 위한 문제 중심 학습 웹앱.

**문제를 먼저 풀고 → 정답·오답 선지를 해부하고 → 필요한 이론만 인출하고 → 같은 규칙의 새 문제로 전이하고 → 원문제로 재도전**하는 흐름에 집중합니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열면 됩니다. 서버, 로그인, 유료 API, 패키지 설치가 필요하지 않습니다. 학습기록은 `localStorage`에 저장됩니다. 공식 기출 PDF 링크는 인터넷이 필요합니다.

## 10개년 활용 순서

1. `⚡ 기출→이론 학습`에서 **자체 제작 문제**를 처음 풀어 취약한 규칙을 확인합니다.
2. 틀린 선지를 구별하는 이유를 읽고, 관련 핵심개념을 가린 상태에서 설명합니다.
3. 자기평가로 15분/1일/3일 복습 예약 후 **개념별 새 전이문제**를 풉니다.
4. 원문제를 다시 풀고 최초 오답과 재도전 결과를 각각 기록합니다.
5. `10개년 기출`에서 **공식 문제 PDF**를 열어 실제 문제를 풀고 OMR에 답을 마킹합니다.
6. `공식 기출에서 필요한 이론 연결`에서 해당 문항 텍스트를 붙이거나 OCR된 TXT를 가져와, 출제개념을 검토하고 직접 연결합니다.
7. 10개년 연결 현황판에서 **텍스트 입력, 개념 연결, OMR 마킹**의 진행도를 확인합니다.

## 구현 원칙

- **능동 인출**: 먼저 답을 떠올린 뒤 확인. 정답을 읽기만 하는 방식보다 회상 연습을 우선합니다.
- **선지 대비**: 정답뿐 아니라 왜 나머지 선지가 틀렸는지 학습합니다.
- **간격 반복**: 기억 못함→15분, 부분 기억→1일, 설명 가능→3일의 *기본 설정*. 개인별 최적 간격을 과학적으로 예측한다고 주장하지 않습니다.
- **정답 출처**: 내장 정답과 수동 등록 정답 모두 A형·최종정답·복수정답 확인이 필요합니다.
- **안전한 진행**: 자동 배포, GitHub Actions, EXE/APK 생성, 사용량이 발생하는 CI 설정은 포함하지 않습니다.
- **데이터 보관**: 학습기록은 브라우저에만 저장. `내 데이터`에서 JSON 백업/복원이 가능하며 타 브라우저·기기와 자동 동기화되지 않습니다.
- **레거시 호환**: 기존 MVP의 저장 키 `recallgraph-first-exam-v1`을 계속 사용합니다.

## 개발 및 검증

이 프로젝트는 우선 하나의 `index.html`을 기준으로 동작합니다. 의존성 설치/빌드가 없고 원격 워크플로는 없습니다. 선택적 로컬 브라우저 검사는 다음과 같습니다.

```bash
python tests/smoke.py
```

이 검사는 Playwright Python 패키지 및 Chromium이 설치된 환경에서 실행합니다. 어느 GitHub Actions도 트리거하지 않습니다.

기능과 미완료 범위: [`docs/PHASE_LEDGER.md`](docs/PHASE_LEDGER.md). 시험일 사용 시나리오: [`docs/VERIFICATION.md`](docs/VERIFICATION.md). 출처 구분: [`docs/DATA_SOURCE_POLICY.md`](docs/DATA_SOURCE_POLICY.md).
